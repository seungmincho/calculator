# 모바일 유류비 차트 요청 시점 조정

## 확인한 병목

미리 읽기 축소 배포 이후에도 유류비 페이지의 첫 진입에서 Recharts가 들어 있는 청크 390,826바이트(로컬 gzip 추정 104,649바이트)가 요청됐다. 차트는 계산 결과 아래에 위치한다. 1280px PC에서 차트 제목의 문서 상단 위치는 약 859px, 390px 모바일에서는 약 2,428px이었다.

## 변경

파이·막대 차트의 기존 데이터와 표시식을 `FuelChartPlots`로 옮겼다. PC에서는 바로, 모바일에서는 차트 영역이 화면 200px 안으로 가까워졌을 때 두 차트를 불러온다. IntersectionObserver를 지원하지 않는 브라우저는 바로 불러온다. 높이를 고정한 자리 표시자와 각 차트의 금액을 설명하는 접근성 이름을 유지한다. PWA 캐시는 v4.31.4로 갱신한다.

## 같은 조건의 브라우저 측정

동일한 정적 export 서버, 브라우저, 날짜, API 모의값에서 최초 진입에 실제 요청된 JS 응답 본문의 합계다. gzip은 해당 응답들을 로컬에서 압축한 추정치다. 실제 사용자의 Web Vitals나 체감 속도를 측정한 결과는 아니다.

| 화면 | JS 전 | JS 후 | gzip 추정 전 | gzip 추정 후 |
| --- | ---: | ---: | ---: | ---: |
| 1280px PC | 1,410,314 | 1,414,693 | 396,385 | 398,284 |
| 390px 모바일 다크 화면 | 1,410,314 | 988,071 | 396,385 | 283,266 |

모바일 첫 요청 JS는 422,243바이트 줄었다. PC는 4,379바이트 늘었다. 차트를 실제로 볼 때 라이브러리 요청이 발생하며, 숨겼던 계산 데이터 자체는 언제나 접근성 이름으로 읽을 수 있다.

## 회귀 검증

- PC·모바일·IntersectionObserver 미지원 조건에서 차트의 최초 표시 여부, 250km 결과의 27,586원 툴팁과 원형 차트 비율, 차트 로드 전후 높이 변화 1px 이내를 검사했다.
- 6페이지 × PC/모바일의 기존 문구·언어 상태·검색 이동 12건과 대출·유류비 계산 브라우저 흐름 11건이 통과했다.
- 번역 원본 대응 11,301건, 전체 타입 검사, 756페이지 정적 빌드가 통과했다. 변경 파일 lint에서 새 오류는 없고 서비스워커의 기존 경고 2개만 남았다.

운영 배포 커밋·PWA 파일과 실제 브라우저 결과는 배포 후의 실행 기록에서 확인한다.
