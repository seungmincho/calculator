# 초기 번역 번들 분리 검증

## 변경

- 공통 화면과 홈·대출·연봉·유류비 화면은 필요한 번역 묶음을 동기적으로 가져온다. 전체 앱을 비동기 Provider/Suspense로 감싸지 않는다.
- `messages/ko.json`, `messages/en.json`이 편집 원본이다. `npm run messages:generate`가 두 언어의 shared·loan·salary·fuelCalculator·legacy 묶음 10개를 생성한다. dev/build/export/deploy 빌드 명령에 생성 단계를 연결했다.
- 아직 전환하지 않은 도구는 shared와 legacy를 합쳐 기존 전체 번역을 사용한다. 공통 번역이 이중으로 다운로드되는 것을 방지한다.
- GuideSection의 표시 부분을 분리해 대출·유류비에서 기존 전체 번역 모듈을 간접적으로 불러오지 않도록 했다.
- 계산식·세율·문구·현재 한국어 번역 동작은 유지했다. 언어 버튼이 en 상태여도 한국어 문구를 쓰는 기존 동작을 이번 작업에서 변경하지 않았다.
- PWA 캐시 버전을 v4.31.2로 올렸다.

## 같은 조건에서 측정한 크기

원본 저장소의 Next 16 Turbopack 정적 빌드를 같은 측정 스크립트로 비교했다. 단위는 바이트다. 초기 압축 추정은 HTML + CSS + HTML에 포함된 초기 JS 각각의 로컬 gzip 합계다. 이미지·폰트·서비스워커 설치 요청·동적 청크는 포함하지 않는다. 실제 브라우저 전송량이나 LCP/INP/CLS 개선율로 해석하지 않는다.

| 화면 | JS 전 | JS 후 | 초기 gzip 추정 전 | 초기 gzip 추정 후 |
| --- | ---: | ---: | ---: | ---: |
| 홈 | 3,326,652 | 1,003,482 | 1,072,510 | 357,752 |
| 연봉 | 3,415,609 | 1,106,381 | 1,093,291 | 384,396 |
| 대출 | 3,354,937 | 1,040,300 | 1,081,032 | 369,914 |
| 유류비 | 3,833,962 | 1,522,764 | 1,207,828 | 497,917 |
| JSON 포맷터 (기존 번역 경로) | 3,356,803 | 3,357,445 | 1,077,776 | 1,077,092 |
| BMI (기존 번역 경로) | 3,758,011 | 3,758,834 | 1,190,238 | 1,189,617 |

전환한 네 화면의 JS는 60.28~69.84%, 초기 gzip 추정은 58.78~66.64% 감소했다. 네 화면의 HTML 바이트 수는 동일하다. 비전환 두 화면의 압축 추정은 유지됐으며 JS의 미압축 크기는 모듈 연결 비용으로 0.02% 증가했다.

## 검증

- 생성 파일 10개가 원본 번역과 일치하며 shared+legacy가 한국어·영어 원본 전체를 그대로 복원한다.
- 기존 조회 함수와 11,301건을 비교했다. 문자열·변수 치환·없는 키·raw 배열/객체를 포함한다.
- 공통 레이아웃과 네 화면의 정적 의존성이 전체 번역 모듈을 불러오지 않는지 검사한다. 미해결 로컬 import도 실패로 처리한다.
- 6페이지 × PC 밝은 화면/390px 모바일 다크 화면 12개 사례에서 제목·본문이 변경 전 기준과 같았다. 언어 전환과 검색을 통한 대출 페이지 이동도 확인했다.
- 대출·유류비 브라우저 회귀 11개 및 계산/API/모의 Worker 테스트 7개 통과.
- 최종 `npm run build` 통과: 756개 페이지, RSC 후처리 1,224개.
- 변경 대상 lint는 기존 24 errors / 20 warnings와 동일하다. 이번 범위에서 추가된 오류·경고는 없고 새 코드 파일 9개는 모두 0 errors / 0 warnings다.
- 전체 lint는 기존 위반으로 실패한다: 550 errors / 457 warnings. 이 가운데 Worker의 기존 미사용 매개변수 경고 1개가 포함돼 있다. 성능 변경에서 새 오류를 만들지 않았다.

초기 타입 검사에서 생성 JSON의 상대 import 경로 오류를 발견해 수정했다. 배포 전 최종 독립 typecheck와 운영 화면/PWA 검증 결과는 실행 기록에 별도로 보존한다.

## 다음 조사 범위

유류비의 Recharts 차트 코드와 전환하지 않은 계산기의 번역 데이터가 남아 있다. 추가 개선은 차트의 실제 표시 위치·초기 요청·계산 결과를 먼저 측정하고 제한된 범위로 진행한다. 공통 런타임 제거, 전체 도구 재작성, 데이터 수집 활성화는 이 작업에 포함하지 않는다.
