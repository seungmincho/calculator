# 23차 독립 브라우저 계획

제품 담당의 부모 final ready와 번역 생성 신호 뒤 기존 localhost:3039에서 단일 Chrome을 순차 사용한다. 서비스워커·외부 요청을 차단하고 격리한 검증 데이터만 쓴다. 제품 파일·패키지·서버·빌드·전체 타입 검사는 수정하거나 실행하지 않는다. 최종 Chrome 종료 뒤 통합 담당에게 타입 검사 신호를 보낸다.

## 내 글 타자 연습

1. 지문 초안의 9/10/1,000/1,001 코드포인트 및 이모지, 줄바꿈·탭·연속 공백 정규화와 원 초안 보존. 불가 입력 무잘림·명시 적용만 확정.
2. 실제 키 입력으로 영어 연습 완료·정확도/오타, 한글 최종 글자의 합성 compositionstart/input/end 순서와 확정 prefix 오타. 중복 이벤트가 완료를 다시 만들지 않는지 확인. 실제 모바일 OS IME로 보증하지 않는다.
3. 시작 후 초안/다음 단위 변경은 현재 지문·타이머를 바꾸지 않음. 재연습은 확정본 유지, 명시 교체/ESC/기본↔내 글 왕복의 단일 활성 타이머와 정리.
4. 앱 언어 전환·기본 모드 왕복의 초안 보존, 사용자 결과가 기존 history/daily 원본 bytes·URL에 들어가지 않음. 기본 시간제 이탈 후 오래된 tick 기록0 및 정상 기본 연습 기록 회귀.
5. native Clipboard 성공·reject+fallback false·수동 전체 선택·재시도, 새로운 결과/모드 이탈 뒤 늦은 복사 응답 무효화. 요약에 지문 미포함·기본 결과 복사 경로 회귀.
6. 320px 다크 KO/EN, 16px 입력·44px 주요 버튼·키보드, 타자칸 붙여넣기/드롭 차단. 원시 번역 키·JS/hydration 수집.

## 화면 녹화

7. 테스트용 canvas.captureStream을 getDisplayMedia 반환값으로 연결해 native MediaRecorder로 실제 영상을 녹화, 비어 있지 않은 WebM Blob·파일명/MIME·다운로드 bytes·브라우저 video 재생 확인. pause/resume과 마지막 결과의 별도 시간 확인.
8. 마지막 성공 결과가 있는 상태에서 준비 거부·취소·생성/시작 실패 뒤 동일 URL/파일 보존. 준비 중 중복 요청 차단 및 뒤늦게 허용된 검증 stream tracks 종료.
9. 마이크 거부 안내→명시 화면 단독 계속 또는 취소. 요청한 system audio가 없을 때 미연결 표시. 가능한 경우 실제 AudioContext의 무음 destination 트랙으로 믹싱·정리 확인.
10. 정상 track ended·오류 뒤 data/stop·빈 Blob·이전 recorder 이벤트가 새 시도/마지막 성공 결과에 영향을 주지 않음. native 성공 증거와 제어된 실패 순서를 분리.
11. 단조 시계의 지연 tick·일시정지 제외, 새 성공 결과 확정 시에만 이전 URL revoke, 명시 삭제/언마운트의 tracks/context/timers/URL 정리, 준비 이탈 뒤 늦은 허용 종료.
12. 320px 다크 KO/EN에서 현재 시도/마지막 성공 결과·오디오 상태·실제 형식·44px 버튼, JS/hydration/원시 키 확인.

개인 화면·마이크·OS 캡처 선택창은 실제 호출하지 않는다. 화면 스트림은 검증용 캔버스, 오디오가 필요하면 검증용 무음 트랙으로만 만든다. 실제 MediaRecorder와 영상 재생 검증을 제어 API 오류/시계 검사 및 실제 기기 지원 주장과 구분한다.
