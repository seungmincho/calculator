# 23차 준비 계약 — 내 글 타자 연습·화면 녹화 다시 찍기

2026-11-17 KST. [후보 조사](../../handoff/2026-11-17-after-batch22-candidates.md)를 바탕으로 기존 경로의 다음 개선으로 채택한다. 20→21→22차가 우선이며 아직 제품 구현을 시작하지 않았다. 새 도구·서버·패키지를 만들지 않는다.

## A. 내가 고른 글로 타자 연습

`/typing-test/`에 ‘내 글 연습’을 추가한다. 기존 오늘의 문장·짧은 글·긴 글·시간제와 원래 기록/공유는 유지한다. 사용자 지문은 방문 중 메모리만 사용하며 URL·기기 기록·외부 요청에 넣지 않는다.

- 지문 작성칸과 타자 입력칸을 구분한다. 10~1,000 코드포인트를 허용하고 CRLF/CR/LF·탭을 공백으로, 반복 공백은 한 칸으로 정리한 미리보기/글자 수를 보여 준다. 적용 전에 결과를 확인할 수 있고 원본 초안은 그대로 보관한다. 잘못된 입력을 조용히 잘라 연습하지 않는다.
- ‘이 글로 시작’에서만 지문을 확정하고 현재 연습을 초기화한다. 초안 편집/앱 언어 전환/다른 연습 방식 방문이 초안을 지우지 않는다. 연습 중 새 지문 적용은 현재 진행이 교체됨을 명시한다. 지문을 수정만 했다고 현재 타이머/채점 대상이 바뀌지 않는다.
- KO/EN 타수 단위와 `diffTyped`/정확도/오타 자모 계산을 재사용한다. 다른 문자 체계의 정확한 키 입력 횟수를 새로 보장하지 않는다. 한글 IME 조합 중 완료를 확정하지 않고 확정 이벤트 후 최종 글자까지 처리한다. 실제 타자칸은 기존처럼 붙여넣기/드롭으로 완성하지 못하게 한다.
- 사용자 지문의 난도가 다르므로 기존 최고 기록·일일 횟수·연속일·최근100개에 합산하지 않는다. 결과는 이번 연습 속도/정확도/오타와 같은 지문 재연습으로 한정한다. 직접 지문 비교를 일반 평균이나 사용자 순위로 평가하지 않는다.
- 제어 가능한 자식 작업공간을 우선 검토한다. 기본 연습에서 내 글로 전환하면 진행 중 기본 타이머를 명시적으로 정리하고 숨겨진 채 계속 기록하지 않는다. 내 글에서 나갈 때도 타이머를 정리한다. 초안 보존과 진행 중 타이머 보존을 혼동하지 않는다.
- 결과 복사는 실제 성공/실패와 수동 선택을 구분하며 지문은 복사 요약에 자동 포함하지 않는다. 같은 지문으로 열리는 공유 링크처럼 표현하지 않는다. 기존 기본 연습의 Clipboard 실패 거짓 성공 경로도 작은 공통 헬퍼로 함께 보완할 수 있다.

검증: 지문 경계/정규화/초안과 확정본 분리, 한글 조합·마지막 글자·영문, 시작/재시작/모드 왕복의 타이머 수, 앱 언어 전환 보존, 기존 기록·일일 통계·URL 원문 부재, 실제 입력/복사 실패, 320px/키보드. 기존 계산 회귀를 재사용하고 모바일 실제 IME 기기와 합성 이벤트 검증을 구분한다.

## B. 화면 녹화 다시 찍기와 마지막 성공 결과 보존

`/screen-recorder/`에서 마지막 성공 결과 1개를 방문 중 메모리에 유지한다. 다시 찍기 준비나 권한 취소/초기화 실패가 그 결과를 지우지 않으며, 새 녹화가 유효한 비어 있지 않은 Blob으로 끝났을 때만 교체한다. 별도 명시적 결과 삭제를 제공한다. 영상 편집/잘라내기·녹화 여러 개 저장·서버 업로드는 추가하지 않는다.

- 준비/녹화/일시정지/종료 중 상태를 구분해 준비 중 중복 시작을 막는다. 권한 대기 취소/새 작업/언마운트 뒤 늦게 허용된 stream은 tracks를 닫고 recorder를 시작하지 않는다.
- 한 녹화가 자기 recorder·chunk·display/mic/합성 stream·AudioContext·타이머·generation을 소유한다. 오래된 onstop/onerror/track ended가 새 녹화나 마지막 성공 결과를 바꾸지 않는다. 정상 정지·브라우저 공유 중단·오류·언마운트에서 해제 가능한 자원을 정리한다.
- 녹화 시간은 interval 호출 횟수 대신 단조 시간과 누적 활성 구간으로 계산해 백그라운드 타이머 지연에도 표시가 따라오게 한다. 일시정지 구간은 제외하고 마지막 성공 결과의 시간은 새 시도의 시계와 분리한다. 영상 컨테이너가 제공하는 재생 길이와 표시 시계를 정확히 같은 값으로 보장하지 않는다.
- 요청한 마이크/시스템 음성과 실제 사용 가능한 트랙을 구분한다. 마이크 거부 후 조용히 마이크 포함 성공처럼 표시하지 않는다. 기존 가능한 화면 단독 녹화를 유지할지 다시 선택할지 사용자에게 명확히 알린다. 시스템 오디오 제공 여부를 브라우저/공유 대상과 무관하게 보장하지 않는다.
- 실패한 시도의 임의 chunk를 성공 영상으로 교체하지 않는다. 마지막 성공 결과는 미리보기/다운로드가 가능하고 별도 이름·크기·길이와 현재 진행을 혼동하지 않게 한다. 새 결과가 확정되기 전 이전 URL을 revoke하지 않는다.
- 기존 화질/FPS·일시정지/계속·기본 WebM 동작은 보존한다. MIME 지원을 점검하고 실제 형식에 맞는 파일명/안내를 사용한다. 새로운 모바일 화면 캡처 지원이나 다른 포맷을 구현했다고 주장하지 않는다.
- 수정 영역은 디자인 토큰과 44px 버튼으로 정리한다. 녹화 상태의 의미 있는 경고 색 외 장식 색/그림자를 추가하지 않는다.

검증: 제어 가능한 media 포트로 늦은 허용/권한 거부/중복 시작/stop-error 순서/track ended/언마운트와 이전 결과 보존, 실제 canvas captureStream→MediaRecorder→Blob/다운로드 재생, URL·stream·context 해제, 마이크 실패 안내와 현재/이전 결과 구분, KO/EN·320px. 개인 화면이나 마이크를 임의로 실제 캡처하지 않으며 OS 선택창/실기기와 합성 API 검증 범위를 구분한다.
