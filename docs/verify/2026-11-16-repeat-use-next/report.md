# 인터랙티브 팀 보드·재방문 기능 2차 검증

2026-11-16, 로컬 개발 서버 `http://localhost:3039`. 기존 도구 확장을 계속 진행하라는 사용자 승인에 따라 구현했다. 빌드·배포·커밋은 실행하지 않았다.

## 구현

| 경로 | 사용 흐름 | 저장·제약 |
|---|---|---|
| `/team-divider/` | 카드를 차례로 공개 → 드래그 또는 탭으로 이동 → 다른 팀 두 명을 선택해 교환 → 멤버 고정 후 다시 편성 → 되돌리기 | 기존 명단 저장 유지. 2~8팀, 최대 200명. 고정 조건 때문에 인원·실력 차이가 커질 수 있음을 표시. 실력 배정은 근사 알고리즘이며 최적해를 보장하지 않음 |
| `/presentation-timer/` | 연습 기록 켜기 → 실제 발표 구간을 넘길 때 버튼 누르기 → 마치고 저장 → 지난 연습과 비교·구성 재사용 | 최대 20회 localStorage. 일시정지 제외. 방문하지 않은 구간은 빈 값. 같은 구간 구성일 때만 구간별 차이 비교. JSON 내보내기·확인 후 삭제 |
| `/image-ocr/` → `/text-to-speech/` | 실제 OCR → 오류 수정 → 전체 또는 선택한 글 읽어주기로 전달 → 사용자가 재생 | 원문은 URL에 넣지 않음. 같은 탭 sessionStorage에서 최대 3만 자·10분 유효. 전달 후 삭제. 기본 기기 내 음성만 사용, 내장 음성이 없으면 사용자 선택 전 재생 차단 |
| `/menu-roulette/` | 룰렛 결과를 오늘 먹은 메뉴로 저장 → 날짜별 기록 → 오늘 또는 최근 7일 메뉴 제외 | 최대 200개 localStorage. 기기 날짜 기준, 오늘 포함 7일. 원래 후보는 유지. 후보 2개 미만이면 돌리기 중지 및 복구 안내. 메뉴 이름이 정확히 같은 항목만 제외 |

팀 결과 공유는 이름·실력·편성 정보가 포함된 URL fragment를 사용하며 복원 가능하다. 공유 버튼을 누르기 전에는 이름을 주소에 반영하지 않는다. 고정·되돌리기 이력은 공유 대상이 아니다. reduced-motion에서는 카드 공개를 즉시 완료한다.

기기 내 기록은 사이트 데이터 삭제 시 사라진다. 저장 공간 오류·잘못된 기존 데이터는 성공으로 표시하지 않으며 입력과 현재 측정값을 보존한다. 추가 생성형 모델이나 서버 저장은 없다. OCR은 기존 Tesseract 모델 다운로드를 사용하고, 연결된 읽어주기의 기존 구간 반복 기능을 유지한다.

## 검증 결과

- `scripts/check-team-board-browser.mjs`: **3개 통과**. 카드 공개, 이동, 교환, 되돌리기, 고정 후 재편성, 공유 링크 복원, 실제 데스크톱 드래그, 375px 탭 조작, 캡틴 드래프트, 동작 줄이기.
- `scripts/check-repeat-use-next-browser.mjs`: **10개 통과**. 리허설 저장·비교·재방문·삭제, 일시정지 제외 및 저장 실패 복구, OCR 전달/음성 선택, 실제 Tesseract 인식 후 전체 글·선택 영역 전달, 메뉴 날짜 범위·재방문·날짜 변경, 제외 후보를 반영한 실제 추첨·후보 복구, 저장 실패, 320px 화면.
- `scripts/check-repeat-use-browser.mjs`: 기존 **10개 회귀 시나리오 통과**. 음성 메모 저장·검색·실제 녹음/일시정지·오류 처리, TTS 반복·대기 취소, 명단 저장·복원·삭제, 좁은 화면.
- `scripts/check-repeat-use-next.ts`: 시간 기록·저장 검증, 전달 만료·크기 제한, 날짜·윤년·7일 경계 등 **23개 통과**.
- `scripts/check-team-board.ts`: 인원 보존·고정·이동/교환·입력 불변성·공유 검증 통과.
- 기존 `check-presentation-timer.ts`, `check-ocr.ts`, `check-tts.ts` 통과.
- 변경한 12개 컴포넌트/유틸 ESLint 오류·경고 0, 전체 `npx tsc --noEmit` 통과.
- 메시지 생성·일치 검사 통과. namespace audit 미해결 **0**, 기존 동적 키/범용 컴포넌트 안내 **60건** 유지. RSS·redirects·llms.txt 재생성.

브라우저 검사에서 JS 예외와 hydration 경고를 수집했다. 발표 타이머의 기존 URL 초기값이 서버 기본값과 달라 발생하던 hydration 불일치는 브라우저 준비 후 복원하도록 수정했다. 최종 통과 시나리오에는 이 오류가 없다.

전체 실행 중 OCR 선택 영역 검사는 합성 `select` 이벤트가 React의 실제 선택 이벤트를 재현하지 못해 실패했다. 테스트를 Home/Shift+방향키의 실제 키보드 조작으로 바꾸고 전체 글·선택 영역 두 흐름을 다시 통과시켰다. `final-results.json`은 전체 실행 결과에 해당 재검증과 최종 모바일 배치 검사를 덮어 합친 결과이며, 원 실행 결과도 남겼다.
