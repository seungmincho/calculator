## 달라진 동작

CSV는 하나의 파서와 확정 결과에서 텍스트·표·통계·복사·다운로드를 만든다. 따옴표 안 줄바꿈과 구분자·공백·빈 셀을 보존하고 문자열을 기본으로 유지한다. 숫자 변환은 명시 옵션이며 안전한 문법·범위만 처리한다. JSON의 안전 범위 밖 정수는 문자열 입력을 안내하며 거부한다. 모든 행의 열 합집합과 특수 키를 유지하고 평탄화 충돌은 오류로 알린다.

파일은 UTF-8/EUC-KR로 실제 읽으며 출력은 UTF-8이다. CSV 출력에만 BOM을 선택할 수 있다. 입력2MiB·10,000행·200열·200,000셀·깊이20·중간 데이터/출력8MiB 한도를 넘으면 원문을 보존한 채 거부한다. 새 파일·편집·옵션·취소 뒤 오래된 읽기를 무시하며, 변경된 결과의 복사/다운로드를 차단한다. 긴 표 셀은 펼쳐 전체 내용을 선택할 수 있다. root의 실제 화면 검토 후 행·열·내용 접근성 이름과 파일 선택 키보드 초점 표시를 추가했고 영향1그룹과 lint를 통과했다.

Base64는 UTF-8 텍스트·원본 파일 바이트·확정 결과를 분리했다. 표준/URL 알파벳·패딩을 선택하고 잘못된 패딩·마지막 비트를 거부한다. 파일을 다시 변환해도 data URL 문자열을 이중 인코딩하지 않는다. 디코딩 업로드는 이름보다 실제 UTF-8 내용·크기·Base64 규칙으로 판단한다. 유효하지 않은 UTF-8 결과는 가짜 텍스트로 바꾸지 않고 바이트 파일로 제공한다.

일반 Base64/data URL 대상을 구분하고 실제 성공에만 복사 완료를 표시한다. 실패 시 현재 결과의 수동 선택·재시도가 가능하며 늦은 읽기/복사는 새 상태를 바꾸지 않는다. PNG/JPEG/GIF/WebP 헤더·16,777,216픽셀 이하·실제 이미지 load를 확인한 경우에만 미리보기를 제공한다. SVG/HTML은 실행하지 않는다. 이미지/다운로드 URL을 회수하며 원문·파일·결과를 URL이나 기기 기록에 새로 저장하지 않는다.

구현 상세: [CSV](json-csv-implementation.md), [Base64](base64-implementation.md).
