# 17차 준비 계약 — 목표 조건 비교·음력 기념일 캘린더

2026-11-17 KST. 사용자의 계속 개발 지시에 따라 기존 도구 개선을 이어 간다. 15·16차 검증 대상 파일은 해당 배치가 끝날 때까지 바꾸지 않는다. 새 도구/경로를 추가하지 않는다.

## A. 수능의 사용자 목표 조건 비교

`/csat-grade/`는 이미 국어·수학·영어·탐구 상위1과목 중 2/3/4개 영역 합을 계산한다. 이 계산을 재사용해 이름 40자·최대 6개의 사용자 조건(영역 수 2/3/4, 등급 합 상한)을 명시 저장·수정·삭제하고 현재 입력에 따른 결과를 함께 표시한다.

대학별 모집요강을 자동 적용하거나 지원 가능/합격으로 판정하지 않는다. 필수영역·탐구 평균·한국사 별도 기준 등을 처리하는 대학별 엔진으로 표현하지 않는다. UI는 입력한 단순 목표의 충족/부족을 설명하고 계산에 포함되는 영역을 보여 준다. 15차 전년도 참고 추정 표시와 16차 기록을 유지한다. 새 조건 목록은 기존 공유 URL에 자동 포함하지 않는다.

빈 점수를 실제 0점·9등급으로 간주해 목표 결과를 단정하지 않는다. 유효한 국어·수학·영어·탐구 상위 1과목 영역 수가 조건의 영역 수보다 적으면 ‘입력 필요’로 표시한다. 일부 입력만으로 계산할 때는 ‘현재 입력된 영역 기준’과 실제 사용 영역을 명시한다. 탐구 두 입력은 한 영역으로만 취급하며 중복 선택을 두 영역처럼 세지 않는다. 값의 범위·영역 수·등급 합 상한을 검증하고, 저장된 목표와 기존 일회성 비교 사이에 판정/표시 모순이 생기지 않는지 함께 검토한다.

담당 예정: gpa_scenarios. 16차 점수 기록의 검증·타입 체크포인트 이후 동일 부모를 이어 소유한다. ko/en 조각·관련 도메인 검사를 함께 작성하며 공용 파일은 통합 담당만 편집한다.

## B. 음력 기념일 날짜를 캘린더로 내보내기

코드 확인: `LunarConverter.tsx`는 음력 기념일의 11개년 양력 변환표와 복사를 제공하지만 ICS 내보내기는 없다. `lunarCalendar.ts`의 변환·윤달/짧은 달 대체 규칙을 바꾸지 않고, 사용자가 선택한 연도의 계산된 날짜를 캘린더 파일로 받게 한다.

- 명시적 제목 입력과 연도 선택, 선택 날짜 미리보기, `.ics` 다운로드. 음력 반복을 양력 `RRULE:FREQ=YEARLY`로 저장하지 않고 각 연도의 계산 날짜를 개별 종일 일정으로 기록한다.
- 윤달이 없는 해·해당 일이 없는 달의 기존 대체 규칙을 화면과 일정 설명에 포함한다. 정상 변환 범위 밖은 조용히 임의 날짜로 바꾸지 않는다.
- 기존 공유·변환·연도표·복사·D-day를 유지한다. 새 자동 저장소·외부 캘린더 쓰기·패키지를 추가하지 않는다. RFC5545 날짜/다음날 종료·CRLF·한글 줄 접기·텍스트 이스케이프는 기존 캘린더 유틸을 재사용할 수 있는지 확인한다.
- 실제 ICS를 독립적으로 읽어 날짜/제목/대체 안내를 확인하고 윤달·연말·지원 범위 경계·빈 선택·긴 제목·320px를 검증한다.

담당 예정: taxi_repeat. 기존 D-day의 인쇄/ICS 검증 경험을 이어 활용한다. 도메인/유틸부터 준비할 수 있으나 부모 UI/공용 번역은 앞 배치 체크포인트와 충돌하지 않게 root가 연결 시점을 조율한다.

전체 타입 검사·Chrome은 순차 사용한다. 빌드·배포·커밋·푸시는 실행하지 않는다. 완료 전까지 이 문서는 준비 계약이며 검증 통과를 뜻하지 않는다.
