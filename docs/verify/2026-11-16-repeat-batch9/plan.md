타이머는 루틴 실행 중 페이지 종료 후에도 계속 울리는 서비스라고 주장하지 않는다. 화면을 열어 둔 동안의 시간 경과를 계산하며, 페이지 재방문은 저장 루틴을 불러와 다시 시작한다. 음향은 기존 사용자의 음소거 설정과브라우저제약을따른다.

QR 원문은 URL·서버·자동저장에넣지않는다. 하나의 QR 내용이 URL인지와무관하게텍스트원문그대로인코딩한다. 실사진없이작은브라우저생성PNG를독립디코더로확인할수있으면검사하고, 디코딩환경이없으면포맷/행매핑검증한계명시및대안검토한다. 새제품의존성을검증목적으로추가하지않는다.

제품별담당이ko/en번역조각·domain검사·scopedlint함께작성. 공용messages/page/menu/RSS는 batch5_integrate만수정. browser는 batch5_verify 순차실행. 모든제품변경은현재미커밋작업을보존하고build/deploy/commit/push없이진행한다.
