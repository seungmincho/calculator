## 통합 검사

세 도구 메뉴 updatedDate와 페이지 설명·JSON-LD 기능 목록을 반영했다. 세 번역 조각을 병합하고 생성물을 스크립트로 갱신했다. 신규 132키/언어와 6개 컴포넌트 정적 사용 315개·동적 접두 경로를 확인해 누락이 없었다. 독립 브라우저 13/13 통과, JavaScript·hydration 오류 0이며 실행한 브라우저는 모두 닫았다.

10차와 함께 Chrome을 닫고 2026-11-16 23:22 KST에 전체 타입 검사(2GB heap)를 통과했다. 시작 직전 여유 메모리는 5.33GiB였다. 번역 생성본 796개 일치, namespace 미해결 0개(기존 동적 안내 60개), RSS 382개·redirect 472개·llms 315개 도구를 재생성했고 공용 메타데이터 lint와 `git diff --check`도 통과했다. TimerStopwatch의 기존 exhaustive-deps 경고 1개는 남아 있으며 신규 루틴 코드에는 경고가 없다.

타이머는 Playwright Clock의 300초 도약과 실제 Web Audio 호출 횟수로 복귀/중복 알림을 확인했다. OS 스피커·실기기 백그라운드 정책까지 확인한 것은 아니다. QR ZIP의 서로 다른 PNG 3개와 기존 Wi-Fi/vCard를 고정 jsQR 1.4.0으로 독립 디코딩했다. 검증용 디코더만 임시 브라우저 컨텍스트에서 사용했고 제품 의존성은 추가하지 않았다. 저장소 잠금 미지원 환경은 원본 비교·쓰기 확인으로 충돌을 감지하지만 완전 동시 쓰기의 원자성은 보장하지 않는다.

상위 큐와 [실행 계약](plan.md)이 재개 기준이다. 루틴은 페이지를 닫은 뒤에도 알림이 계속되는 서비스가 아니며, QR 일괄 원문은 URL·서버·자동저장에 넣지 않는다. 공통 번역기의 기존 한국어 전용 제약을 유지하고 영어 UI 전환을 주장하지 않는다.
