# 13차 실행 계약 — 실패한 작업을 이어가기

2026-11-16. 사용자가 GPA 변환기 복사 실패 복구와 읽어주기 오류 문장 재시도를 멀티 에이전트로 구현·검증하도록 명시 승인했다. 이전 15개 개선(8~12차)은 66개 브라우저 시나리오와 타입 검사를 통과한 별도 완료 기록이다.

| 대상 | 사용자 동작 | 보존·검증 기준 |
|---|---|---|
| GPA 변환기 | 결과/공유 링크 복사 실패 시 이유와 직접 선택할 텍스트, 명시적 재시도 | Clipboard 거부·API 없음·execCommand false/throw를 성공으로 표시하지 않음. 현재 결과/링크만 제공, 입력·만점·다른 복사 요청 후 오래된 Promise가 상태를 덮지 않음. 공유 링크 초기 복원 유지. 기존 계산식·참고 등급표·이미지 저장 보존 |
| 읽어주기 | 오류가 난 문장 번호/미리보기와 해당 문장부터 다시 읽기 버튼 | 사용자 클릭으로만 재시도. 정확한 실패 문장·현재 반복 회차·남은 반복 횟수 보존. 본문/반복 설정 변경·정지·다른 문장 재생·새 전달은 실패 위치 무효화. 오래된 utterance 오류/종료 콜백 무시. 기존 기기 음성 필터·pause/resume·OCR/메모 전달 보존 |

두 기능 모두 실패 안내 바로 옆에 복구 버튼을 배치한다. 16px 입력·44px 터치·320px 가로 넘침·디자인 토큰·ko/en 번역 키를 확인한다. 개인정보가 포함될 수 있는 본문을 서버에 전송하거나 새로운 자동 저장소에 넣지 않는다. 새로운 서버·경로·유료 API·패키지는 추가하지 않는다.

## 분업

- taxi_repeat: GPA 컴포넌트·필요 유틸·도메인 검사·ko/en 번역 조각.
- gpa_scenarios: TTS 컴포넌트·필요 유틸·도메인 검사·ko/en 번역 조각.
- writing_versions: 독립 코드/도메인 리뷰, 재현 근거·수정 확인. 제품 파일은 직접 수정하지 않음.
- batch5_verify: 별도 테스트 브라우저에서 실제 UI 조작, Clipboard/Web Speech 실패 주입, 산출물·모바일·회귀. 음성 API 상태 전이와 실제 기기 합성 품질을 구분.
- batch5_integrate: 공용 메시지·생성물·메뉴/페이지·최종 타입·보고서·인계.
- root: 범위·우선순위·후속 배정·결함 판단·사용량 확인.

새 파일을 준비한 다음 부모에 연결해 공유 개발 서버의 전역 오류 화면을 피한다. 단일 Chrome과 전체 타입 검사는 순차 사용한다. 실제 관련 검사가 끝나고 브라우저를 종료한 뒤 2GB heap으로 전체 타입 검사를 한 번 수행한다. 새 실패/변경이 없는 검사를 반복하지 않는다.

사용자는 한도가 소진되면 초기화 쿠폰을 사용하도록 승인했다. 계정 사용량은 전체 계정 공유 수치다. 시작 조회는 89% 사용/11% 남음, 초기화 쿠폰3개 미사용. 필요 시 root가 공식 사용량 화면의 지원되는 경로를 확인한다. 사용하지 않은 쿠폰을 사용했다고 기록하지 않으며 임의 구매/유료 자동 충전은 하지 않는다. 빌드·배포·커밋·푸시는 이번 승인에 포함되지 않는다.
