## 통합 범위

메뉴 updatedDate·페이지 설명·JSON-LD 기능 목록과 도구 소개를 갱신했다. ko/en 번역 조각은 공용 담당 한 명이 원본에 병합하고 생성 스크립트로만 생성물을 바꿨다. 신규 15키/언어와 세 컴포넌트의 정적 사용 138개에 누락이 없다. 계산식·성적 참고표·기기 음성 필터·기존 OCR/메모 전달은 각 담당과 독립 검증자가 회귀 확인한다.

읽어주기는 실패 당시 본문·문장·반복 회차를 메모리에만 보관한다. 본문/반복 설정·정지·다른 재생은 실패 위치를 버리고, 음성/속도/음높이/음량 변경은 위치를 유지해 재시도에 새 설정을 적용한다. 기기 음성 전용 토글은 기존 정지 정책을 유지한다. 같은 세션의 이전 발화 이벤트도 현재 문장을 덮지 않으며 `canceled`/`interrupted`는 복구 오류로 표시하지 않는다. [구현 검사와 한계](tts-implementation.md).

## 독립 검토와 실제 브라우저

GPA 준비 중 결과 복사가 대기하는 동안 링크 복사가 성공한 뒤 과거 요청이 실패하면, 예전 fallback이 최신 클립보드를 덮는 P2를 발견했다. 전역 요청 번호와 단일 최신 복사 상태로 이전 fallback/UI 갱신을 무효화했다. 최종 실제 컴포넌트에서 결과 대기→링크 성공→이전 결과 실패를 재현해 fallback 0회·최신 링크 유지로 해결을 확인했다. [독립 검토](independent-review.md).

브라우저에서는 실제 Clipboard 성공과 실패/미지원/fallback 행렬, 수동 선택·재시도, 입력·만점·다른 복사 대상의 늦은 응답을 확인했다. 기존 4.5/4.3/4.0/100 계산과 공유 URL·PNG 이미지 저장도 통과했다. 담당 도메인 검사는 실제 계산 함수를 추출해 정상·경계·잘못된 값과 비례 환산/참고 등급 구분을 고정 기대값으로 대조했다.

TTS는 실제 화면에서 제어한 Web Speech 콜백으로 정확한 실패 문장·반복 회차·남은 발화 순서, 명시적 재시도·pause/resume·입력 변경 무효화·늦은 콜백·기기 음성 필터·OCR/메모 전달을 확인했다. 두 도구 모두 320px 다크와 복구 버튼/입력 크기를 확인했다. 초기 1개 실패는 React 반영 전 disabled를 읽은 테스트 대기 문제였으며 해당 사례만 재실행해 통과했다. 제품 미해결 결함은 없다.
