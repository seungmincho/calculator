## 독립 검토와 수정

팀 백업에서 복사본 제목을 바꾼 뒤에도 과거 importOrigin만 보고 중복으로 오인하는 문제를 수정했다. 복사 당시 제목을 함께 보존하고 현재 제목과 일치할 때만 origin 중복으로 판단한다. GPA에서는 오래된 잠금 요청의 실패가 새 파일 미리보기를 지우는 문제를 catch/finally의 세대 검사로 막았다. 두 수정은 독립 재현·해결 확인했다. 독립 도메인 15그룹과 실제 GPA 컴포넌트의 지연 이벤트 하네스가 통과했다. [독립 검토](independent-review.md).

원고 백업은 다른 구현 담당자가 독립 검토했다. 실제 컴포넌트의 지연 파일 읽기·취소·잠금 대기·현재 탭 전환·원본 변경·현재 원고 키 보존 6개 검사를 통과했다. 이 하네스는 DOM/React 렌더러를 대체한 이벤트 검사이며 실제 브라우저 검증과 구분한다. [원고 교차 검토](writing-independent-review.md).

## 공용 통합과 실제 브라우저

ko/en 신규 92키와 6개 컴포넌트 정적 사용 204개를 대조했다(후속 참석자 연결을 포함한 최종 코드). 메타데이터·도구 설명·JSON-LD에 백업을 반영하고 기존 updatedDate 2026-11-16을 유지했다. 영어 UI 전환을 구현하거나 검증한 것은 아니다.

독립 브라우저 14/14·JavaScript/hydration 오류 0이다. 세 도구에서 실제 JSON 파일 다운로드→파일 선택→미리보기→명시적 추가 왕복을 확인했다. 팀 결과/고정, GPA 현재 성적/자동저장, 원고 5문항/실행 취소를 보존했다. quota·다른 탭 변경·손상/다른 도구/미래 버전/중복 ID·읽기 전 크기 초과·지연 읽기 취소·개수 초과의 전체 거부도 통과했다. 독립 리뷰의 팀 제목 변경과 GPA 오래된 요청 실패를 실제 Chrome에서 각각 재현해 수정 결과를 확인했다. 320px 다크 화면에 페이지 가로 넘침이 없다.

12차까지 모든 브라우저를 종료하고 23:34 KST에 `node --max-old-space-size=2048 node_modules/typescript/bin/tsc --noEmit`을 단독 실행해 exit0을 확인했다. 시작 직전 여유 메모리는 5.54GiB였다. 번역 생성본 796개 일치·namespace 미해결 0개(기존 동적 안내 60개), 공용 범위 lint·RSS/redirect/llms 생성·`git diff --check`도 통과했다.

Web Locks 지원 시 쓰기를 직렬화하며 미지원 환경의 원본 비교·쓰기 확인은 완전한 탭 간 원자성을 보장하지 않는다. 빌드·배포·커밋·푸시는 실행하지 않았다.
