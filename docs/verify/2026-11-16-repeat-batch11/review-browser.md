# 11차 독립 브라우저 검증

팀 명단·GPA 시나리오·원고 수정본 백업을 각 4개 흐름, 총12개로 검증한다. 기존 개발 서버3039를 재사용하고 한 개 Chrome에서 순차 실행한다. 외부 요청과 서비스 워커는 차단한다. 9/10차 전체 타입 검사 종료 뒤 브라우저를 시작한다.

## 결과

2026-11-16 실제 Chrome, 기존 개발 서버3039에서 **14/14 PASS**. JavaScript 예외·hydration 오류0. 한 브라우저에서 순차 실행 후 종료했다. 제품 파일은 수정하지 않았다.

- 세 도구의 실제 JSON 다운로드 파일을 다시 선택해 원본 데이터 왕복, 미리보기 단계의 무변경, 중복 거부, 충돌 새 ID 복사, 현재 작업 보존을 확인했다. 원고는5문항과 되돌리기, 팀은 현재 결과와 고정까지 확인했다.
- 각 도구에서 quota·다른 탭 변경·손상/타 도구/미래 버전/중복 ID 파일·읽기 전 크기 초과 거부·느린 읽기 취소·최대 개수 초과 전체 중단을 확인했다.
- 독립 리뷰에서 수정된 팀 복사본 제목 변경 후 재수입과 GPA A 추가의 Web Lock 대기 중 B 파일을 선택한 뒤 A가 실패하는 상황을 실제 Chrome에서 별도 재현했다. 변경한 팀 복사본은 보존되고 B 미리보기도 유지됐다.
- 320px 다크 화면에서 문서 가로 넘침 없이 미리보기/초과 안내/비활성 추가 버튼을 확인하고 캡처를 검토했다. ko/en 번역 구조 대조와 language=en 상태의 기능·원시 번역 키 노출을 확인했다. 기존 공통 i18n 레지스트리는 한국어 전용이므로 영어 UI 전환 통과를 의미하지 않는다.

초기 실패는 테스트의 사라진 DOM 검사 시점, GPA 선택 플래그 정규화 및 JSON 속성 순서 비교, 원고 목록 추가 위치에 대한 기대 오류였다. 기대와 대기를 바로잡은 뒤 해당 케이스만 재실행했다. 새 제품 결함은 발견하지 않았다. Web Locks 미지원 환경의 완전 동시 쓰기 원자성은 별도 보장 범위가 아니다.
