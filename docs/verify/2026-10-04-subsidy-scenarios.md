# 지원금 검증 시나리오

- 생성일: 2026-10-04 (Asia/Seoul)
- 대상: 정적 빌드 및 https://toolhub.ai.kr
- 도구: 기존 Playwright 검증 스크립트, TypeScript, ESLint, 번역 생성 검사
- 실행 순서: 빌드 → 로컬 브라우저 → 커밋·푸시·배포 → 운영 브라우저. 입력 검증과 정책 수정은 별도 커밋으로 진행한다.

| 시나리오 | 실제 동작 | 기대 결과 |
|---|---|---|
| 청년월세 빈칸 | 모바일에서 금액 5개를 비운 채 자격 확인 클릭 | 결과 없음, 필드별 오류 5개, 첫 오류 필드로 포커스 |
| 청년월세 0원 | 소득·재산·보증금 0, 월세 20 입력 후 계산·새로고침 | 0을 URL과 입력에 보존, 계산 결과 복원 |
| 청년월세 잘못된 값 | 음수, 비유한 수, 문자 섞인 금액, 금액 누락 링크 방문 | 오류 안내, 지원 대상으로 표시하지 않음 |
| 결과 무효화 | 계산 후 월세 변경 | 이전 결과와 계산 URL 제거, 재계산 가능 |
| 정부지원금 공유 | 소득·재산·월세·보증금 0 링크 방문·계산·새로고침 | 0 유지, 잘못된 공유 값은 오류 안내 및 결과 없음 |
| 언어·모바일 | 두 지원금 페이지 한국어/영어 직접 진입·홈에서 이동·언어 전환 | 번역 키 노출·가로 넘침·런타임 오류 없음 |
| 모바일 회귀 | 검색·메뉴·하단 패널을 열고 배경 스크롤 및 닫기 | 스크롤 잠금과 원래 위치 복원 |
| PWA | 이전 버전 정적·동적 캐시를 생성하고 홈 방문 | 새 서비스 워커 활성화, 이전 캐시 제거 |
| 운영 PWA 실갱신 | 배포 전 운영 브라우저 또는 실제 이전 배포 자산으로 초기화한 브라우저에서 registration.update·새로고침 | 최신 서비스 워커 활성화, 이전 캐시 제거, 새 정책 화면 표시; 사전 운영창과 아카이브 재현을 구분 |
| 정책별 계산 | 국가사업 미수혜·12회 기수혜·24회 기수혜 및 월세 15/20/50 입력 | 최대 24회에서 기수혜 차감, 잔여 24/12/0회, 월 지원 상한 20만원 |
| 정책 안내 | 결과·상단 안내·가이드·메타데이터 확인 | 국가사업과 서울시 사업 구분, 2026 접수 종료, 2차 수혜자 신청 시점·지급 기한 안내 |
| 정책 경계 | 청년가구 소득평가액 153/154만원·30세 원가구 고소득·월세 100만원·보증금 6000만원 확인 | 2026 중위소득 적용, 30세 이상 예외 적용, 폐지된 주거 상한으로 탈락시키지 않음 |
