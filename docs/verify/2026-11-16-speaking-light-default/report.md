# 말하기 연습실 경량 기본 모드 — 2026-11-16

사용자 승인에 따라 기본 흐름을 Whisper tiny + 규칙 기반 점검으로 변경했다. 생성형 코칭은 원하는 사용자가 다운로드 용량을 확인하고 직접 선택·실행할 때만 받는다. 배포·빌드는 실행하지 않았다.

## 구현

- 녹음·직접 입력·기본 점검·비교·저장은 생성 모델 다운로드 없이 동작한다. 음성 인식은 기존 Whisper tiny int8/WASM 워커를 쓰며, 버튼을 누를 때만 모델을 준비한다. 모델 가중치 약 40.84MB와 토크나이저·실행 파일은 별도라는 안내를 표시한다.
- 기본 점검은 입력 수정 즉시 갱신된다. 녹음 시간·어절 수·속도, 전사문의 추임새 후보, 3회 이상 반복된 어절(일부 상용어 제외, 최대 5종), 모드별 구성 단서를 표시한다. 45~75초는 연습 참고 범위이며 점수 기준이 아니다. 직접 입력의 시간을 추측하지 않는다.
- 단어/표현 규칙이며 의미 이해·발음 평가가 아님을 명시했다. 인식에서 빠진 추임새를 세지 않으며, 구성 단서가 없다고 내용이 빠졌다고 단정하지 않는다.
- Qwen3-1.7B 생성형 코칭은 별도 선택 카드로 이동했다. 안내 펼치기나 동의 체크만으로 다운로드하지 않는다. 첫 실행 약 1.1GB(기기에 따라 더 클 수 있음)를 확인한 뒤 코칭 실행 버튼을 눌러야 한다. 미지원 기기에서도 기본 모드는 유지된다.
- 음성 인식/코칭 처리 완료 후 워커를 종료한다. 파일 캐시는 재사용하며 ASR와 LLM을 동시에 메모리에 유지하지 않는다. 코칭 컨텍스트는 4096토큰으로 명시했다(설치된 모델 기본 설정과 동일).
- 코칭 캐시 삭제는 WebLLM CacheStorage의 해당 Qwen 모델 두 변형(f16/f32)과 실행 파일만 삭제한다. 빈 캐시나 일부 다운로드 파일에도 네트워크 없이 동작한다. 라이브러리 기본 삭제 함수가 없는 manifest를 다시 받으려는 문제를 피했다. Whisper·다른 모델·IndexedDB 연습 기록은 유지한다.
- 기존 IndexedDB version 1 형식과 최대 20개 기록/5회 연습 제한을 유지했다. 기본 점검은 저장된 원문·시간으로 재계산한다. 비교에 추임새 후보/반복 어절 수를 추가하고 텍스트 내보내기에도 기본 점검을 포함했다.
- 모바일 입력은 16px, 녹음·점검·코칭 버튼은 충분한 터치 높이와 전체 폭을 사용한다. 결과 이동 링크 및 화면 상단 진행/취소 표시로 긴 화면에서도 조작할 수 있다.
- 실제 모델에서 완료 작업을 진행 중으로 바꾸는 출력이 발견됐다. 예시가 원문에 섞이는 few-shot 프롬프트를 제거하고 상태 보존 지시·temperature 0을 적용했다. 원문에 없던 진행 중 주장을 추가하는 경우를 거절하는 좁은 검사도 추가했다. 모든 의미 변화를 판별하는 검증은 아니므로 사실관계 확인 안내를 유지한다.
- ko/en 문구, 도구 소개·메타데이터/JSON-LD, OG 이미지, RSS·리다이렉트·llms.txt를 갱신했다.

## 검증

- 순수 로직 검사 18개 PASS: 추임새 경계, 반복 어절/상용어, 직접 입력·빈 입력, 시간 경계, 모드별 구성 단서, 기존 피드백·기록·공유 검증과 진행 상태 변경 거절.
- Chrome 사용자 흐름 14개 PASS: 대형 모델 무요청 기본 흐름, WebGPU 없는 환경, 자동 점검·수정, 명시적 선택, 코칭 취소, 오프라인 캐시 삭제/일부 파일/다른 파일 보존, 재녹음·실제 음성 Blob 재생·복원, 파일 검사, 저장 실패·20개 제한·손상 기록, 숫자만 공유, 권한 거절/늦은 응답 취소, 실제 90초 자동 종료.
- 전체 실행에서 캐시 삭제 1개가 실패한 뒤 수정했고, 해당 시나리오를 재실행해 통과했다. 원본 결과를 보존하고 최종 상태를 `verification-summary.json`에 합쳤다.
- 실제 한국어 WAV → Whisper 전사 → 기본 점검 성공. 이 단계에서 Qwen/MLC 모델 요청 없음. 고유명사 인식 오류가 있어 원문 편집을 유지한다.
- 실제 Qwen 자기소개/업무 보고 생성 → 저장 → 원문 수정 시 이전 코칭 제거 → 기록 복원 성공. 마지막 실행의 업무 보고는 완료한 작업과 다음 배포 일정을 보존했다. 샘플 몇 개의 검증이며 모델 전체 품질 보장은 아니다.
- 모바일 Chrome 뷰포트 320px(다크), 375px(라이트) 가로 넘침 없음. 320px 기본 점검 화면을 시각 확인했다. 추가로 높이 812px에서 첫 녹음 버튼이 하단 내비게이션 위에 완전히 보이도록 시작 안내·간격·빈 연습 버튼을 정리했다. 320/375px 첫 화면 검증도 통과했다(`browser-initial-mobile.json`).
- 전체 TypeScript, 변경 TS/TSX ESLint, 생성 번역 일치 검사 PASS. namespace audit unresolved 0.

결과: `verification-summary.json`, `browser-results.json`, `browser-remove-coaching-cache.json`, `real-standard.json`, PNG 화면 및 텍스트/음성 내보내기 파일.
