# 42차 실행 계약 — 한글 워들 일일 기록과 결과 공유

상태: 로컬 구현·자체21·독립8그룹·실제 Chrome8/8·공용 검증과08:43:20 KST 전체2GB 타입 첫 실행을 통과해 완료했다. 빌드·배포·커밋·푸시는 하지 않았다. [최종 보고서](report.md).

## 기존 문제 근거

`check-wordle-baseline.mjs --record`는 실제 read/copy/submit/practice 핸들러와 기존 통계 유틸을 합성 포트로 실행했다. 정상 빈 기록1건을 기준으로 JSON `null`·잘못된 guesses 구조2건이 통계 TypeError로 이어지고, native 실패+legacy false도 복사 성공을 표시하며, 예전 일일 도전 공개 타이머가 새 연습을 만든 뒤 이름/통계 창을 여는 문제를 재현했다. 원본 SHA와5그룹은 `before-fix.json`에 있다. 실제 공개 점수/사용자 기록은 읽거나 쓰지 않았다. 타이머 검사는 실제 이전 핸들러 closure를 실행한 제어 포트이며 아직 실제 브라우저 재현은 아니다.

## 사용자 경험

- 통계에서 최근 일일 도전30개의 날짜·성공 여부·시도 횟수를 볼 수 있게 한다. 기존에 저장된 날짜별 기록을 읽기 전용으로 보여 주며 현재 퍼즐을 과거 날짜로 바꾸지 않는다. 도전이 끝난 기록만 스포일러 없는 색상 격자를 펼치고 복사할 수 있다.
- 기록이 손상되거나 저장이 막혀도 게임 화면이 죽지 않게 한다. 기기 저장 여부를 알리고 지금 푼 내용을 메모리에서 유지한다. 아직 확인되지 않은 저장을 완료로 표시하지 않는다.
- 일일/연습·글자 수 전환·자정 뒤 이전 애니메이션이나 복사 안내가 새 판에 나타나지 않게 한다.

## 구현 계약

1. `koreanWordle-daily-v1`, settings 및 구버전 누적 통계 키/의미를 유지한다. 신규 history 저장소를 만들지 않는다. 초기 읽기0쓰기, 기본 구조와 날짜/단어 길이/유효어/최대6시도/terminal 이후 추가시도/boolean 등을 검증한다. permissive JSON cast 대신 결과 타입을 사용한다. 이상 raw는 보존하고 해당 key 자동 쓰기를 중단한다. 유효 legacy 누적 통계를 현재 기록과 중복 계산하지 않는 기존 계약을 유지한다.
2. 저장 상한은 현재 유효 legacy 최대 날짜수·내용을 측정해 결정한다. 오래된 유효 기록을 새30개 표시 한도로 잘라 저장하지 않는다. 미래/손상 항목을 자동 삭제한 결과로 원본을 덮지 않는다. settings 오류와 daily 기록 오류를 분리한다.
3. 일일 추측 append는 같은 날짜 이전 guesses를 기준으로 CAS/키 잠금/readback한다. 다른 탭과 같은 prefix면 호환 처리할지, 분기된 추측이면 현재 퍼즐/저장본을 어떤 방식으로 보여 줄지 구현 전 설계한다. 늦은 lock/저장 완료가 현재 모드/날짜/입력을 바꾸지 않는다. 잠금 없는 환경의 원자성을 과장하지 않는다.
4. 유효 제출의 결과 확정과 애니메이션을 분리한다. 완료된 판의 성과 기록은 판별 토큰으로 한 번만 처리하되, 단순히 판을 바꿨다는 이유로 이미 끝난 판의 기록을 잃지 않게 한다. 이름 입력/축하/통계 자동 열기는 여전히 해당 판을 보고 있을 때만 한다. 이전 공개·shake·bounce·toast·copied timer는 새 판/자정/새 결과/언마운트에 영향을 주지 않는다. Strict replay와 빠른 중복 Enter를 포함한다.
5. 일일 정답의 KST 날짜 기준과 현재 사전/정답 순서/하드 모드/색약 모드/두벌식 조합·채점/통계 수학은 변경하지 않는다. 자정 직전 제출은 클릭 시점의 날짜·판 스냅샷으로 소유한다. 새로운 날짜가 되어도 전날 타이머가 오늘 입력 잠금을 풀지 않는다.
6. 기록 패널은 최신30개만 렌더하고 전체 누적 통계는 기존 유효 기록 전체를 사용한다. 완료된 과거 기록 공유는 날짜·도전 번호·횟수·색상 격자만, 실제 정답/추측 텍스트는 포함하지 않는다. 모달·색약·언어 전환을 명시 scope로 묶는다. 일일 정답을 정적 HTML에 새로 넣지 않는다.
7. 현재/과거 결과 복사와 공용 ShareResult의 요청 소유권을 연결한다. native 또는 legacy true만 성공, 실패하면 전체 readOnly 격자와 선택/재시도/닫기를 제공한다. input/locale/contrast/선택 날짜 A→B→A에서도 옛 성공/실패가 부활하지 않도록 실제 token으로 표시한다. OS에 이미 제출한 Clipboard 작업 자체를 취소한다고 말하지 않는다.
8. 이름 입력/명시 리더보드 제출 payload·성공 조건은 유지하고 실제 테스트에서는 공개 RPC를 가짜 포트로 막는다. 모바일44px/한글 입력/키보드 모달/320px KOEN, motion 감소 설정도 검사한다. 구현 컴포넌트와 KOEN fragment는 동일 담당, canonical/meta는 통합 담당만 수정한다.

## 검증

기존 `check-korean-wordle.ts` 회귀 + strict legacy parser·기록 집계·최근30projection·spoiler-free 결과 oracle, 저장/CAS/지연락/unknown write·두탭 분기, 실제 부모 late reveal·새연습·자정·중복제출·타이머와성과1회, 현재/과거/ShareResult 교차복사·A-B-A를 확인한다. 독립 검토 후 단일 Chrome에서 합성 두 탭·native Clipboard·모바일 KOEN·실제 타이머 흐름을 검증한다. 빌드·배포·실제 공개 점수 제출은 실행하지 않는다.
