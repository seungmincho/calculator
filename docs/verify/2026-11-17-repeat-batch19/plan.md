# 19차 준비 계약 — 문서 비교 응답성·마크다운 복사 복구

2026-11-17 KST. [코드 조사](../../handoff/2026-11-17-document-tool-candidates.md)에 근거한 후속 기존 도구 개선이다. 18차 공용 번역 복원을 완료한 뒤 부모 UI를 연결하며, 그 전에는 충돌하지 않는 순수 도메인 설계만 준비한다. 새 경로·패키지·서버·자동 원문 저장은 추가하지 않는다.

## A. 텍스트 비교

- 입력한 두 문서를 사용자가 ‘비교’할 때 확정한다. 이후 편집하면 결과가 이전 입력 기준임을 표시하고 재비교할 수 있게 한다. 입력 중 매 키마다 전체 비교를 다시 계산하지 않는다.
- LCS 계산은 Worker에서 수행한다. 공통 앞/뒤 줄은 먼저 분리하고 남은 계산의 작업량을 제한한다. 초기 상한은 문서당 UTF-8 1MiB·10,000줄, 남은 DP 셀 4,000,000개로 검증한다. 실제 측정에 따라 바꾸면 사유와 최종 한도를 보고서에 기록한다. 한도 초과·Worker 실패를 결과 없음/같음으로 표시하지 않는다.
- 비교 중 취소, 새 비교, 원문 편집, 좌우 교체, 전체 초기화, 언마운트 시 이전 요청의 결과/오류/로딩 종료가 최신 상태를 바꾸지 않게 한다. Worker를 사용할 수 없으면 이유를 알리고 메인 스레드의 무제한 계산으로 되돌리지 않는다.
- 전체/변경된 줄만 보기와 줄 번호, 추가·삭제·유지 개수를 제공한다. 변경 보기로 필터해도 통계와 내보내기 원문 기준을 혼동하지 않는다. 한글·빈 줄·CRLF/LF·마지막 개행의 비교 정책을 명시한다. HTML처럼 보이는 텍스트는 실행하지 않는다.
- 기존 텍스트 결과 복사의 실제 성공/실패를 구분하고 실패 시 선택 가능한 결과 텍스트를 제공한다. 명시적 텍스트 다운로드를 추가하며, 현재 결과와 파일 내용이 일치해야 한다. 이를 다른 프로그램에 바로 적용 가능한 표준 patch 파일이라고 표현하지 않는다.
- 토큰 스타일·16px 입력·44px 제어·320px 레이아웃을 유지한다. 의미 있는 예제의 첫 결과가 보이게 하되 사용자가 입력한 두 원문을 자동 교체하지 않는다.

검증: 순수 비교의 원문 재구성/중복 줄/비대칭/빈 문서/개행 경계, 작업량 상한, 실제 Worker의 연속 취소·실패·오래된 응답, 큰 동일 문서와 작은 수정, 모바일 입력/필터, 실제 다운로드 내용, 복사 실패 복구. 결과 배열의 합으로 왼쪽/오른쪽 원문을 각각 재구성하는 검사를 포함한다.

## B. 마크다운 복사 및 파일 읽기 복구

- Markdown·HTML 텍스트·서식 복사의 Clipboard 거부/API 없음/execCommand(false)를 성공으로 표시하지 않는다. 서식 복사 실패에는 현재 Markdown/HTML 텍스트를 직접 선택할 수 있는 대안을 제공하며, 텍스트 대안을 서식 복사 성공이라고 표현하지 않는다.
- 진행 중 원고 변경/다른 복사/언마운트 후 늦게 완료한 복사가 오래된 성공 안내나 복구 텍스트를 노출하지 않는다. 수동 대안은 원문을 고칠 수 있는 새 편집기가 아닌 읽기 전용 선택 영역이다.
- 텍스트 파일 열기는 명시 선택으로만 시작하며, 파일 크기 상한·읽기 오류·늦은 완료를 처리한다. 새 파일 선택이나 원고 편집 뒤 이전 읽기가 덮어쓰지 않게 한다. 파일 최대 1MiB로 시작하고 텍스트 형식은 기존 md/markdown/txt를 유지한다. 파일 열기 취소는 현재 원고를 보존한다.
- 이미지 삽입의 기존 2MiB 제한과 자동저장·미리보기·md/html 다운로드를 유지한다. 이미지 읽기 경합이 원고를 덮는 경우에는 같은 세대 가드 범위에서 보완하되 렌더러/이미지 포맷을 교체하지 않는다.

검증: 세 복사 형태의 성공/거부/대체 API false, 오래된 비동기 완료, 모바일 수동 선택, 파일 크기·읽기 실패·두 파일 역순 완료·읽는 동안 편집·언마운트, 저장과 다운로드의 현재 원문 보존.

## 진행 경계

제품 담당은 해당 UI와 ko/en 번역 조각을 함께 작성한다. 공용 messages·메타·생성물은 통합 담당이 편집한다. 독립 검토 및 브라우저 검증 후 Chrome을 닫고 전체 타입 검사를 한 번 실행한다. 18차와 동시에 공용 번역기를 수정하거나 부모 연결을 변경하지 않는다. 빌드·배포·커밋·푸시는 실행하지 않는다.
