# 19차 브라우저 검증 계획

기존 localhost:3039, 격리 Chrome 한 인스턴스, 순차 실행. 제품 연결·번역 final ready 후 실행하고 완료 시 Chrome을 닫아 통합 담당에게 타입 검사 가능 신호를 준다. 제품 파일·dev 서버·빌드·배포는 수정하지 않는다.

| 범위 | 시나리오와 실제 근거 |
| --- | --- |
| Diff 정상 | 실제 Worker bundle/메시지로 한글·빈 줄·개행 경계·HTML처럼 보이는 원문 비교. 결과 행으로 양쪽 원문을 독립 재구성하고 실제 TXT/OS clipboard 확인 |
| Diff 확정 입력 | 결과 뒤 입력 편집 시 이전 기준 안내, 복사/다운로드는 이전 확정 결과. 명시 재비교 후 최신 결과 |
| Diff 큰 문서/페이지 | 큰 동일 문서와 작은 변경을 실제 Worker로 완료. 200행 페이지·변경 필터가 전체 통계/내보내기를 바꾸지 않음 |
| Diff 한도 | 1MiB UTF-8·10,000줄·남은 DP 상한 초과를 같음으로 표시하지 않고 원문/이전 결과 보존 |
| Diff 취소/실패 | 실제 Worker 시작을 지연시켜 취소·편집·새 비교·교체/초기화. Worker 미지원·번들 실패는 안내하고 회복. 시간 초과/늦은 콜백 주입은 실제 계산과 구분 |
| Diff 복사 | native 성공, API 거부/대체 false·수동 전체 선택, 늦은 거부 이후 입력 변경으로 오래된 복구 표시/대체 실행 차단 |
| Diff 모바일/영어 | 320px 다크, 입력16px/버튼44px, 표 내부 스크롤·원시 키 없음·영어 전환 |
| Markdown native | Markdown·HTML 텍스트·서식 복사를 실제 Clipboard API로 읽어 payload와 타입 확인. OS 앱 붙여넣기까지 검증했다고 주장하지 않음 |
| Markdown 실패 | 세 복사 거부/대체 false, 읽기 전용 수동 영역과 전체 선택, rich 대안 형식 전환, 명시 재시도 |
| Markdown 늦은 복사 | API 없음/대체 true/false, 진행 중 편집·다른 복사·언마운트 이후 늦은 성공/거부 무효화 |
| Markdown 파일 | 실제 작은 md/txt 선택·파일 상한/형식 오류. FileReader 역순 완료·읽는 중 편집·취소·읽기 오류를 제어하여 원고 보존 |
| Markdown 기존 동작 | 실제 md/html 다운로드, 이미지2MiB 경계·늦은 이미지 읽기, 자동저장·미리보기·18차 영어 예제와 같은 사용자 원고 보존 |
| Markdown 모바일/영어 | 320px 다크에서 실패/수동 선택의16px·44px·레이아웃 및 영어 표시 |

실제 Worker/Clipboard/FileReader/다운로드 결과와 오류 주입·모의 지연을 보고서에서 분리한다. JS/hydration 오류와 외부 요청 차단을 수집하고, 제품 결함은 담당에게 전달한 후 영향 사례만 재검사한다.
