# 43차 실행 계약 — 단위 변환 여러 값 한 번에

상태: 로컬 구현·자체29·독립15그룹·실제 Chrome7/7·공용 검증과08:43:20 KST 전체2GB 타입 첫 실행을 통과해 완료했다. 빌드·배포·커밋·푸시는 하지 않았다. [최종 보고서](report.md).

## 확인한 사용자 흐름

`UnitConverter.tsx`는 한 값의 양방향 단위·전체 변환표·즐겨찾기 조합·최근8개·공유를 이미 제공한다. `units.ts`의 convert/formatNum/parseInput을 재사용한다. 여러 측정값이나 레시피 수량을 같은 단위로 변환하려면 현재는 한 값씩 입력·복사해야 한다. 기존 즐겨찾기나 전체 단위표를 다시 만드는 작업은 아니다.

## 최소 구현

- 현재 단위 조합 옆에 `여러 값 변환` 진입을 제공하고 한 줄에 숫자 하나를 받는다. 최대1,000개 물리 행·50,000 UTF-16 code units, 초과는 원문을 자르지 않고 안내한다. 이 한도는 신규 기능의 범위이며 기존 단일 입력 제한으로 확장하지 않는다.
- 명시적 변환 버튼이 원문·category/from/to/유효숫자/CSS rem 기준을 캡처한다. 결과는 행 번호·원문·변환 값·오류로 구성한다. 빈 줄은 빈 행으로 보존하고 0으로 계산하거나 다른 행과 합치지 않는다. 마지막 줄바꿈 처리와 행 수는 구현 전 명시한 fixture로 고정한다.
- 숫자 하나의 해석은 기존 parseInput과 일치시킨다. 쉼표는 천 단위 표기이며 CSV 열 구분자가 아니다. 탭이 있는 행은 여러 열을 붙여 숫자로 바꾸지 않고 별도 오류로 안내한다. 잘못된 한 행 때문에 나머지 유효 행을 버리지 않는다.
- convert 결과가 비유한 값이면 해당 행을 계산 불가로 표시한다. 음수·지수 표기·온도 offset·연비 역수·CSS rem/px를 기존 엔진 의미대로 보존한다. 전통 단위 요약 탭은 특정 한 쌍이 없으므로 먼저 개별 조합을 선택하도록 연결한다.
- 처음200행 미리보기와 전체/정상/오류 수를 표시하고 전체1,000행 복사·CSV를 제공한다. 반출은 실행 당시 snapshot과 같은 단위·정밀도·원문이다. 현재 편집이 달라지면 이전 결과임을 분명히 보여 주고 다시 변환할 수 있다.
- CSV는 BOM·따옴표·개행·수식 안전 처리를 갖추고 원문/오류 행을 조용히 빼지 않는다. 전체 TSV 복사 실패는 클릭 당시 전체 텍스트 선택·재시도를 제공한다. 기존 단일 결과/전체표/ShareResult와 복사 소유권을 연결해 늦은 안내가 새 동작을 덮지 않게 한다.
- 일괄 원문은 URL·localStorage·최근 변환·서버에 추가하지 않는다. 기존 단일 값 URL/즐겨찾기/최근값의 의미를 유지한다. 새 저장소·의존 패키지·Worker는 첫 범위에 필요 없다.

## 파일 소유와 완료 기준

제품 담당은 `UnitConverter.tsx`, 신규 `UnitBatchConverter.tsx`, `unitBatch.ts`와 반출/복구 모듈, KO/EN fragment를 함께 소유한다. canonical 번역·가이드/메타/updatedDate와 생성물은 통합 담당만 쓴다. 기본값 결과·320px16px입력/44px버튼·명시적 현재 단위 요약·design tokens를 유지한다.

1. 기존 check-units 회귀와 별도 산술 기대값으로 선형/offset/역수/CSS, 음수/0/지수/빈 행/한도/overflow/반올림을 확인한다. 최대 행의 전체 CSV/TSV와 미리보기 수를 구분한다.
2. 실제 부모에서 즐겨찾기 변경/단위 swap/정밀도/locale A-B-A, 실행 후 원문 편집, 기존 복사↔일괄↔ShareResult 요청 경합, 초기가져오기/URL unknown query·hash·history 보존을 검사한다.
3. 독립 검토와 실제 Chrome의 paste/CSV/Clipboard/320 KOEN 후 범위 lint·번역·전체 타입을 완료한다. 실제 모바일 기기·통계상 사용 빈도는 이 코드 조사로 검증했다고 표현하지 않는다.

첫 화면의 단일 변환 경험은 유지하고, 여러 측정값을 옮기는 반복 작업을 줄이는 것이 이 후보의 목적이다.
