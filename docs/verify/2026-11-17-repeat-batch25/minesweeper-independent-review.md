- 담당: team_rotation. 제품 파일 수정 없음. 26B 미연결 준비 TS도 편집 중지 상태.

## 확인 범위

1. 별도로 계산한 5×5 인접 수/확산 결과와 실제 유틸을 비교했다. 첫 칸 자동 열기로 24개 안전 칸을 모두 여는 배치는 즉시 승리하며 시간·클릭·표식이 0이다. 복습의 배열을 변경해도 원본 스냅샷과 최초 배치는 변하지 않는다.
2. 실제 부모의 일반 패배와 일반 승리 뒤 반복 복습을 실행했다. 첫 칸과 열린 칸, 지뢰 위치를 보존하고 표식·물음표·폭발·시간·클릭을 초기화한다. 첫 유효 후속 행동에서만 시계를 시작한다. 복습 승패 전후 기록/BEST/DAILY/설정/업적 저장 바이트가 같고 생성·업적·점수 판정·제출·이름 저장·리더보드 갱신이 추가 호출되지 않는다.
3. 일반 승리의 BEST와 점수 모달은 계속 작동한다. 복습 전 모달의 오래된 제출은 실행되지 않는다. 정상 게임에서 이미 시작된 모의 제출은 한 번만 수행하며, 그 응답 전에 복습으로 전환하면 이후 이름 저장이 실행되지 않는다.
4. 실제 부모의 사용자 지정 5×5·지뢰 1개 배치를 네 번 복습했다. 첫 자동 열기만으로 승리해도 시간과 클릭은 0이며 기록·모달·배치 재생성이 추가되지 않는다.
5. 이전 터치 타이머와 같은 pointerId를 재사용한 오래된 이벤트가 복습 또는 현재 타이머를 변경하지 않는다. 현재 길게 누르기는 깃발을 설정하고 뒤따르는 클릭을 억제한다. IME keyCode 229와 언마운트 뒤 오래된 콜백도 상태를 변경하지 않는다.
6. 같은 일반 모드·같은 난도 선택과 새 게임은 복습을 종료한다. 일일 모드의 일반 패배 기록은 유지하고 복습 버튼은 표시하지 않는다. 일반 모드 복귀는 빈 배치로 시작하며 URL 모드 값도 정리한다.

## 검증 방식과 한계

실제 부모 컴포넌트와 실제 보드 동작/복습 유틸을 실행하고 생성 시드·시계·저장소·포인터·모달·리더보드 포트만 제어했다. 리더보드 제출은 메모리 포트이며 실제 네트워크 요청은 throw로 금지했다. DOM 배치·실제 터치·브라우저 시계 렌더링은 이 검사의 주장이 아니며 브라우저 담당의 별도 결과와 구분한다.

물음표 표시가 있는 칸의 기존 접근성 라벨은 지뢰 표시보다 물음표를 우선한다. 따라서 전체 지뢰 위치 비교는 복습으로 표식을 지운 뒤 다시 패배시켜 수행했고, 물음표 초기화는 별도로 확인했다. 이 기존 라벨 우선순위를 새 복습 기능의 결함으로 확대하지 않았다.
