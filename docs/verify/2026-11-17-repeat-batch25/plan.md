# 25차 준비 계약 — 저장 원고의 줄 비교·같은 지뢰판 연습

2026-11-17 KST. [원고 연결 조사](../../handoff/2026-11-17-writing-diff-handoff-candidate.md)와 [지뢰찾기 조사](../../handoff/2026-11-17-minesweeper-replay-candidate.md)를 다음 기존 도구 개선으로 채택한다. 24차 브라우저·전체 타입 검사 통과 뒤, 준비한 순수 로직을 실제 부모에 연결하는 구현을 시작했다. 25차는 아직 최종 검증 전이다.

## A. 글자수 저장 버전에서 텍스트 비교로 보내기

기존 글자수/원문 나란히 보기를 유지하고, 저장한 버전과 현재 탭의 글을19차 Diff 도구로 전달하는 명시 버튼을 추가한다. 비교 대상은 클릭 당시 snapshot이며 원래 편집 탭/저장 목록을 변경하지 않는다. 충돌/손상 목록에서는 현재 저장본이라고 전달하지 않는다.

- 별도 v1 두 문서 payload/key, 최대50,000자/문서,10분 만료로 제한한다. 이름/출처도 제한된 문자열만 사용한다. 빈 원문은 유효한 비교다. 실제 Diff의1MiB/10,000줄/DP 한도는 그대로 적용한다.
- 사용자 클릭 안에서 새 about:blank 탭을 열고 그 탭의 sessionStorage에 쓰기/읽기 확인→opener 제거→대상 경로 이동을 수행한다. 원문을 URL·localStorage·로그·서버로 보내지 않는다. 기존 OCR/Notepad→TTS v1에는 손대지 않는다.
- 대상은 명시된 source로 들어온 유효 payload만 한 번 확인하고 두 문서를 보여 준다. 사용자가 비교 버튼을 눌러야 Worker를 실행한다. 이미 입력을 수정했거나 소비한 뒤 재렌더/언어 변경으로 다시 적용하지 않는다. 삭제는 읽은 raw가 현재 값과 같을 때만 한다.
- 팝업/저장소 차단 시 새 실패 탭을 정리하고 원래 탭을 보존한다. 만료/미지원/미존재 링크에서도 기본 Diff를 사용할 수 있게 한다. 원문이 담긴 공유 링크라고 표현하지 않는다.

검증: 실제 양쪽 원문 일치·소스 탭/저장 bytes 불변, 차단/만료/역순 payload/새 값 삭제 방지, 대상 편집 뒤 재적용 금지, 실제 Worker/TXT와 복사 복구, 기존 TTS 전달 회귀, KO/EN·320px.

## B. 지뢰찾기 종료한 클래식 판 다시 풀기

종료한 클래식 판에 ‘같은 판 연습’을 추가한다. 현재 방문의 원 배치·크기/지뢰 수·최초 연 칸·noGuessFailed를 보관하고 새 난수로 만들지 않는다. 일일 도전 모드·기록·공유는 첫 범위에서 변경하지 않는다.

- 같은 안전한 시작 칸을 자동으로 연 새 상태를 만들고 깃발/물음표/실패 칸/클릭/시간은 초기화한다. 첫 후속 조작부터 시간을 잰다는 정책을 보여 준다. 시작 칸의 펼침만으로 완성되는 작은 판도 즉시 완료 상태로 처리하고 멈춘 ready 상태로 남기지 않는다.
- 연습 상태를 분명히 표시하고 개인 최고/업적/공개 리더보드/이름 제출 모달에 반영하지 않는다. 승패의 시각·소리 피드백은 유지할 수 있다. 새 판·난도·모드 변경은 일반 흐름으로 돌아간다.
- 재연습을 반복해도 원본 배치 배열을 변이하지 않는다. 종료 전 판에서 재연습 버튼을 제공하지 않으며, 이전 길게 누르기 타이머/지연 포인터가 새 판을 조작하지 않게 입력 세대를 무효화한다. 기존 키보드·마우스·터치 조작은 유지한다.
- 새 장기 저장/배치 URL/힌트/자동 풀이/난수·무추측 알고리즘 변경은 없다. 클라이언트 연습 UI의 기록 제외이며 서버의 부정행위 방지까지 구현했다고 주장하지 않는다.

검증: 원본/재연습 배치·최초 칸 동일성, 자동 펼침 완료 경계, 깃발/시간/실패/반복 재연습, 난도/일일 왕복, 일반 승리 기록 회귀와 연습 비반영, 늦은 포인터·키보드·320px. 리더보드 전송은 mock으로 차단해 실제 서비스에 테스트 점수를 쓰지 않는다.

## 공통

새 경로·서버·패키지 없이 기존 도구를 연결한다. 제품 담당이 UI와 ko/en 조각을 같이 쓰고 공용 원본/메타/생성물은 통합 담당에게 전달한다. 순수/실제 부모·독립·단일 Chrome 검증 뒤 Chrome 종료·TS 작성 정지·메모리 확인·전체 타입 검사로 완료한다. 빌드·배포·커밋·푸시는 실행하지 않는다.
