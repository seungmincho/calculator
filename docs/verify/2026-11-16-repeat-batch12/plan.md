# 12차 실행 계약 — 모임·식사·메모의 다음 사용

2026-11-16. 연속 개선 큐13~15. 사용자에게 이미 승인된 기존 도구 개선의 마지막 묶음이다. 11차 팀 명단 작업과 13은 같은 담당이 순차 진행한다.

## 13 팀 나누기: 오늘 참석자

현재 전체 이름 목록은 유지하고 참석 여부만 따로 선택한다. 기본은 전원 참석. 명단 각 행에 접근 가능한 참석 체크, 전체/참석 인원 수, 전원 참석/선택 해제를 제공한다. 삭제 버튼과 참석 체크의 의미를 분리한다. 명단 불러오기·일괄 입력·프리셋 변경은 전원 참석으로 시작하며 개별 추가도 참석으로 추가한다. 출석은 현재 화면에서만 유지하며 저장 명단을 덮지 않는다.

랜덤/실력 균등/팀장 모드와 이전 조합 줄이기는 참석자만 사용한다. 참석 변경은 이전 팀 결과·잠금·드래프트·되돌리기를 기존 resetBoard로 정리해 빠진 사람이 다시 결과에 나오지 않게 한다. 편성/드래프트 도중 변경은 막는다. 참석자가 팀 수보다 적으면 원인을 보여주고 실행을 막는다. 팀장 모드는 참석한 순서에서 팀장을 고른다. 명단 저장/갱신/백업에는 전체 이름·능력치를 남긴다. 공유 결과는 실제 편성된 참석자만 포함한다.

## 14 메뉴 룰렛: 앞으로 먹을 7일 계획

실제 /menu-roulette/의 컴포넌트는 `DecisionTools.tsx`이며 `MenuPicker.tsx`와 다르다. 기존 MealHistoryPanel은 먹은 기록이므로 별도 계획 패널을 추가한다. 한 날짜에 메뉴 하나를 정하는 7일 계획이라고 설명한다. 기본 시작일은 기기 현지 오늘, 사용자가 시작일을 바꿀 수 있고 날짜별 메뉴를 직접 편집한다.

`빈 날 채우기`는 현재 룰렛 후보에서 고르며 이미 채운 날을 바꾸지 않는다. 후보 이름을 중복 제거하고 해당 주에 이미 사용된 메뉴를 빼서 가능한 만큼만 채운다. 후보가 부족하면 반복 메뉴로 몰래 채우지 않고 남은 빈 날과 후보 부족을 설명한다. 계획 생성은 먹은 기록·룰렛 결과에 영향을 주지 않는다. 변경한 날짜를 명시적 저장 버튼으로 저장하고 다른 주 날짜는 보존한다. 저장 날짜는 최대90개, 메뉴80자, 버전/날짜/중복 날짜 검증·CAS/readback·Web Locks 패턴을 사용한다. 손상/가득 참/저장 실패에서 기존 내용을 보존한다.

현재 주 복사/TXT 내보내기, 저장 계획의 날짜별 제거를 제공한다. 계획의 날짜가 오늘 이하일 때만 명시적 `먹은 기록에 추가`를 제공하며 기존 addMeal의 저장 성공을 확인한 뒤 성공을 안내한다. 이미 같은 날짜/메뉴가 있으면 중복 안내. 계획은 남긴다. 미래 계획을 먹은 기록으로 자동 추가하지 않는다. 메뉴는 건강/영양 추천이 아니라 사용자가 정한 후보에서 선택하는 도구임을 유지한다.

## 15 음성 메모: 선택한 전사문 묶어 내보내기

현재 녹음 목록에서 전사문이 있는 항목을 선택한다. 최대20개·각12,000자·합계240,000자를 명시한 TXT 묶음 다운로드. 제목·기기 현지 녹음 시각·길이·구분선·현재 편집 중인 전사문을 포함한다. 선택한 순서 대신 화면과 같은 최신순으로 고정해 순서가 예측 가능하게 한다.

음성 Blob을 새로 복사하거나 ZIP으로 묶지 않는다. 기존 개별 음성 다운로드·전사·이름 편집·기기 저장·검색·회의록 연결은 보존한다. 선택 UI는 현재 검색 결과의 전체 선택/해제를 지원하고 검색 밖 선택 개수도 보여줘 누락을 숨기지 않는다. 삭제/전사 비우기 시 선택을 제거하거나 내보내기 직전 유효성을 검사한다. 빈 전사와 오류 항목을 몰래 누락해 성공으로 표시하지 않는다. 버튼은 녹음/전사/저장 작업 중 기존 busy 정책을 따른다. 다운로드 실패를 완료로 표시하지 않는다.

각 담당은 제품 코드·도메인 검사·ko/en 번역 조각을 함께 소유한다. 공용 메시지/메뉴/페이지는 통합 담당, 실제 모바일·회귀 검증은 별도 담당이다. 빌드/배포/커밋/푸시는 하지 않는다. 15개 완료 시 전체 결과와 미검증 한계를 기록하고 사용자가 검토할 수 있는 체크포인트를 제공한다.
