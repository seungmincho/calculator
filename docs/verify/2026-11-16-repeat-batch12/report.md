참석 변경은 기존 결과·고정·드래프트·되돌리기를 초기화하고 편성 중 변경을 차단한다. 명단 불러오기·일괄 입력은 전원 참석으로 시작하며 개별 추가도 참석 상태다. 오늘의 참석 여부는 저장 명단을 덮지 않는다.

메뉴 계획은 `/menu-roulette/`의 실제 부모 `DecisionTools`에 연결했다. 현재 룰렛 후보의 중복과 이미 채운 메뉴를 제외해 빈 날만 채우며 후보 부족을 반복 메뉴로 숨기지 않는다. 주 이동 중 초안을 보존하고 저장 시 다른 주의 날짜도 보존한다. 오늘 이하 날짜만 명시적으로 먹은 기록에 추가할 수 있으며 실제 저장 성공·동일 날짜/메뉴 중복을 확인한다. 계획 생성·저장이 룰렛 결과나 식사 기록을 자동 변경하지 않는다.

전사문 선택은 검색 결과 전체 선택/해제와 검색 밖 선택 개수를 표시한다. 선택 중 일부가 삭제·빈 본문·잘못된 데이터가 되면 몰래 제외해 성공으로 처리하지 않는다. 도메인 검사에서 오디오 Blob getter를 강제로 실패시켜도 TXT 내보내기가 성공해 오디오 미접근을 확인했다. 녹음·전사·기기 저장 중에는 기존 busy 정책을 따른다.

## 독립 검사와 최종 통합

세 번역 조각을 병합한 ko/en 신규 73키·5개 컴포넌트 정적 사용 252개에 누락이 없다. 팀·메뉴·음성 설명과 기능 목록을 갱신하고 updatedDate 2026-11-16을 유지했다. 320px 다크·실제 파일·복사 실패·기존 기능 회귀를 독립 브라우저에서 확인했고 JavaScript/hydration 오류와 페이지 가로 넘침은 0이다.

참석자 담당 도메인 검사는 선택·랜덤/실력/팀장 순서·재편성 고정·공유·전체 명단 저장/백업·200명 경계를 확인했다. 메뉴·전사문 [독립 검토](independent-review.md)는 12그룹(월말 2,411주·선택 24순열 포함)을 통과했다. [참석자 교차 검토](attendance-independent-review.md)도 독립 9그룹·기존 보드/명단/백업/회전/균등 회귀를 통과했다. 두 검토 모두 재현 가능한 미해결 결함이 없다.

실제 참석자 백업은 전체 6명을, 공유 링크는 참석한 4명만 보존했다. 메뉴의 7일 TXT와 클립보드를 대조했고 후보 2개에서 나머지 5일을 비워 부족을 안내했다. 전사문 TXT는 UTF-8 BOM·최신순·기기 현지 시각·길이·미저장 편집 본문을 바이트로 확인했다. 검색 밖 선택·기존 IndexedDB와 WAV Blob·개별 다운로드를 보존했고 Chrome 가상 마이크의 실제 MediaRecorder 녹음/일시정지 중 작업 차단도 확인했다. 11개 사례는 첫 실행에서 모두 통과했다.

모든 브라우저를 종료하고 23:34 KST에 전체 타입 검사를 2GB heap으로 단독 실행해 exit0을 확인했다(직전 여유 5.54GiB). messages 생성/검사 796개 일치, namespace apply 추가 0·audit 미해결 0(기존 동적 안내 60개), 공용 범위 lint와 JSONPath 수정 범위 lint, RSS 382개·redirect 472개·llms 315개 도구 생성, `git diff --check`를 통과했다.

공용 번역기의 기존 한국어 전용 제약은 유지한다. 실제 모바일 기기·실제 사용자 마이크·ASR 모델 다운로드/전사 품질·정적 export·배포는 확인하지 않았다. Web Locks 미지원 환경의 원본 비교·쓰기 확인은 완전 동시 쓰기의 원자성을 보장하지 않는다. 빌드·배포·커밋·푸시를 실행하지 않았다.
