- 참석자 체크를 끈 이름은 전체 명단에 남고 균형 편성·회전·공유 결과에서 빠진다. 실제 백업 JSON은 전체6명, 공유 링크 복원은 참석4명을 정확히 담았다. 참석 변경 시 결과/고정/회전/되돌리기 초기화, 팀장 후보 순서, 인원 부족, 명단 불러오기와 편성 중 입력 잠금도 확인했다.

- 전사문 TXT 실제 바이트에서 UTF-8 BOM, 최신순, 현지 시각 UTC+09:00, 길이, 미저장 편집 본문을 확인했다. 검색 밖 선택도 파일에 포함됐고 기존 IndexedDB 및 WAV Blob 바이트는 그대로였다. 개별 음성/글 다운로드도 원본과 대조했다. 빈 전사문·삭제된 선택은 전체 다운로드를 거부하고,20개 초과 및 실패 재시도도 검증했다. Chrome의 가상 마이크로 실제 MediaRecorder 녹음·일시정지 중 선택/내보내기 잠금을 확인했다.
- 세 도구의320px 다크 캡처를 시각 검토했다. 문서 가로 넘침0, 줄바꿈과 입력/버튼 배치가 읽을 수 있는 상태다. ko/en 추가 번역 구조는 대조했으며 language=en 저장 상태에서도 기능을 확인했다. 기존 공통 i18n 레지스트리는 한국어 전용이므로 실제 영어 UI 전환을 검증했다고 주장하지 않는다.
