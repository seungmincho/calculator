# 15차 수능 등급 계산 기준 정리

2026-11-17. 사용자 승인된 기존 도구 개선. 담당: `gpa_scenarios`. 제품 구현·자체 검사 완료이며 독립 브라우저 결과와 공용 통합은 각 담당자가 별도로 기록한다.

## 바뀐 동작과 유지한 범위

- 첫 화면 `#csat-grade-context`에서 **2027학년도 시험**과 **2026학년도(2025년 시행) 상대평가 참고 자료**를 구분한다. 2027학년도 컷은 계산기에 반영되어 있지 않다고 명시한다.
- `#csat-grade-result`, 공유 이미지의 라벨·보조 문구·과목별 행, 공유 텍스트에도 기준 학년도와 추정 여부를 남긴다. 영어·한국사는 절대평가로 구분한다.
- `#csat-grade-cut-table`은 상대평가에서 원점수 추정 컷·참고 등급 구분 표준점수·명목 누적 비율을 구분한다. 절대평가 표에는 원점수 기준만 표시한다. 명목 누적 비율과 실제 응시자·동점자 비율을 동일하게 설명하지 않는다.
- 표준점수·백분위는 전년도 참고점 사이의 단순 보간이며 공통·선택 점수 조정이나 올해 성적 분포를 재현하지 않는다고 설명한다.
- 등급 평균은 탐구 2과목 평균, 수능최저 참고 합계는 탐구 상위 1과목을 쓴다는 차이를 명시한다. 수능최저 결과를 입력 기준과의 참고 비교로 표현하며 대학별 영역 지정·탐구 반올림·한국사 조건 또는 합격 판정으로 표현하지 않는다.
- 올해 시험·채점 제도 공식 안내의 직접 링크와 확인일을 추가했다. 이 자료가 기존 2026 원점수 추정 표 전체를 보증하는 것으로 연결하지 않는다.
- 날짜 계산은 기기 시간대와 무관한 KST로 맞추고 1분마다 갱신한다. 과목별 모바일 행을 줄바꿈하고 입력·선택은 16px, 버튼·선택·입력은 44px 최소 높이를 사용한다.
- 독립 브라우저에서 비기본 공유 URL의 초기 결과(서버 2.25 vs 클라이언트 1.25) 때문에 hydration 경고가 재현됐다. 공용 훅은 유지하고 이 컴포넌트에 `useHydrated`와 한 번의 URL 복원, 복원 완료 전 URL 동기화 가드를 추가했다. 첫 렌더는 기본값으로 일치하며 이후 점수·선택과목·등급 합 설정을 복원한다.

숫자 계산, 선택과목 매핑, 현행·구형 공유 쿼리, 등급 평균과 합계 공식은 유지했다. 새 컷·학교별 예측·저장 형식을 추가하지 않았다. 현재 `CsatGrade`에는 별도 로컬 저장이 없으며 D-day 답안 저장은 이 변경의 대상이 아니다.

3. [평가원 2027학년도 Q&A 자료집, 인천교육청 게시 PDF](https://www.ice.go.kr/upload/ice/na/bbs_1482/2026/04/b38c68a1f07bfba215f2107e1e040910.pdf): 검색 색인에서 절대평가·성적통지표 설명을 확인했다. 작성자 웹 도구의 PDF 직접 열기는 시간 초과였다. 독립 리뷰 담당 `writing_versions`가 PDF 30쪽에서 영어 90·80…20·0, 한국사 40·35…5·0 기준을 직접 확인하고 기존 CUTS와 일치함을 전달했다.
4. [대입정보포털 어디가 성적통지표 안내](https://www.adiga.kr/uve/faq/conseFaqAjax.do): 2027학년도 통지표 예시와 상대평가 표준점수·백분위·등급, 절대평가 등급만 제공, 국어·수학의 공통·선택 점수 조정 설명을 검색 결과에서 대조했다. 이 페이지는 여러 FAQ를 반환하는 주소이므로 제품 링크는 교육부·평가원 자료를 사용했다.

**수록된 2026 상대평가 표 전체 숫자의 평가원·종로 원문 대응은 이번에 재검증하지 않았다.** 원래 주석·번역의 “확정 컷/공식 발표치” 단정을 제거하고 참고 자료로 표시했다. 숫자는 원래 값과 동일하게 유지했다. 올해 기준 공식 성적을 예측할 수 없다는 문구와 선형 보간·수능최저 범위 설명은 공식 자료와 현행 계산 구현을 대조한 제품 해석이다.

## 파일

- `src/components/CsatGrade.tsx`: 기준 안내, 공유·표·가이드 연결, KST 갱신, 입력 크기·모바일 줄바꿈.
- `src/utils/csatGrade.ts`: 출처·보간 주석 정리, 순수 `csatToday(now)` 추가. 기존 CUTS·계산 함수 값 유지.
- `scripts/check-csat-grade-context.ts`: 데이터 보존·날짜·절대평가 경계·계산 가정·실제 React SSR·공유 props 검사.
- `docs/verify/2026-11-17-repeat-batch15/translations-grade.json`: ko/en `csatGrade` 하위 병합 조각. 원본·생성 메시지와 페이지 메타데이터는 `batch5_integrate`만 편집한다.

메타데이터에도 “2027 시험 / 2026 참고 원점수 추정 컷 / 올해 실제 성적 아님”을 맞추고, 기존 표 전체의 공식 원문 검증을 주장하지 않도록 공용 통합 담당자에게 전달했다.

## 검증

- `node scripts/check-csat-grade.ts`: 기존 계산 회귀 PASS.
- `node scripts/check-csat-grade-context.ts`: **13그룹 PASS**. 24개 과목 표 전체 SHA-256 일치, KST 자정·시험일·연말, 영어·한국사 8개 경계 각각, 탐구 평균/합계 가정, ko/en 키·변수 일치, 실제 React SSR의 기준 안내, ShareResult props, 상대/절대 표 전환, 신·구 쿼리의 hydration 전 HTML 일치 및 복원 후 결과 포함.
- CUTS JSON SHA-256: `137d11fd379ac5627f9a789f2b088ecdeab84145593ce5de224bbfafeff5bcd5` (변경 전·후 동일).
- `npx eslint src/components/CsatGrade.tsx src/utils/csatGrade.ts scripts/check-csat-grade-context.ts`: **exit 0**. 수정 전에는 날짜 초기 effect의 `react-hooks/set-state-in-effect` 1건이 있었으나 KST 갱신 구간 보완으로 해소했다. 규칙 비활성화 없음.
- 독립 `writing_versions`: 실제 컴포넌트 7그룹·도메인 6그룹 PASS 통지 수신. 화면·공유 학년도/추정 구분, 영어 표, 입력 변경 및 URL 재방문, KST 경계, 수치 해시 확인. 추가 재현 결함 없음.
- 독립 `batch5_verify`의 hydration 수정 후 재검증 PASS: 비기본 6점수·선택과목·minN/minSum 새 방문, 복사 링크 새 탭, 구형 영어 링크, 실제 PNG·공유 문구를 확인했고 JS/hydration 오류 0. 증거: `results-csat-grade-share.json`. 전체 브라우저 사례 집계는 통합 보고서에 기록한다.

자체 검사는 브라우저·실제 공유 PNG·배포된 정적 HTML의 검증을 대신하지 않는다. 작성자는 Chrome·전체 타입 검사·빌드·배포·커밋을 실행하지 않았다. 재현된 hydration 경고 수정은 독립 브라우저 담당자가 재확인했으며 리뷰 담당자도 상태 경계를 추가 검사한다. 후속 16차 점수 기록은 이 배치의 검증·전체 타입 검사 완료 및 root 신호 전까지 같은 부모 파일에 연결하지 않는다.
