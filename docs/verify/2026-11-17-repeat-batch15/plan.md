## 분업과 검증

- gpa_scenarios: CsatGrade 제품·관련 순수 로직·범위 검사·ko/en 번역 조각.
- taxi_repeat: CsatDday 제품·공식 근거 대조·과목별 타이머 연결·범위 검사·ko/en 번역 조각.
- writing_versions: 공식 근거와 제품 표현 독립 대조, 코드/도메인·상태 검토, 재현 결함과 수정 확인.
- batch5_verify: 단일 Chrome 실제 입력·공유·저장·인쇄/ICS·타이머 연결·모바일·날짜 경계 검증.
- batch5_integrate: messages 원본·메타 페이지·메뉴·생성물·최종 타입 검사·완료 보고/인계.
- team_rotation: 별도 다음 후보 조사 문서만 작성. 이 배치 제품 파일 변경 없음.
- root: 범위·우선순위·사용량·최종 수용·다음 배정.

준비물 등 핵심 설정을 숨기지 않고 디자인 토큰·320px·44px 버튼·16px 입력을 확인한다. 제품과 번역은 같은 담당이 작성하고 공용 원본은 통합 담당 한 명이 병합한다. 브라우저를 닫은 뒤 전체 타입 검사를 2GB heap으로 실행한다. 원인·제품 변경이 없는 검사를 반복하지 않는다.

빌드·배포·커밋·푸시는 실행하지 않는다. 검색 반영은 공개 배포와 검색엔진의 처리에 달려 있으며 로컬 구현만으로 색인 완료를 주장하지 않는다.

## 사용량 확인

사용자가 무료 쿠폰 1개를 직접 사용했다고 알려 준 뒤 root의 읽기 전용 조회에서 사용 0%·잔여 100%·쿠폰 2개·ordinaryUsageAllowed=true를 확인했다. 에이전트가 쿠폰을 직접 실행했다고 기록하지 않는다. 사용량은 계정 전체 공유 값이다. 지속 작업은 실제 개선·검증에 배분하고 동일 검사 반복으로 사용량을 늘리지 않는다.
