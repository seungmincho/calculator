# 15차 수능 두 도구 독립 검토

담당: writing_versions. 2026-11-17 KST 기준. 제품 파일을 수정하지 않고 공식 자료와 변경 경계를 독립 대조한다. Chrome·전체 타입 검사·빌드·배포는 담당 범위에서 실행하지 않는다.

## 판정

두 제품 ready 뒤 공식 자료·코드·변경 경계를 독립 검토했다. 도메인 6그룹, 실제 D-day 컴포넌트 7그룹, 실제 등급 컴포넌트 7그룹으로 **20그룹 PASS**다. 독립 검사에서 추가 결함은 발견하지 않았으나 이후 브라우저 담당이 공유 URL hydration과 모바일 숫자 줄바꿈 두 결함을 발견했다. 두 수정 경계만 추가 대조했으며 URL 복원 독립 검사 **3그룹 PASS**다. 따라서 독립 실행 증거는 합계 **23그룹**이며, 최초 20그룹을 최종 변경 후 전부 다시 실행한 것은 아니다.

구현 중 가채점 허용 범위와 명목 누적 비율 표현을 담당자와 조율했고, 최종 ko/en 문구에서 반영을 확인했다. root가 요구한 대학별 일정·충원 통보와 등록 구분은 화면뿐 아니라 ICS 설명에도 포함되도록 마지막 연결을 확인했다. 제품 파일은 수정하지 않았다.

## 검증 정책과 한계

- `CUTS` 24개 표의 개선 전 JSON SHA-256은 `137d11fd379ac5627f9a789f2b088ecdeab84145593ce5de224bbfafeff5bcd5`다. 숫자를 올해 값으로 임의 갱신하지 않는 경계를 확인한다.
- 2026 상대평가 수록표 전체를 당시 원자료와 항목별로 재입증하지 못했다. 따라서 이번 리뷰는 기존 수록표 보존·전년도 참고 원점수 추정이라는 표시를 확인하며, 전체 숫자 정확성을 새로 인증하지 않는다.
- 가채점 문구는 교육부가 설명한 범위 내에서 작성하고 사이트 인쇄물을 시험장 허용 서식으로 안내하지 않도록 구현 담당에게 전달했다. 4교시 선택 순서·첫 과목 답 수정 금지도 직접 대조했다.
- 정시·수시 후속 일정의 최신 개정 여부와 대학별 접수·충원 마감은 일반 수능 시간표와 별도다. root의 대교협 대조 결과를 참고하되 최신 개정 첨부 원문을 읽었다고 주장하지 않는다.

### 도메인

- 2027학년도/2026-11-19/2026-12-11과 참고 학년도 2026을 독립 사실로 확인했다. 24개 기존 수록표의 JSON hash가 변경 전과 일치한다.
- 영어·한국사의 1~9등급 경계와 바로 아래 점수를 검사했다. 절대평가 영역은 표준점수·백분위 추정을 반환하지 않는다.
- KST 자정 직전/직후 D-3→D-2→D-1→D-day와 08:10 입실·4교시 시각·2분 회수 구간을 확인했다.
- 과목별 80·100·70·30·30·40분 링크가 `/timer/?m=`만 사용하고 기존 타이머 parser로 정확한 초 값을 전달한다. 타이머 초기화 소스에서도 시간을 설정할 뿐 자동 시작 함수를 호출하지 않는 것을 확인했다.

### 실제 컴포넌트

`component-harness.cjs`는 실제 제품 컴포넌트를 esbuild로 메모리 안에 불러오고 React hooks/events와 시각·저장소를 제어한다. 내부 D-day 영역도 실제 함수를 실행한다. 외부 ShareResult/AddToCalendar는 전달 props를 검사하며 실제 PNG·ICS 파일·인쇄·320px 화면은 브라우저 담당 검증과 구분한다.

- 첫 화면 안내와 Hero·준비물·시간표·가채점·일정·응원·가이드 영역이 모두 남는다. 08:10 안내·공식 확인일·동일 페이지 앵커와 과목별 6개 링크를 검사했다.
- D-day Hero와 등급 화면 모두 KST 자정 경계에서 D-2→D-1로 바뀌며 참고 연도는 2026으로 유지한다.
- 준비물·답안·응원 이름의 hydration 전 기본 상태가 저장소를 쓰지 않고, hydration 후 기존 `csatDday.checklist`/`csatDday.sheet` 데이터와 공유 이름을 복원한다. 복원 뒤 편집한 응원 이름도 렌더만으로 되돌리지 않는다.
- 저장된 답·선택 과목이 PrintSheet props에 그대로 전달되고 인쇄 호출은 버튼 클릭 때만 발생한다. 인쇄물의 사용 범위 안내가 PrintSheet에도 있다.
- 달력 파일명·10개 이벤트·시험/성적 통지 날짜가 유지된다. 마지막 변경 후 모든 이벤트 description에 `timeline.note`의 대학별 기간·통보/등록 구분이 전달됨을 재확인했다.
- 실제 ko/en 번역을 적용한 등급 화면에서 상단·공유 카드·공유 텍스트에 2026 참고 추정과 2027 실제 성적과의 구분이 남는다. 국어·수학·탐구는 추정, 영어·한국사는 절대평가 표시가 공유 행에도 전달된다.
- 영어 표로 전환하면 2027 절대평가 caption과 공식 원점수 경계를 표시하고 상대평가 표준점수·명목 비율 열은 제외한다. 입력 변경과 현재 공유 URL 새 방문에서도 등급·공유 headline이 일치한다.

### 통합 코드·문구 대조

- 메타 description·Open Graph·Twitter·JSON-LD가 동일한 상수 설명을 사용한다. 등급 페이지는 전년도 추정과 올해 확정컷 미제공을 표시하며, 올해 공식 제도 출처가 기존 수록표 전체의 정확성을 보증하지 않는다고 구분한다.
- D-day 문구는 1교시 미선택자의 동일 입실 마감, 모바일 신분증 불가, 전자기기 제출, 한국사 필수 응시, 탐구 순서와 이미 끝난 첫 과목 답 수정 금지, 일반 수험생 시간표 범위를 공식 안내와 일치시킨다.
- 현재 사이트 공용 번역기는 한국어 전용이다. ko/en 실제 번역 데이터를 별도로 적용한 컴포넌트 검사는 영어 UI 전환 기능이 제공된다는 뜻이 아니다.

실브라우저·실제 다운로드·인쇄/PDF·모바일 및 최종 전체 타입 검사는 별도 담당 보고서를 따른다. 이 검토는 빌드·운영 배포·검색 색인 완료를 의미하지 않는다.

## 브라우저 발견 결함 수정 후 추가 확인

브라우저 담당이 비기본 공유 URL에서 SSR 기본 결과와 클라이언트 초기 결과가 달라 hydration 경고가 발생하는 것을 재현했다. 최초 독립 검사는 클라이언트 복원 결과와 props를 확인했으며 실제 브라우저 hydration을 검증했다고 주장하지 않는다.

담당자가 `useHydrated`와 기본 state로 첫 렌더를 통일하고, 최초 query 복원 후에만 URL 동기화를 실행하도록 수정했다. `check-grade-hydration-fix.cjs`의 실제 컴포넌트 검사 3그룹이 PASS했다.

1. 비기본 URL에서도 hydration 전 기본 트리가 동일하고 주소를 쓰지 않는다. hydration 후 6개 점수·4개 선택과목·minN/minSum을 모두 복원한다.
2. 구형 `subject`/`score`와 탐구 `sci` 링크는 값을 먼저 복원한 뒤 새 query로 정규화한다.
3. 알 수 없는 선택값은 기본값을 사용하고, 최초 복원 후 편집값을 다시 덮지 않는다. 동일 URL 쓰기를 생략하고 기존 history.state·관계없는 query·hash를 보존한다.

```text
node docs/verify/2026-11-17-repeat-batch15/check-grade-hydration-fix.cjs
CSAT hydration fix: 3 independent groups passed
```

320px에서 두 자리 카운트다운 숫자가 두 줄로 갈라진 문제는 Hero의 카드/숫자 className 두 줄만 변경했다. 카드 `min-w-0`·좁은 화면 가로 padding 축소, 숫자 `whitespace-nowrap`·모바일 글자 크기 조절을 확인했고 계산·상태 변경은 없다. 최종 시각 수용은 수정 후 브라우저 재검사 결과를 따른다.
