# 대입 일정 보조 대조

2026-11-17 KST, root. 수험생 유의사항은 제품/독립 담당이 별도 확인하며 이 메모는 기존 `TIMELINE`의 대입 일정만 다룬다.

- [대교협 2027학년도 대학입학전형시행계획 주요사항](https://www.kcue.or.kr/_upload/news/2025/04/30/application_25d9ccd90388d6ba316a2c7d398ff944.pdf), 2025-04-30, PDF 3페이지(인쇄 1쪽)의 일정표 텍스트를 확인했다. 표의 일정은 기존 `src/utils/csatDday.ts`의 날짜와 일치한다.
- 정시 접수는 2027-01-04~07 범위에서 대학별 3일 이상이다. 개별 대학이 전체 기간을 모두 운영한다고 단정하지 않는다.
- 수시 충원 **합격 통보**는 2026-12-24~29이고 최종일 18시까지다. **등록 마감**은 12월 30일 22시다.
- 정시 충원 **합격 통보**는 2027-02-13~17이고 최종일 18시까지다. **등록 마감**은 2월 18일 22시다.
- 추가모집은 2월 19~26일이며 마지막 날 합격 통보 18시와 등록 22시를 구분한다.

[어디가 기본사항 게시물](https://www.adiga.kr/uct/ces/archiveView.do?menuId=PCUCTCES1000&prtlBbsId=23508)에 2026년 3월 개정 첨부가 표시됨을 확인했다. 해당 첨부 원문을 이 조사에서 읽지 못했으므로 최신 개정 전체를 대조했다고 주장하지 않는다. 기관의 FAQ에도 날짜·용어 불일치가 있을 수 있으므로 위 직접 일정표와 구체적인 대학 모집요강을 우선 확인한다.

숫자 변경 근거는 발견하지 않았다. 일정 항목의 통보/등록 의미와 개별 대학 접수 범위를 화면·ICS 설명에 정확하게 반영하도록 제품/독립 담당에게 전달했다.
