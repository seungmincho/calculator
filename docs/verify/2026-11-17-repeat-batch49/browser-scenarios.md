# 49차 native 검증 준비

현재 결과가 아닌 준비 계약이다. `scripts/check-repeat-batch49-browser.mjs --list`만 실행 가능하며 부모/canonical final 전 Chrome을 띄우지 않는다. 대상은 `/menu-roulette/`이고 별개 `/menu-picker/`를 새 기능 대상으로 검증하지 않는다.

| 흐름 | 확인할 경계 |
| --- | --- |
| 중복/복구 | `[피자,국수,피자,김밥]` 실제 추첨→피자 전체2줄 제외→2후보→복구 원순서4줄. 원본 입력/URL 불변, 결과 무효화와 spin 버튼 DOM focus |
| 최소/no-op | `[피자,피자,국수]` 피자 제외 거부·국수 제외 후 중복2칸 허용. 스핀 중 UI·늦은 handler 차단, 없는 복구/빈 추가의 no-op가 이력/저장을 바꾸지 않음 |
| 수명/필터 | 새 방문 임시 제외0·다른 탭 전달0, 원본 편집/같은 preset 명시 적용 초기화, 실제 식사 필터 배열 변화만 초기화하고 관계없는 기록은 유지 |
| 계획/기록 분리 | 임시 제외 전후 meal/history raw 바이트 불변. 계획 후보는 식사 필터까지만 적용되어 임시 제외 메뉴도 후보로 남음. 명시 먹은 기록 추가와 기존 계획 TXT/미저장 초안 보존 |
| native RNG/파일 | 4.2초 native RAF와 첫 난수만 제어한 독립 각도/index 계산·완료1회, 옛 완료 callback 재호출0. 실제 룰렛 PNG MIME/치수와 복사·지연 callback 소유권 |
| 기존 경로 | 일반 `/roulette/`와 `/order-picker/`에 메뉴 제외 UI가 새로 노출되지 않음, 기존 기본 동작 짧은 smoke. 31 전체 검사 반복 없음 |
| 모바일/언어 | 320px 다크 KO/EN·긴 후보·제외 목록·44px·가로 넘침 없음, 실제 Tab/Enter/Space·복구 후 초점과 locale가 초점을 훔치지 않음 |

합성 storage만 사용하고 공개 RPC/외부 요청은 차단한다. 난수 제어는 명시 spin 직전 필요한 호출에만 적용하고 ID 생성/장식 전체를 상수 난수로 만들지 않는다. 저장·확률 계산 제품 유틸을 기대값으로 재사용하지 않는다. 실제 PNG/Clipboard와 RAF 역순 강제 callback 같은 제어 포트 근거를 분리한다. 완료 후 Chrome을 닫고 통합 담당 전체 타입 순서를 따른다.
