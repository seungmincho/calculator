# 음성 메모 → 회의록·할 일 연결

2026-11-16. 기존 도구 개선을 계속 진행하라는 승인 범위에서 후보 7번을 구현했다. 로컬 개발 서버 3039에서 검증했고 빌드·배포·커밋은 실행하지 않았다.

## 사용 흐름

1. `/voice-memo/`에서 녹음하거나 오디오를 가져온다. Whisper tiny 전사 또는 직접 입력한 전사문을 확인·수정한다.
2. **회의록으로 정리 (새 탭)**를 누른다. 원래 음성과 저장하지 않은 편집 내용은 원래 탭에 남는다.
3. 새 회의록 탭에서 필요한 문장을 체크하고 **토의·결정 사항·할 일**을 선택한다. 선택한 문장은 추가 전에 수정할 수 있다.
4. **선택한 N개 추가하고 저장**을 누르면 기존 회의록에 덧붙인다. 기존 제목·참석자·내용을 보존하며 빈 제목만 메모 이름으로 채운다.
5. 할 일의 담당자·기한·상태를 직접 입력하고, 기존 자동 저장·이름 붙여 저장·미리보기·내보내기를 사용한다.

자동 요약이나 생성 모델을 추가하지 않았다. 문장 구분은 기존 TTS의 순수 문자열 로직을 재사용한다. 발언자·담당자·기한은 추정하지 않고 빈칸으로 남긴다. 긴 문장은 1,000자 이내로 나누며 한 번에 최대 100개·총 12,000자를 추가한다. 첫 10문장부터 표시하고 더 보기를 제공한다.

## 저장과 데이터 보호

- 원문은 URL에 포함하지 않는다. 사용자가 연 새 탭의 `sessionStorage`에 전달하며 원래 탭과의 `opener` 연결은 끊는다. 전달 내용의 최초 읽기 유효 시간은 10분이다. 탭 안에 불러온 뒤 검토하는 시간에는 제한을 두지 않는다.
- 적용·닫기 시 임시 원문과 주소의 가져오기 표시를 지운다. 팝업·저장소 차단 시 원본 탭과 입력을 유지하고 안내한다.
- 선택한 내용만 기존 `meetingMinutes_auto`에 저장한다. 원래 오디오의 IndexedDB 저장 방식은 변경하지 않았다.
- 같은 전달 ID를 이미 적용했다면 다시 추가하지 않는다. 기존 회의록에 이전에 없던 `importedSources` 필드만 추가하며 이전 저장 형식은 계속 읽는다.
- 자동 저장·저장 슬롯의 실패를 숨기지 않는다. 손상된 기존 데이터는 덮어쓰지 않고, 다른 탭이 저장 내용을 바꾸면 덮어쓰기를 중단한다. 현재 내용을 내보낸 뒤 재진입하도록 안내한다.
- 기존 HTML 내보내기에서 사용자가 입력한 문자를 이스케이프해 글이 태그나 스크립트로 실행되지 않도록 수정했다. 텍스트 내보내기는 원문을 보존한다.
- 회의록 입력 폰트 16px, 주요 조작 최소 44px, 모바일 명시적 1열과 토큰 색상으로 정리했다. 기존 미리보기·템플릿·슬롯·내보내기는 유지한다.

## 검증

- `node scripts/check-meeting-handoff.ts`: **11개 검사 통과**. 유효/만료/미래/손상된 전달, 소수점 문장 경계, 긴 글 보존, 선택 내용만 추가, 담당자·기한 미추정, 원본 불변성, 중복 전달, 저장 형식과 충돌·용량 오류, HTML 이스케이프.
- `node scripts/check-meeting-handoff-browser.mjs`: **7개 시나리오 통과**. 실제 WAV 가져오기 → 새 탭 → 문장 선택/수정 → 기존 내용 보존 → 담당자·기한 편집 → 저장/재방문 → HTML 다운로드, 저장 실패, 다른 탭 충돌, 손상된 저장/만료된 전달, 중복 방지, 팝업 차단, 320px 다크 모드.
- `node scripts/check-repeat-use-browser.mjs voice`: **기존 음성 메모 4개 회귀 시나리오 통과**. 저장·검색·복원·삭제, 실제 MediaRecorder 일시정지 시간, ASR 취소/제한, 저장 실패 시 녹음 유지.
- 변경 컴포넌트·유틸 ESLint 통과, 전체 `npx tsc --noEmit` 통과, 메시지 생성본 일치 검사 통과.
- i18n audit 미해결 0. 기존 동적 키·범용 컴포넌트 안내 60건은 유지. 메뉴 업데이트 날짜와 RSS·redirects·llms.txt 재생성.

브라우저 검사는 JavaScript 예외와 hydration 경고를 수집해 실패 처리한다. 원문에서 생성형 모델을 호출하지 않는 흐름임을 외부 요청 검사로 확인했다. 이 회차의 입력은 테스트 WAV와 직접 입력한 한국어 전사문이며 Whisper 인식 품질을 다시 평가한 것은 아니다. 실제 휴대폰·Safari·정적 export 빌드·배포는 미검증이다. 기존 정책상 도구 본문은 한국어이며 ko/en 원본은 모두 보완했다.
