# 가이드 배포 전 검증 시나리오

대상은 로컬 프로덕션 빌드의 `out/`이다. 브라우저는 390px과 1280px 너비로 검사한다.

| 항목 | 실행 | 기대 결과 |
|---|---|---|
| 검색용 HTML | 전체 가이드 파일에서 제목·본문·canonical과 도구 링크를 확인하고 목록·사이트맵·RSS와 대조한다. | 모든 가이드가 기본 주소로 노출되며 예시 쿼리 주소가 사이트맵에 생기지 않는다. |
| 추천 동선 | 홈 추천에서 택배비·음력·평수 계산기를 열고 각 가이드와 예시를 누른다. 가이드 목록 상단도 확인한다. | 세 글이 보이고, 각각 500g 운임, 2025년 윤6월 10일, 공급면적 112㎡ 조건이 복원된다. |
| 택배 운임 | 가이드의 500g, 1kg, 2kg 예시를 차례로 열고 계산기 상단 링크로 돌아온다. | 결과 영역 첫 비교표에서 각각 2,500원, 2,700원, 2,900원 절약을 읽을 수 있다. |
| 택배 경계값 | 501g, 1.08kg, 5kg 초과, 세 변 합 80cm 초과와 빈 무게를 넣은 뒤 정상값으로 복원한다. 기본 주소도 새로 연다. | 입력과 요금이 함께 갱신되고 불가 사유가 표시된다. 기본 주소는 전체 택배사 비교로 시작한다. |
| 새 콘텐츠 | 여섯 분야의 새 글과 기존 글 일곱 편을 열어 본문·표·도구 링크를 확인한다. | 표와 글을 가로 스크롤 없이 읽을 수 있고 도구에서 관련 가이드로 이동할 수 있다. |
