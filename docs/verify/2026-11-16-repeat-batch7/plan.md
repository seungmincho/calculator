# 팀 나누기 후속 — 직전 동료 겹침 줄이기

2026-11-16. 사용자가 특히 원했던 팀 나누기의 상호작용과 실제 모임 활용도를 함께 높이는 후속 개선이다. 기존 명단 저장·팀 카드 이동·교환·고정·되돌리기·공유는 유지한다.

## 사용 흐름

완료된 편성에서 **동료 겹침 줄여 다시 나누기**를 누르면 같은 팀에 있었던 사람 조합이 덜 반복되도록 다음 편성을 제안한다. 직전 편성만 비교한다. 기록을 저장했다거나 여러 라운드의 공정성을 보장한다고 표현하지 않는다.

- 명단·팀 수가 현재 완료 편성과 일치할 때 사용한다. 드래프트 중에는 사용할 수 없다.
- 고정한 사람의 팀은 보존한다. 인원 수 차이가 최소가 되도록 배정하고, 고정 때문에 불가능하면 그 제한을 알린다.
- 실력 균형 모드에서는 기존 균형 편성과 비교해 실력 편차를 악화시키지 않는 후보 중에서 동료 겹침이 적은 것을 고른다.
- 제한된 후보 탐색이며 항상 반복 조합이 0이 되거나 수학적 최적해가 나온다고 보장하지 않는다. 반복 조합 수와 기준을 실제 결과에서 계산해 보여 준다.
- 다음 결과도 기존 카드 공개·고정·이동·되돌리기·공유 흐름을 그대로 쓴다. 새 경로·서버·모델·추가 저장소는 만들지 않는다.

## 검증

- 사람 누락·중복 없음, 고정 위치 보존, 인원 균형, 가능한 작은 명단에서 반복 감소.
- 2~200명·2~8팀 범위와 불가능한 고정 조건, 실력 편차와 반복 수 표시 정확성.
- 실제 버튼 → 결과 → 되돌리기 → 공유 복원, 모바일320px·모션 감소 환경, 기존 팀보드 회귀.
- UI 담당이 ko/en 번역 조각을 작성하고 공용 파일은 통합 담당이 반영한다. 브라우저·전체 타입 검사는 다른 묶음과 순차 실행한다.
