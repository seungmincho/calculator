# 팀 나누기 7차 — 직전 동료 겹침 줄이기

2026-11-16, KST. 기존 `/team-divider/`의 완료된 팀 보드에 **동료 겹침 줄여 다시 나누기**를 추가했다. 기존 카드 이동·교환·고정·되돌리기·명단 저장·공유를 유지한다. 새 저장소·경로·서버·모델을 추가하지 않았고, 빌드·배포·커밋·푸시는 실행하지 않았다.

## 동작과 기준

- 현재 명단·팀 수와 완료된 편성이 일치할 때 무작위 또는 실력 균형 모드에서 사용한다. 드래프트 중에는 실행하지 않는다.
- 직전 편성과 같은 팀에 있던 두 사람 조합이 얼마나 반복되는지 계산한다. 최대 40개 후보에서 인원 균형을 우선하고 반복 조합이 적은 편성을 고른다.
- 고정한 사람의 팀을 유지한다. 고정 인원이 한 팀에 몰려 인원 차이를 1명 이내로 맞출 수 없으면 안내한다.
- 실력 균형 모드에서는 같은 조건으로 생성한 기본 균형 편성보다 실력 합계 편차가 큰 후보를 제외한다. 화면에 그 기준을 표시한다.
- 결과 보드를 직접 수정하면 실제 현재 팀을 기준으로 반복 조합 수를 다시 계산한다. 되돌리기는 이전 편성과 비교 상태를 함께 복원한다.
- 비교 기준은 직전 편성 한 번뿐이다. 새로고침하면 비교 상태가 사라지고 공유 링크에는 현재 팀만 담긴다. 여러 라운드의 공정성·반복 0쌍·수학적 최적해를 보장하지 않는다.

## 검증

| 검사 | 결과 |
| --- | --- |
| `check-team-rotation.ts` | 168개 범위·고정·실력·공유 시나리오 및 예외·쌍 계산·불가능 고정 검사 통과 |
| TeamDivider·teamRotation·검사 스크립트 ESLint | 오류·경고 0 |
| 독립 코드 리뷰·기존 보드 회귀 | 147개 조건 통과, 기존 `check-team-board.ts`도 통과. 재현 가능한 미해결 결함 없음 |
| 독립 브라우저 사용자 흐름 | 4/4 통과, JavaScript 예외·hydration 오류 0. 실제 반복 수·되돌리기·공유·이동·교환·드래그·고정·주장 모드·320px 다크/모션 감소 확인 |
| 한국어·영어 번역 | `teamDivider.rotation` 12개 키/언어, 실제 사용 키·보간 변수·병합값 일치 |
| 메타데이터·발견 경로 | 기존 updatedDate 유지, 팀 페이지 설명·도입·FAQ와 메뉴 설명 갱신 |
| 전체 `tsc --noEmit` | 5·6·7차 최종 코드 통합 후 오류 0. 브라우저 종료 뒤 2GB 힙 한도로 단독 실행 |

실제 휴대폰·Safari/Firefox·프로덕션 정적 export는 검증 범위 밖이다. 공통 번역기의 기존 한국어 전용 제약을 유지하며 새 영어 키를 작성·대조한 것을 영어 UI 전환 검증으로 표현하지 않는다.
