## 실행 결과

- 타입 검사와 변경 파일 ESLint를 통과했다. 번역 생성물 792개가 원본과 일치하고 네임스페이스 감사의 미해결 항목은 0개다.
- 택배·더치페이·서브넷·러닝 페이스·이미지 리사이즈·QR·출산예정일 계산 검사를 통과했다. 정산 순잔액, 후반 5km 페이스, 서브넷 호스트 범위, 사진 자르기·여백 수치는 글의 값과 계산 함수의 출력을 대조했다.
- `npm run build`가 891개 정적 경로 생성과 RSC 파일 경로 후처리를 마쳤다. 전체 HTML 검사에서 제목(h1) 누락으로 표시된 페이지는 기존의 색인 제외 대상 `/tips/[id]/` 400개다. 이번 가이드와 계산기에는 해당 경고가 없었다.

운영 배포 뒤에는 [개선 계획의 배포 후 항목](../handoff/2026-11-12-guide-release-plan.md)에 따라 운영 주소와 Search Console의 실제 크롤링·색인 상태를 확인한다.
