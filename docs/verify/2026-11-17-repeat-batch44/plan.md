## 기존 기능과 남은 불편

`RunningPaceCalculator.tsx`는5km/10km/하프/마라톤/직접거리, 완주시간↔페이스,1km/5km 누적 구간표, 복사·인쇄를 이미 제공한다. `runningPace.ts`는 최대500km·소수4자리, 시분초 범위와 마지막 잔여 구간을 계산한다. 현재는 목표 시간을 바꾸면 앞선 목표의 페이스/구간표가 사라지고 입력을 재현하는 공유 URL은 없다. 기존 구간표나 인쇄 기능을 새로 만들었다고 설명하지 않는다.

## 최소 구현 범위

- 현재 거리 하나에 목표 완주시간 최대3개를 나란히 둔다. 현재 유효 시간의 `비교에 추가`와 행별 시/분/초 직접 입력·삭제를 지원한다. 이름 대신 목표1/2/3으로 시작해 저장/개인정보 범위를 늘리지 않는다.
- 각 행은 총시간·km당 페이스·속도를 표시하며 같은 거리 기준의 차이만 계산한다. 입력이 잘못된 행은 그대로 오류 표시하고 정상 행과 순위를 섞지 않는다. 건강 상태·훈련 효과·달성 가능성은 판단하지 않는다.
- 선택한1km/5km 표에는 같은 구간거리마다 목표별 누적 시간을 표시한다. 기존 calculateRunning을 재사용하고 표시된 반올림 페이스를 다시 곱하지 않는다. 마지막 잔여 구간/하프21.0975/마라톤42.195에서도 합계가 원래 목표시간으로 끝나야 한다.
- 거리나 모드를 바꿔도 목표3개는 사용자가 입력한 완주시간으로 남고 새 거리의 페이스가 다시 계산된다. 현재 단일 입력과 비교 행을 자동 덮어쓰지 않는다. 최대 행수에서 버튼 disabled/이유를 표시한다.
- 단일 입력과 비교 목표의 숫자 조건을 URL로 재현한다. 기존공유링크가없으므로 새 owned keys와 버전을 명시하며 unknown query·hash·history.state를 보존한다. 초기 hydration 전 기본값으로 URL을 덮지 않고 초기 사용자의 직접 편집이 늦은 복원보다 우선한다. 잘못된 공유 입력을 정상 기본값으로 꾸미지 않는다.
- 전체 비교 구간표를 TSV복사·CSV·인쇄로 제공한다. 출력은 클릭 당시 거리/목표/간격 snapshot이고 최대500구간을 누락하지 않는다. 미리보기는 행 수를 제한해도 전체 반출은 동일하다. 복사 실패 시 전체 텍스트 선택/재시도, ShareResult와 기존 복사의 요청 소유권을 함께 처리한다.
- 새 localStorage/계정/공개 기록/운동 데이터 자동 수집은 없다. 첫 화면은 기존 기본 예시와 결과를 유지한다. 기존 직접 lazy 번역 scope(runningPace)와 EN 재시도 경로도 유지한다.

## 담당 파일과 검증

제품 담당은 기존 RunningPaceCalculator, 신규 RunningPaceComparison, runningPaceComparison/query/actions 순수 모듈과 KO/EN fragment를 함께 소유한다. 계산 엔진은 불필요하게 바꾸지 않고 canonical/가이드/메타/updatedDate/생성물은 통합 담당이 맡는다.

검증은 기존 check-running-pace 회귀, 독립 정수 초/거리 비율 기대값,0·99시간·60분/초·500km·짧은 소수거리·마지막 잔여 구간·반올림 경계를 포함한다. 실제 부모에서는 목표 CRUD/거리 변경/URL 초기화/공유 새방문/반출 중 수정/locale A-B-A·복사 교차 요청을 확인한다. 별도 Chrome에서 실제 CSV/Clipboard/인쇄 레이아웃·320px KO/EN을 확인한 뒤 범위 lint·번역·전체 타입을 통과해야 완료다. 실제 휴대기기·인쇄물 출력·운동 성과를 검증했다고 주장하지 않는다.

비교표는 모바일에서 카드 요약과 명확한 가로스크롤 표를 사용하고 페이지 전체를 넓히지 않는다. 버튼44px·입력16px·토큰 색·MobileResultLink를 적용한다. 페이지의 기존 경고색 하드코딩을 수정할 때는 소유 범위에서 의미가 같은 토큰/기존 경고 패턴으로 정리한다.
