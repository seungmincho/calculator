# 16차 독립 브라우저 검증

최종 **12/12 PASS**, JavaScript·hydration 오류 **0건**. 마지막 영향 사례 확인 시각은 2026-11-17 00:39 KST(2026-11-16 15:39 UTC)다. Chrome을 닫고 통합 담당에게 전체 타입 검사 가능 시점을 알렸다.

기존 `http://127.0.0.1:3039` 서버를 보존하고 Chrome 하나에서 사례별 격리 컨텍스트를 순차 사용했다. 외부 요청·서비스 워커는 차단했다. 검증용 점수와 기록만 사용했으며 제품 수정·서버 시작/종료·빌드·배포·Git·전체 타입 검사는 이 담당이 실행하지 않았다. 15차 전체 검사를 반복하지 않고 새 저장/복원 경계에 집중했다.

## 최종 변경과 영향 확인

최초 내신 6개·수능 6개는 모두 통과했다. 이후 구현 담당이 **빈칸 기록 복원 뒤 공유 URL에서 빈 문자열을 0으로 쓰던 기존 경계**를 발견해 보완했다. 해당 수정을 최초 브라우저가 발견했다고 기록하지 않는다.

기존 핵심 사례에 실제 복사 링크 새 탭 검증을 추가했다. 수학/영어 빈칸은 `math=&eng=`로 유지되고 새 방문에서도 빈칸이다. `kor=0`은 실제 0점, 파라미터 없는 국어는 기본 84점, 구형 `subject=english&score=`는 빈칸으로 복원됨을 확인했다. 비기본 선택과목과 다른 점수도 그대로 보존되고 hydration 오류가 없다. 영향 핵심/URL 2개를 재실행해 통과했으며 관련 모바일 비교 카드도 캡처했다. 근거: [추가 실행 결과](browser/results-csat-records-rawcsat-records-url.json).

이 담당의 브라우저 실행에서 추가 미해결 제품 결함이나 테스트 실패는 없었다.

위 저장 패널과 비교 카드 이미지를 직접 열어 확인했다. 모바일은 데스크톱 Chrome의 320px 뷰포트이며 실기기 검증은 아니다. `language=en`에서 기능·원시 번역 키 노출을 검사하고 신규 ko/en 구조를 대조했지만, 공통 도구 레지스트리의 기존 한국어 표시 제약 때문에 본문 영어 전환 완료로 주장하지 않는다.

두 탭 충돌은 실제 Chrome Web Locks·storage event를 사용했다. quota/접근 차단/readback 실패는 검증 컨텍스트의 Storage 메서드에 예외를 주입했다. 쓰기 후 확인 불가에서는 실제 쓰기가 끝난 상태를 확인했으며 rollback을 보장한다고 해석하지 않는다. Web Locks 미지원 환경의 완전 동시 쓰기 원자성은 이 검사로 보장하지 않는다.

내신의 빈 문자열과 숫자 입력으로 표현 가능한 무효 값(석차 200/수강자 100)을 실제 폼에서 확인했다. `type=number`가 표시할 수 없는 `2abc` 같은 원문은 독립 상태/도메인 검토 범위이며 브라우저에 해당 문자가 그대로 보였다고 주장하지 않는다. 공식 누적 내신이나 합격 가능성을 검증하는 사례는 포함하지 않는다.
