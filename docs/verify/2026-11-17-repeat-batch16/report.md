## 저장과 비교의 의미

빈 입력은 실제 0점과 구분하며 수능은 선택과목이 다르면 차이를 계산하지 않는다. 원점수 차이는 현재 값에서 저장 값을 뺀 수치이며 시험 난이도 보정이나 성적 향상·합격 예측이 아니다. 과거 시험/참고 학년도 기록은 기준 차이를 표시하고 불러오기 후 현재 계산기 기준으로 계산한다. 현재 수능최저 조건은 기록 복원으로 바뀌지 않는다. 15차의 전년도 추정·절대평가 구분을 유지했다.

내신은 중간 편집 원문·빈 행·중복 과목명을 보존하지만 요약에 계산 가능한 과목/단위만 포함한다. HTML 숫자 입력에서 일부 잘못된 원문은 빈칸처럼 보일 수 있어 내부 저장 원문 보존과 화면 표시를 구분한다. 서로 다른 5·9등급 평균을 차감하지 않는다. 명시적 복원 때 과목 행 ID와 선택 상태를 재구성하며 기존 동석차·단위 가중 계산을 보존한다.

최초 공유 URL을 먼저 복원하고 저장 목록을 자동 적용하지 않는다. 기록을 고르는 것은 비교/미리보기이며 현재 입력 교체에는 명시적 확인이 필요하다. 삭제는 현재 폼을 유지한다. 목록은 브라우저에만 저장하며 새 서버·패키지를 추가하거나 외부로 자동 전송하지 않는다.
