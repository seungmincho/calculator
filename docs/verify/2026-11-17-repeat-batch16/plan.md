# 16차 실행 계약 — 입력을 다시 쓰는 성적 기록

2026-11-17 KST. 사용자가 한도 초기화 후 멀티 에이전트로 다음 개선을 계속 구현·검증하도록 재차 요청했다. [코드 조사](../../handoff/2026-11-17-next-tool-candidates.md)에서 확인한 빈 흐름만 기존 도구에 추가한다. 15차의 수능 근거/표시 작업은 먼저 안정화하고 같은 파일 담당자가 이어 소유한다.

## A. 수능 점수 기록·현재 입력과 비교

- `/csat-grade/`에서 이름 40자·최대 12개 점수 기록을 명시적으로 저장·불러오기·삭제한다. 6개 영역의 원본 입력과 선택과목, 시험 학년도·참고 자료 학년도를 구분해 저장한다. 계산 엔진이나 컷 숫자를 새로 만들지 않는다.
- 선택한 기록과 현재 입력의 원점수를 나란히 비교한다. 과목 선택이 다르면 같은 과목의 점수 변화처럼 차감하지 않는다. 빈 입력을 저장/비교에서 실제 0점으로 바꾸지 않는다.
- 전년도 추정 자료를 사용한다는 15차 기준을 목록/비교에서도 유지한다. 저장 시점과 현재 자료 기준이 다르면 재계산된 현재 결과를 당시의 확정 결과로 표시하지 않는다. 최초 범위는 원점수 비교이며 합격 가능성/성적 추세 예측은 추가하지 않는다.
- 저장본을 자동 적용하지 않는다. 공유 URL을 먼저 복원하고, 명시적 불러오기 시 현재 입력을 교체한다는 안내를 제공한다. 기록 삭제는 현재 입력을 바꾸지 않는다.

## B. 내신 시험/학기별 입력 저장·복원

- `/grade-calculator/`에서 이름 40자·최대 8개 입력 기록을 명시적으로 저장·불러오기·삭제한다. 입학년도·5/9등급제·최대 30개 과목의 이름/단위/석차/동석차/수강자수 입력을 보존한다.
- 빈 행과 편집 중 값도 문자열 경계를 검증해 보존하며 잘못된 행을 정상 계산 결과로 취급하지 않는다. 같은 과목명이 있어도 자동 병합하지 않는다. 복원 시 행 ID/선택 상태를 안전하게 재구성한다.
- 저장 목록에 등급제와 유효 과목/단위 요약을 표시한다. 다른 5/9등급제 평균을 서로 빼서 성적 상승/하락으로 판정하지 않는다. 이번 범위에서 학교별 공식 누적 내신이나 자동 과목 대응 비교를 추가하지 않는다.
- 최초 공유 URL 복원·기존 동석차/단위 가중 계산·행 추가/삭제·공유를 유지한다. 불러오기만 명시적으로 현재 입력을 교체한다.

## 공통 계약

저장소는 도구별 분리·버전·정확한 필드·길이·개수·범위 검증을 적용한다. 손상/미래 버전/용량 초과/접근 차단/감지된 다른 탭 변경에서 거짓 성공이나 조용한 덮어쓰기를 막고 명시적인 목록 재조회로 복구한다. 쓰기 후 확인 불가에서는 이미 쓰였을 수 있음을 인정하고 rollback을 보장하지 않는다. 새 서버·계정·패키지를 추가하거나 기록을 외부로 자동 전송하지 않는다.

디자인 토큰·16px 입력·44px 버튼·320px·ko/en·SSR 공유 복원을 검증한다. 제품 준비 전 부모 import를 연결하지 않는다. 15차 최종 검사 동안에는 검증 중인 파일을 바꾸지 않는다. 전체 타입 검사와 브라우저는 통합/검증 담당 한 명이 순차 실행한다.
