# 8차 독립 브라우저 검증

기존 개발 서버3039와 실제 Chrome 한 개를 순차 사용한다. 서비스 워커와 외부 요청을 차단하고 제품 파일은 수정하지 않는다. 실제 출력 파일 및 CSV/ICS 내용을 검증하며 외부 캘린더에는 등록하지 않는다. 포모도로는 Playwright Clock으로 Date와 타이머를 함께 제어한다.

| 대상 | 검증 계획 |
| --- | --- |
| 이미지 | 작은 PNG 2장 → 프로필 저장·변경·복원 → PNG/JPEG 실제 MIME·크기 및 ZIP 파일 확인 |
| 이미지 | 할당량 실패에서 원본·이름 유지, 손상/미지원 저장값 보존, 두 탭 충돌, URL 입력 우선권, 320px 다크 |
| D-day | 현재 일정과 선택 저장 일정 실제 ICS 다운로드, 날짜·윤일·exclusive end·제목·UTF-8 접기·stable UID 확인 |
| D-day | 선택 해제·잘못된 날짜·손상 저장값·다운로드 실패 처리, 기존 계산 및 320px 다크 |
| 포모도로 | 목표 변경 중 타이머 지속, pause/resume, 실제 집중 완료만 집계, skip·휴식·재방문 중복 집계 없음 |
| 포모도로 | 최근7일 CSV 날짜·누락일·중복일 합산, 저장 실패·손상 원본 보존, 320px 다크 |

신규 ko/en 키 구조와 영어 설정 상태의 기능을 확인하며 공통 한국어 전용 번역 런타임을 영어 UI 전환 성공으로 기록하지 않는다. 모든 시나리오에서 JavaScript·hydration 오류를 수집하고 `browser/`에 결과 및 증거 파일을 저장한다.

## 결과

최종 **16/16 PASS**, JavaScript·hydration 오류 **0**. 실행한 Chrome은 모두 종료했다. 원본 실행 기록은 `browser/results*.json`, 각 시나리오의 최신 결과와 출처는 `browser/final-results.json`이다. 실패한 초기 실행도 원인 추적을 위해 보존했다.

| 대상 | 통과 | 실제 확인 |
| --- | ---: | --- |
| 이미지 프로필 | 5 | 80×40 실제 PNG 2장 → PNG 40×20, JPEG 24×24, ZIP 안 두 파일의 MIME·크기·고유 이름. 프로필 복원·재방문·이름 변경·삭제 확인/취소. 할당량 실패에서 원본/입력 유지, 손상/미지원 버전 보존, 다른 탭 변경 차단. URL 우선권·WebP 미지원 시 적용 차단·320px 다크. |
| D-day ICS | 5 | 현재 일정과 선택한 2개만 실제 다운로드. `text/calendar;charset=utf-8`, CRLF, 윤일 2028-02-29→배타적 종료 2028-03-01, 연말 경계, 제목의 쉼표/세미콜론/역슬래시/줄바꿈, UTF-8 75바이트 접기, 반복 다운로드 동일 UID. 손상 저장소에서 현재 일정 독립 내보내기, 빈 날짜·9999-12-31·바뀐 선택 원본·다운로드 실패 거부, 320px 다크. |
| 포모도로 | 6 | 실행 중 목표 수정, 일시정지 중 시간 불변, 재개·집중 완료 1회 집계·재방문 중복 없음. 집중 건너뛰기/휴식 완료/휴식 건너뛰기 집계 없음. CSV 7일·누락일 0·중복일 합산·BOM·작업 문구 제외. 목표 quota 입력 보존·통계 quota 화면 기록/CSV 유지·재시도, 손상/미래 날짜 보존·두 탭 충돌, 320px 다크. |

최초 검사의 5건 실패는 검증 코드에서 화면 초기화 전에 누른 버튼 2건과 이미 지난 시각으로 `Clock.pauseAt`을 호출한 3건이었다. 초기화 대기와 현재 가상 시각 기준 정지를 적용해 해당 사례만 다시 실행했다. 저장 일정 목록이 날짜순으로 정렬되는 기존 동작에 맞게 선택자를 날짜/제목으로 바꾸었다. 이 검증 과정에서 추가 제품 결함은 확인되지 않았다. 사전 리뷰에서 확인된 기존 포모도로 `skip` 집계 결함은 구현 담당이 수정했으며, 실제 완료와 건너뛰기를 분리한 브라우저 회귀 검사를 통과했다.

증거는 `browser/image-320-dark-panel.png`, `dday-320-dark-panel.png`, `pomodoro-320-dark-panel.png`와 각 `*-320-dark-top.png`이다. 세 패널을 직접 열어 확인했고 가로 넘침은 없었다. 긴 이미지 프로필 요소 캡처에는 고정 헤더가 겹치는 촬영 특성이 있어 실제 상단 viewport 캡처도 함께 보존했다. 실제 출력은 `resized-40x20.png`, `resized-24x24.jpg`, `resized-batch.zip`, `current-leap.ics`, `selected-two.ics`, `pomodoro-seven-days.csv` 등을 참조한다.

ko/en 추가 키 구조를 대조하고 `language=en` 설정에서도 기능/원시 키 노출 여부를 검사했다. 공통 번역 런타임이 한국어 네임스페이스를 등록하는 기존 제약 때문에 실제 영어 UI 전환을 검증했다고 주장하지 않는다. 외부 캘린더 등록, 실제 OS 알림·스피커 음향, 모바일 실기기는 범위 밖이며 Playwright Clock과 데스크톱 Chrome의 320px viewport를 사용했다. WebP 미지원 및 저장/다운로드 실패는 해당 브라우저 API만 실패하도록 주입했다. 이미지 변환과 ICS/CSV 생성 함수는 대체하지 않았다.
