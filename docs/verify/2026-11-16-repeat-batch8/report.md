# 8차 검증 결과 — 이미지 설정·D-day 캘린더·집중 목표

2026-11-16 KST. 연속 개선 계획의 01~03을 구현하고 도메인·브라우저·전체 타입 검사를 완료했다. 기존 도구 세 개를 확장했으며 새 경로·의존성·서버 저장을 추가하지 않았다. 기존 3039 개발 서버를 재사용했고 빌드·배포·커밋·푸시는 실행하지 않았다.

## 추가한 기능

| 항목 | 사용 흐름 | 저장·입력 기준 |
| --- | --- | --- |
| 01 `/image-resizer/` | 출력 크기·맞춤 방식·형식·품질·목표 용량을 이름으로 저장하고 수동으로 불러오기. 이름 변경·삭제 지원 | 최대 10개, 이름 40자. 설정만 저장하며 사진·파일명·크롭 위치·cm 입력 원문은 저장하지 않음. 공유 URL 조건을 자동으로 덮지 않음 |
| 02 `/dday-calculator/` | 입력한 날짜 1개 또는 선택한 저장 일정 최대 100개를 종일 .ics로 다운로드 | 외부 캘린더 자동 등록·초대·반복·알람 없음. 잘못된 날짜·제목·변경된 선택은 일부만 잘라 성공시키지 않음 |
| 03 `/pomodoro/` | 오늘 목표 집중 횟수 설정, 완료 횟수 기준 진행률, 최근 7일 기록 CSV | 목표 1~20회, 기본 4회. 기존 `pomodoro-daily-stats` 사용. 목표 변경으로 실행 중 타이머를 정지·초기화하지 않음 |

이미지 설정은 지원 출력 범위 안에서만 저장하며, WebP를 지원하지 않는 브라우저에서는 해당 설정 적용을 막고 안내한다. 기존 프리셋·cm/DPI 입력·개별 다운로드·ZIP은 유지한다.

포모도로는 집중 완료만 통계·세션 완료·할 일 완료에 반영한다. 휴식과 건너뛰기는 완료로 세지 않는다. 기존 통계는 날짜·횟수·분만 있어 과거에 포함된 건너뛰기를 구분할 수 없으므로 유효한 과거 기록은 유지하고 중복 날짜만 합산한다. 수정 이후의 건너뛰기부터 집계하지 않는다. CSV에는 할 일 문구를 넣지 않는다.

손상·미지원 저장 데이터, 할당량·접근 실패, 다른 탭의 변경을 숨기지 않는다. 유효하지 않은 항목만 걸러 원본을 덮지 않고 실패 시 원본과 입력을 보존한다. Web Locks 지원 환경에서는 쓰기를 직렬화하고, 미지원 환경은 원본 비교·쓰기 후 읽기 확인으로 기존 기능을 유지하되 완전 동시 쓰기의 원자성은 보장하지 않는다.

## 캘린더 형식 기준

D-day 담당이 [RFC 5545 공식 원문](https://www.rfc-editor.org/rfc/rfc5545.html)을 확인했다. 종일 DATE와 다음 날을 사용하는 종료 경계, UTF-8 문자를 끊지 않는 75바이트 줄 접기, 제목 이스케이프, 안정적인 UID와 UTC DTSTAMP를 적용했다. 날짜는 기존 유틸에 맞춰 0100-01-01~9999-12-30을 지원한다. 파일 생성은 외부 캘린더 자동 등록이 아니며 앱별 재가져오기 중복 처리까지 보장하지 않는다. [공식 절별 출처·구현 결정](dday-rfc-note.md).

브라우저에서는 실제 PNG 40×20·JPEG 24×24와 ZIP 안 두 파일의 형식·크기·고유 이름을 확인했다. ICS는 실제 다운로드한 CRLF·윤일·다음날 종료·제목 이스케이프·UTF-8 접기·동일 UID를 확인했다. 포모도로는 Playwright Clock으로 실행·정지·재개·집중 완료·휴식·건너뛰기·재방문을 구분하고 CSV 날짜 7개·누락일 0·중복일 합산·개인 문구 제외를 확인했다. 세 도구의 저장 실패·손상 데이터·충돌과 320px 다크 화면도 통과했다.

타입 검사 체크포인트는 **2026-11-16 23:02 KST까지 확인한 현재 디스크 상태**이며, 당시 진행 중인 9·10차 코드도 검사 대상에 포함됐다. 이 결과를 9·10차 최종 제품 검증 완료로 취급하지 않는다. 뒤이어 변경되는 코드는 해당 묶음의 체크포인트에서 다시 확인한다.

## 한계와 증거

공통 번역기는 기존에 한국어만 로드한다. 새 ko/en 키와 영어 설정 상태의 기능·원시 키 노출 여부를 확인했으며 실제 영어 UI 전환을 검증했다고 주장하지 않는다. 외부 캘린더 앱 가져오기, 실제 OS 알림·음향, 휴대폰 실기기·Safari/Firefox·운영 정적 export는 검증하지 않았다. 실패 시나리오는 해당 API만 주입하며 이미지 변환·ICS/CSV 생성 함수를 모의 구현하지 않았다.
