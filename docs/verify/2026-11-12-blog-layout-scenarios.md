# AI 노트와 평수 가이드 표시 검증

| 대상 | 확인 순서 | 기대 결과 |
| --- | --- | --- |
| 운영 배포 | 공개 AI 노트와 가이드를 열고 사이트맵과 RSS를 읽는다. | 두 페이지가 열리고 사이트맵에 들어 있다. RSS에는 실제 발행된 가이드가 있다. |
| 평수 계산 예시 | 휴대폰 화면에서 가이드의 공급 112㎡ 예시를 누르고 계산기에서 글로 돌아온다. | 공급면적이 선택되고 33.88평이 표시된다. 제목 링크로 같은 글에 돌아온다. |
| 헤더 | 수정본을 작은 휴대폰, 중간 화면, 큰 화면에서 열고 메뉴와 검색을 사용한다. | 이름이 잘리거나 조작 영역이 겹치지 않는다. 메뉴에서 AI 노트로 이동할 수 있다. |
| 첫 글 이전의 블로그 | 수정본에서 AI 노트 목록을 열고 추천 가이드 링크를 누른다. | 실제 가이드가 열리고 빈 글 목록이나 공통 도구 목록 버튼이 보이지 않는다. |
| 검색창 | 페이지 맨 위와 스크롤한 위치에서 검색을 열고 상단 모서리를 클릭하거나 Esc를 누른다. | 배경이 화면 전체를 덮고 닫으면 기존 스크롤 위치와 검색 조작이 복원된다. |
