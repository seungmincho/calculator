# 20차 준비 계약 — 음력 기념일·말하기 기록 다시 찾기

2026-11-17 KST. [실제 코드 조사](../../handoff/2026-11-17-personal-record-candidates.md)에 근거한 기존 도구 개선이다. 19차 문서 도구의 전체 체크포인트 후 부모를 연결한다. 준비 도메인은 미연결 상태로 작성할 수 있으며, 공용 번역기/진행 중인 검증 파일을 동시에 바꾸지 않는다.

## A. 이름 붙인 음력 기념일

- `/lunar-converter/`에서 이름 40자·최대 12개 기념일을 명시 저장·불러오기·이름 변경·삭제한다. 저장하는 날짜는 실제 유효한 **원 음력 연도·월·일·윤달 여부**다. 지금 계산된 변환 쌍에서 원 음력 날짜를 얻으며 다른 해의 날짜를 추측해 저장하지 않는다.
- 목록에는 이름·원 음력 날짜·기존 변환 규칙으로 구한 다음 양력 기념일과 대체 여부를 구분해 보여 준다. 다음 날짜는 화면의 현재 날짜 기준으로 다시 계산하며 미지원 범위에서는 날짜를 만들어 내지 않는다. 생년에서 나이나 제사 방식을 추정하지 않는다.
- 자동 복원하지 않으며 최초 공유 URL이 우선이다. 명시 불러오기는 현재 입력 교체를 안내하고 원 음력 날짜/모드와 달력 제목을 적용한다. 17차 캘린더 연도 선택은 이때 초기화해 사용자가 다시 고르게 한다. 이름 변경·삭제는 현재 입력을 바꾸지 않는다.
- 별도 v1 저장 키·정확한 필드·길이·개수·유효 날짜를 검증한다. 손상/미지원/용량/접근 차단/다른 탭 변경을 조용히 덮지 않는다. Web Locks 지원 시 직렬화하고 CAS/readback의 한계를 구분한다. 늦은 불러오기가 새 입력을 덮지 않게 한다.
- 기존 복사의 Clipboard 거부/execCommand(false) 거짓 성공도 최소 보완한다. 실패하면 현재 대상 텍스트를 직접 선택할 수 있게 하고 오래된 복사 안내는 무효화한다. 변환 엔진·윤달/짧은 달 대체 규칙을 변경하지 않는다.

검증: 원 윤달 연도 보존→윤달 없는 올해의 대체 날짜, 30일 짧은 달·지원 첫/마지막 범위, 공유 URL 우선, 명시 불러오기/이름변경/삭제, 17차 ICS 제목·연도 재선택·실제 파일, 저장 실패/2탭/대기 취소, 복사 실패/모바일.

## B. 말하기 기록 이름·검색

- `/speaking-practice/`의 현재 연습에 선택적 이름 40자를 지정하고 기존 ‘기기에 저장’ 동작으로 저장한다. 이름을 비워도 기존 모드/시각 표시로 사용할 수 있다. 이름과 모든 take의 전사문을 대상으로 검색하고 전체/자기소개/업무 보고 필터를 제공한다. 중복 이름은 허용하고 id로 식별한다.
- 기존 이름 없는 v1 기록과 음성 Blob·모든 take·피드백을 유지한다. 목록을 읽는 것만으로 저장하거나 이름을 자동 생성하지 않는다. 이름은 텍스트 내보내기에 포함하되 기존 요약 공유 URL에 추가하지 않는다. 검색/필터/언어 변경은 현재 연습을 교체하지 않는다.
- 이름 변경이 오래된 session 전체를 덮지 않게 IndexedDB의 같은 readwrite 트랜잭션에서 기존 기록의 저장 기준을 확인한 후 쓴다. 신규 저장마다 revision을 부여하고 이후 revision 충돌은 입력을 보존한 채 재조회하도록 한다. 최초 생성은 같은 id의 기존 기록을 덮지 않는다.
- 기존 revision 없는 기록은 불러온 당시 updatedAt을 별도 저장 기준으로 캡처하고 최초 저장 시 revision으로 전환한다. 편집 중 updatedAt과 저장 당시 기준을 혼동하지 않는다. revision을 모르는 옛 탭과의 경쟁을 완전히 보장한다고 표현하지 않는다. 삭제에도 선택한 기록의 저장 기준을 확인해 새 수정본을 조용히 지우지 않는다.
- 저장/목록 재조회 실패·트랜잭션 abort·quota·동시 수정·언마운트/다른 작업의 늦은 완료를 구분한다. 검증이 되지 않은 저장을 성공으로 안내하지 않는다. 기존 기기 내 최대 20개/5take 한도를 유지한다.
- Whisper tiny/기본 점검/선택형 생성 코칭·재녹음 비교·음성/텍스트 반출을 유지한다. 모델 코드·패키지·서버·다운로드 동의 흐름을 바꾸지 않는다.

검증: 실제 IndexedDB의 이전 v1 읽기·선택 이름 저장/빈이름·새 방문·이름/전사 검색·모드 필터·검색결과없음, 음성 Blob과 기존 take/feedback 보존, 두 탭 수정/삭제 충돌과 abort/quota, 수동 입력/첫 take 비교/텍스트 반출·요약 URL. 모델 코드가 그대로이면 대용량 모델 재다운로드를 필수 검사로 만들지 않는다.
