# 20차 독립 브라우저 검증 시나리오

2026-11-17 KST. 제품 부모 연결 및 번역 final ready 전에는 Chrome을 실행하지 않는다. 기존 localhost:3039를 재사용하고 격리 context, 외부 요청 차단, service worker 차단, 단일 Chrome 순차 실행 후 종료한다. 기존 17·19차 통과 전체를 반복하지 않는다.

최종 실제 실행은 음력 7개·말하기 7개, 총 14개다. 아래 초기 계획의 저장/미디어 경계에 독립 검토에서 발견한 ICS 편집 중 불러오기 경합을 추가했다. 결과는 [브라우저 보고서](review-browser.md)를 따른다.

## 음력 기념일 — 7개 시나리오

1. 원 윤달 2025-06-10 저장·새 방문 및 공유 URL 우선. 자동 적용 없이 명시 불러오기로 원 연도/윤달/모드가 복원되고 이름이 ICS 제목에 적용되는지 확인한다. 원 날짜와 올해 대체 날짜는 구분한다.
2. ICS 기존 선택 뒤 같은 기록을 다시 불러와 모든 연도 미선택을 확인한다. 2026년을 명시 재선택해 실제 다운로드를 독립 파싱하고 `DTSTART=20260723`, 제목, 대체 설명을 확인한다. 늦은 SHA 완료도 이전 파일을 내보내지 않아야 한다.
3. 이름 변경·삭제는 현재 입력/ICS 제목/선택을 유지한다. 이름 40자/12개, 원 30일 및 지원 첫·마지막 날짜의 저장 요약을 확인한다. 달력 계산 자체의 전수 회귀는 이전 17차 근거를 재사용한다.
4. 손상/미래 버전/접근 차단/quota/readback 실패와 다시 읽기 복구. 실패한 원문·현재 날짜·이름 입력을 보존하고 성공 안내를 만들지 않는지 확인한다.
5. 같은 context의 실제 두 탭 수정 충돌 및 Web Lock 대기 중 취소/입력 변경. 새 revision과 기존 목록을 보존하고 늦은 불러오기가 최근 입력을 덮지 않아야 한다.
6. 기존 결과/연도표 복사 실패와 수동 전체 선택·늦은 완료, 320px 다크 영어 UI, 16px 입력·44px 조작·원시 키·가로 넘침을 확인한다.
7. 불러오기가 native Web Lock을 기다리는 동안 ICS 제목 수정·연도 선택·선택 전체 해제 각각이 대기 작업을 무효화하는지 확인한다. 새 편집과 원 날짜가 유지되고 이후 새로운 명시 불러오기는 정상 동작해야 한다.

## 말하기 기록 — 7개 시나리오

1. 실제 IndexedDB `toolhub-speaking-practice` v1 `sessions`에 이름/revision 없는 이전 기록을 넣는다. 두 take, WAV Blob, feedback을 포함하고 단순 목록 조회·불러오기 때 DB 원문이 쓰이지 않는지 비교한다. 명시 이름 저장 때만 revision으로 전환되는지 확인한다.
2. 선택 이름/빈 이름·중복 이름 ID 구분, 이름/모든 take 전사문 검색·모드 필터·검색 결과 없음·새 방문. 검색/언어 변경이 현재 연습을 교체하지 않아야 한다.
3. 수동 입력과 첫 take 비교·기존 feedback/음성 Blob 보존. 실제 TXT 다운로드에 이름이 있고 공유 URL에는 이름/전사문이 없는지 확인한다. 실제 audio download byte를 fixture와 비교한다.
4. 실제 같은 origin 두 탭이 같은 basis로 저장한 뒤 두 번째 저장/삭제가 충돌하는지 확인한다. 목록 새로 읽기만으로 편집 중 basis를 최신값으로 올려 충돌을 우회하지 않아야 한다.
5. native IndexedDB transaction abort와 주입 quota 오류, 목록 읽기 오류·재조회 복구. 쓰기 성공은 native transaction commit 이후에만 인정한다.
6. 실제 write commit 뒤 목록 `getAll`만 실패시키고 DB는 새 revision임을 확인한다. 저장됨/목록 재조회 실패 안내를 구분하고 다음 편집 저장이 올바른 basis로 성공해야 한다. native readwrite transaction을 유지해 늦은 완료/다른 작업 경계도 가능한 UI 범위에서 확인한다.
7. 손상/미지원 기록의 물리 보존·목록 안내, 20개 한도·5 take 기존 경계에서 영향 범위를 확인한다. 320px 다크 영어의 이름/검색/필터/실패 복구, 16px·44px·JS/hydration을 수집한다.

## 증거와 한계

실제 IndexedDB·Blob·다운로드·Web Locks와 오류 주입을 분리해 기록한다. 검증용 WAV는 작은 로컬 합성 데이터이며 실제 사용자 녹음·모델 서버에 접근하지 않는다. ASR/생성 코칭 코드 변경이 없으면 대형 모델 다운로드나 정확도 검사를 추가하지 않는다. old revision 없는 탭이 guarded API를 우회하는 쓰기까지 완전한 원자성을 보장한다고 쓰지 않는다. product final selector에 맞춰 시나리오를 합치거나 나누되 필요한 경계만 실행한다.
