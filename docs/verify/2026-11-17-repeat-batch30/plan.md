## 코드에서 확인한 불편

`src/components/PomodoroTimer.tsx`는 1초 interval마다 `Math.round((now-lastTick)/1000)`을 빼고 lastTick을 현재 시각으로 바꾼다. 개별 tick마다 반올림하므로 반복 지연의 소수 초가 누적 보존되지 않는다. 일시정지 역시 마지막 표시 이후 경과한 시간을 먼저 확정하지 않는다. 현재 `Date.now` 기반 보정이 전혀 없는 것은 아니며, 단순 interval 카운터라고 설명하지 않는다.

저장된 실행 중 세션을 복원할 때 이미 만료됐으면 `timeLeft=0, isRunning=false`가 되어 완료 처리와 다음 단계가 실행되지 않는다. 화면은 정지한 0초 상태가 되고, 사용자가 시작 버튼을 누른 뒤에야 이전 단계를 현재 날짜의 통계에 더할 수 있다. 장시간 부재 중 집중을 실제 수행했다고 추정하거나 여러 단계를 소급 생성해서는 안 된다.

settings/tasks/timerState는 `JSON.parse(...) as T`만 사용한다. 잘못된 구조·null·미지원 phase·유효하지 않은 수치도 런타임 상태로 들어갈 수 있고 이후 자동 저장이 원본을 덮을 수 있다. 기존 목표/일별 통계의 엄격한 parser·CAS 정책과 달리 이 세 저장 키에는 구조 검증이 없다.

## 최소 제안

- 실행 중 현재 단계의 기준 시각·남은 밀리초를 단일 소유자가 관리한다. 화면 tick은 남은 초를 표시하는 역할만 하며 일시정지/재개/건너뛰기/단계 리셋/설정 적용이 먼저 현재 시점을 확정한다. 같은 방문에서는 단조 시계 기준, 재방문 경과 계산에는 검증된 저장 시각을 사용한다. 시스템 시계가 바뀐 경우의 정책을 별도로 명시한다.
- 늦은 interval/visibility/완료 callback은 단계 ID·세대로 거부한다. 같은 단계의 완료→통계·할 일 증가·알림·다음 단계 전환은 한 번만 호출한다. StrictMode·자동 시작·완료 직전 건너뛰기/리셋에서도 중복 증가하지 않는다.
- 탭이 늦게 깨어났을 때 현재 단계 하나의 만료만 처리한다. 보지 못한 휴식/다음 집중 여러 회차를 소급 생성하지 않는다. 백그라운드나 OS 절전에서 정시에 알림이 실행된다고 보장하지 않는다.
- 재방문 시 아직 유효한 실행 상태는 기존 복원 경험을 유지한다. 이미 만료된 저장 상태는 명확한 복귀 안내와 다음 단계 시작을 제공하며, 부재 시간을 자동으로 당일 집중 기록에 더하지 않는다. 과거 기록을 추가하는 기능은 별도 요구와 중복 방지 설계 없이 넣지 않는다.
- 세 기존 저장 키를 각기 검증한다. 현재 정상 legacy JSON은 계속 읽고 이름·설정·할 일 원문을 보존한다. 부정확한 값의 조용한 보정/초기값 덮어쓰기는 하지 않는다. 손상/접근 불가 상태는 안내하고 해당 자동 저장만 막으며 타이머의 메모리 내 사용은 유지한다. 사용자가 원본을 버리는 동작은 명시 확인한다.
- 실행 상태를 매초 직렬화할 필요가 있는지 검토하고 시작/일시정지/전환/visibility/pagehide 체크포인트로 줄이되, 재방문 정확성을 유지한다. 저장 실패를 성공으로 표시하지 않는다. 여러 탭이 같은 타이머 저장본을 덮지 않도록 충돌 정책을 실제 부모 연결 전에 확정한다.
- 기존 목표·7일 CSV·통계 잠금/복구·할 일 목록·알림 권한 요청·설정 범위는 유지한다. 기록 저장 형식 변경이 필요하면 이 후보를 별도 설계 단계로 돌리고 기존 통계 bytes를 먼저 보존한다.

## 검증 조건

독립 시계 모델로 1.4초 간격의 반복 tick, 큰 시간 점프, 0.5초 이내 일시정지/재개, 경계에서 reset/skip/autoStart를 비교한다. 실제 부모에서 단계별 완료 호출 수·할 일/통계 증분·이전 callback·StrictMode·언마운트·새로고침 복원을 확인한다. legacy 정상/손상/미지원/저장 불가/다른 탭 변경을 구분하고 저장 원문 보호를 검사한다.

브라우저에서는 제어된 시계·가짜 알림/음향 포트로 복귀 안내와 기본 기능을 확인한다. 실제 사용자에게 소리를 재생하거나 알림을 보내지 않는다. KO/EN·320px 및 기존 PomodoroGoalPanel 저장/CSV 회귀 후 전체 타입 검사로 완료한다. 빌드·배포·커밋은 실행하지 않는다.
