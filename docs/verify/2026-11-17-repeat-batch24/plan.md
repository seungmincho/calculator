## A. PDF 페이지 정리 undo/redo

`/pdf-tools/` 페이지 정리의 이동·개별/전체 회전·삭제·전체 원상복원을 최대30개 메모리 전이로 되돌리기/다시 실행한다. 원본 File/PDF 바이트를 이력마다 복제하지 않고 기존 카드의 안정 key·원본 페이지·회전·크기만 보존한다. 새 문서의 성공한 로드는 새 이력 기준이며 실패한 읽기는 현재 문서/편집을 지우지 않는다. no-op은 이력을 만들지 않고 undo 뒤 새 편집은 redo를 버린다.

- 기존 회전/원상복원/드래그·버튼 이동·키보드와 전체 삭제 오류를 유지한다. 삭제/undo/redo 뒤 초점은 존재하는 카드 또는 사용 가능한 이력 버튼으로 보낸다. 편집 입력의 native undo와 IME 이벤트를 가로채지 않는다.
- 각 반출은 클릭 당시 파일/카드 목록 snapshot을 사용한다. 원본 PDF 회전과 추가 회전을 합산하고 실제 출력 순서/내용을 확인한다. 완료 후 다시 편집하면 이전 결과는 무효화해 현재 편집본으로 표시하지 않는다.
- 공통 작업 세대를 도입해 다른 탭/새 읽기/새 작업/새 편집/언마운트 뒤 늦은 읽기나 생성 완료가 입력·상태·자동 다운로드를 만들지 않게 한다. pdf-lib 연산 자체를 강제 종료한다고 설명하지 않는다. 탭을 바꿀 때 다른 탭이 보관한 정상 입력을 지우지는 않는다.
- 이 경계는 공통 finish/readPdfs 및 기존 병합·분할·이미지PDF 호출부도 일관되게 적용하고 관련 회귀를 확인한다. 복사본 PDF에 원래 없던 북마크·주석·폼 보존을 새로 보장하지 않는다. 새로운 렌더러/페이지 복제/서버 처리는 없다.

검증:30회 한도/no-op/redo 폐기/회전·삭제·순서·리셋 복원, 새 문서 실패/늦은 결과, 실제 여러 페이지 PDF의 출력 페이지 내용·순서·회전 재읽기, 탭 전환 중 작업과 늦은 다운로드 차단, 병합/분할/이미지PDF 회귀, KO/EN·320px·초점.

## B. 비밀번호 결과 한 항목만 다시 만들기

`/password-generator/`의 생성 결과마다44px ‘이 항목 다시 만들기’를 추가한다. 일반 비밀번호/PIN/단어 조합의 현재 설정으로 그 위치 하나만 교체하고 나머지 결과는 그대로 둔다. 설정 변경과 전체 재생성은 기존처럼 전체 갱신한다. 강도 확인 탭의 입력은 건드리지 않는다.

- 기존 암호학적 난수·옵션 검증·단어 목록·엔트로피 계산을 그대로 쓴다. 우연히 같은 값이 나오는 것을 허용하며 중복 방지/반드시 다른 값/보안성 강화라고 표현하지 않는다.
- 앱 표시 언어만 바뀌어 생성 결과가 자동 재생성되지 않게 한다. 생성과 번역된 안내의 의존성을 분리한다. 한 항목 재생성 후 해당 위치의 버튼 초점을 유지하고, 값 자체를 React row identity로 삼아 초점이 사라지는 경계를 피한다.
- 개별/전체 복사의 실제 성공만 체크 아이콘을 표시한다. Clipboard 거부·legacy false는 실패와 수동 선택·재시도를 제공한다. 재생성/설정 변경/탭 이동/언마운트 뒤 오래된 복사 안내/복구 대상을 무효화한다.
- 생성 결과 및 강도 확인 입력은 URL·저장소·로그·외부 요청에 추가하지 않는다. 기존 설정 URL과 기본 생성 동작을 유지한다. 새 내보내기/비밀번호 보관 기능은 없다.

검증: 한 위치 교체와 나머지 동일성, 세 생성 모드 옵션/무효 옵션, 기존 생성기 회귀, 복사 차단/legacy false/늦은 성공·실패/재생성과 경합, 실제 현재 결과 복사 및 수동 선택, 설정 URL/원문 비저장, KO/EN·320px.
