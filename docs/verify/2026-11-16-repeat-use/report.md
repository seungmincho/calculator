# 기존 도구 재방문 기능 — 구현·검증

2026-11-16, 로컬 Next 개발 서버 3039. 빌드·배포·커밋·푸시는 실행하지 않았다.

## 구현

- **음성 메모**: `VoiceMemo.tsx`, `voiceMemoStorage.ts`. 제목·전사문 검색, 수정, TXT/오디오 다운로드, IndexedDB 저장/복원/삭제. 명시적으로 전사를 눌러야 Whisper tiny 워커가 실행되며 종료 후 모델 메모리를 해제한다. 공유 `decodeSpeakingAudio`는 호출별 길이 한도를 받도록 확장했고 말하기 연습실의 기존 90초 기본값은 그대로다. 모바일 입력 16px, 주요 조작 44px 이상, 기본 녹음 버튼 첫 화면 표시. 녹음 중 일시정지 시간은 저장된 길이에서 제외한다. 실제 지원 MIME으로 파일을 저장하고 MP4에도 대응한다. 브라우저 녹음 종료 시 타이머·마이크·AudioContext를 정리한다.
- **TTS**: `TextToSpeech.tsx`. 반복 시작/끝, 횟수, 쉬는 간격. 반복 구간 밖 문장으로 이동하지 않도록 제한한다. 쉬는 시간 중 일시정지/정지 시 타이머를 취소하고 이전 콜백이 재생을 다시 시작하지 못하게 한다. 재개는 해당 회차 문장부터, 원고 편집은 정지 및 반복 해제. 기존 목소리·속도 저장과 원고/속도 링크 공유는 유지한다. 반복 설정은 현재 페이지에만 적용한다.
- **팀 나누기**: `TeamDivider.tsx`, `teamRosters.ts`. 명단 저장/불러오기/명시적 덮어쓰기/삭제 확인. 이름·실력·팀 수·모드를 복원하고 예전 편성 결과는 초기화한다. 저장소 예외·중복·한도를 검사한다. 다른 탭의 저장소 변경도 반영한다. 모바일 결과 바로가기와 한 열 결과 배치. 동적 로드 시 가이드의 서버/클라이언트 ID가 달라지던 문제는 이 가이드에 안정적인 `panelId`를 제공해 해결했다.
- ko/en 원본 문구와 생성본 갱신, 도구 소개/메타데이터, 메뉴 `updatedDate`, RSS·redirects·llms 갱신. 새 패키지는 추가하지 않았다.

브라우저 시나리오 ([결과 JSON](results.json)):

1. 오디오 가져오기 → 전사문 수동 편집 → 저장 → 새로고침 → 제목/전사문 검색 → TXT 다운로드 → 재생 → 영구 삭제.
2. **실제 MediaRecorder** 녹음 → 일시정지 → 재개 → 중지 → 저장: 일시정지 시간을 제외한 길이와 Blob 확인.
3. ASR 워커 스텁으로 버튼 클릭 전 워커 미생성, 전사 결과 반영, 취소, 181초 파일 거부, 무음 거부 확인.
4. IndexedDB 저장 실패 주입: 원음·편집문 유지, 다운로드 가능, 거짓 저장 성공 표시 없음, 임시 메모 삭제 가능.
5. TTS 이벤트 스텁: 선택한 두 문장만 정확히 2회 재생, 자동 종료, 원고 편집 시 반복 해제.
6. TTS 이벤트 스텁: 쉬는 시간 중 일시정지/재개/정지 후 오래된 타이머로 소리 재시작 없음.
7. 실력·팀 수가 있는 명단 저장 → 새로고침 복원 → 실제 3팀/6명 편성 → 덮어쓰기 → 삭제 취소/확정.
8. 잘못된 저장 데이터가 있어도 화면이 동작하고 기존 데이터를 임의로 덮어쓰지 않음.
9. 320px 밝은 화면: 세 도구 가로 넘침·번역 키 노출·모델 자동 다운로드 없음.
10. 320px 어두운 화면 및 영어 내비게이션 설정에서도 동일 확인. **도구 본문은 기존 동기 번역 레지스트리 정책상 한국어**, 영어 원본 번역 키는 함께 유지했다.

실모델은 기존 한국어 샘플과 격리된 모델 캐시를 사용했다. 실제 전사 결과·요청 내역은 [whisper-result.json](whisper-result.json). 측정된 약 3.7초는 이 데스크톱의 캐시 재사용 조건이며 최초 다운로드나 휴대폰 속도를 의미하지 않는다. 음성 인식 오탈자가 관찰되어 UI에 검토·수정 안내를 제공한다. 테스트에서 방문 통계/광고 요청은 차단·분리했으며 전사 과정에 음성 업로드는 없다.

## 확인 범위

실제 iPhone/Android의 마이크 권한, Safari MP4 녹음, 기기별 한국어 음성, 장시간·백그라운드 동작은 별도 기기 확인이 필요하다. TTS 반복 순서는 결정적 음성 합성 스텁으로 확인했으며 이번 검증에서 실제 스피커 출력을 청취하지 않았다. 프로덕션 정적 HTML/빌드는 요청이 없어 실행하지 않았다. 저장 기록과 모델 캐시는 브라우저가 삭제할 수 있으며 중요 기록의 파일 다운로드를 안내한다.
