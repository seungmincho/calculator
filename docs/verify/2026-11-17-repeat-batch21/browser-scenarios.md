# 21차 독립 브라우저 검증 계획

2026-11-17 KST. 제품 final ready와 공용 번역 병합 후 해당 도구부터 실행한다. 기존 localhost:3039, 격리 context와 외부 요청/service worker 차단, 단일 Chrome 순차 검증을 유지한다. 전체 타입 검사는 Chrome 종료 뒤 통합 담당이 실행한다.

## 텍스트 변환 — 6개

1. `trimLines → dedupe`와 반대 순서의 실제 출력 차이. 이동·개별 삭제·전체 초기화와 undo/redo가 원문/작성 중 치환 입력을 보존하는지 확인한다.
2. 다른 옵션의 중복 단계 위치, regex flags·앞뒤 문자열·shuffle seed를 undo/redo·순서 이동 뒤 유지한다. seed 보존은 결과의 결정성으로 검사하며 공유 URL이 seed까지 저장한다고 주장하지 않는다.
3. 30개 이력 상한, no-op의 redo 보존, undo 뒤 새 편집의 redo 폐기. 자기 URL 동기화가 이력을 초기화하지 않아야 한다.
4. 기존 `ops` URL 최초 복원과 실제로 다른 외부 query 복원의 새 기준. 같은 query의 popstate 및 실제 앵커 뒤로/앞으로는 private 단계·shuffle 결과·undo/redo를 보존한다. 현재 원문/치환 draft 유지, 원문/찾기/치환/affix 문자열이 URL에 추가되지 않는지 확인한다.
5. 잘못된 regex와 기존 100,000자 REGEX_MAX 오류가 해당 단계에 표시되고 다른 단계/undo를 계속 사용할 수 있어야 한다. 큰 입력은 이전 검증에서 안정적이었던 native Clipboard paste를 사용한다.
6. 320px 다크 영어, 원시 키·16px·44px·가로 넘침, 행 이동 뒤 실제 focus, Alt+방향키와 패널 범위 undo/redo. 편집 입력/IME에서는 단계 단축키를 가로채지 않아야 한다.

## QR 이미지 — 약 7개

1. 기존 `qrcode`와 설치된 `pngjs`로 한글/줄바꿈/동일 내용·다른 파일명/동일 파일명의 실제 PNG를 생성한다. native 미지원 상태에서 사용자가 시작하기 전 Worker 0개, 시작 후 자체 번들 Worker 실제 픽셀 디코딩과 순서·결과를 확인한다.
2. 두 QR을 합성한 실제 이미지에서 유효한 payload 하나만 반환함을 확인한다. 공간상 첫 위치나 QR이 유일하다는 판정은 하지 않는다. 흰 이미지·손상·비지원·과대 파일과 정상 파일을 섞어 행별 실패를 보존한다.
3. 10/11개, 8MiB/40MiB·원본 픽셀 상한의 거부와 기존 목록 유지, 선택 취소/새 선택. 헤더 상한은 브라우저가 거대 원본을 디코딩하기 전에 거부하는지 확인한다.
4. native detector 성공은 Worker를 만들지 않고, 미검출/생성·실행 실패는 실제 Worker로 한 번 이어지는지 확인한다. 제어한 native 결과와 실제 jsQR 픽셀 결과를 보고서에서 구분한다.
5. 지연한 native Worker 전달 또는 image 읽기 중 취소/탭 변경/새 선택, 오래된 완료 무효화와 실패 항목 재시도. 성공 행과 TXT 선택 보존·Worker terminate/object URL 정리를 확인한다. 시간 제한은 제어한 API와 가상 clock으로 검사한다.
6. 실제 TXT 다운로드를 UTF-8 바이트로 비교해 파일 순서/표시 번호/파일명/원문 공백·개행을 확인한다. 기본 선택 없음, 명시 선택만 포함, HTML/비http URI의 비실행, 복사 실패/수동 선택/늦은 fallback을 검사한다.
7. 기존 단일 스캔/최근 기록 보존과 손상 원문 보호, 카메라 탭 변경·늦은 승인 뒤 tracks 종료, 320px 긴 내용/다크 영어. 카메라 테스트는 로컬 합성 MediaStream과 제어한 detector를 사용하며 실제 카메라 인식 성능 검사로 표현하지 않는다.

부모 selector와 최종 지원 형식/시간 정책이 확정되면 필요한 경계 중심으로 합치거나 나눈다. 제품 dependencies 설치·생성 메시지 수정은 담당자만 수행한다. 검증 fixture에만 기존 로컬 패키지를 사용하며 QR 내용이나 이미지 원본을 외부로 보내지 않는다.

최종 6+7=13개 실제 브라우저 사례를 수행했다. 실제 파일/바이트·native Worker 증거, 제어한 API 경계 및 실행하지 않은 범위는 [결과 보고서](review-browser.md)를 따른다.
