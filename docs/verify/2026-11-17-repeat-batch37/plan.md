## 확인한 사용자 불편과 경계

- `AspectRatio.tsx`의 이미지 채우기는 가운데 crop만 제공한다. 세로 썸네일로 자를 때 사진의 주인공이 한쪽에 있으면 위치를 옮길 수 없다. 기존 crop/pad·검정/흰색 여백·비율 잠금·규격/해상도 표·공유는 유지할 대상이다.
- `loadFile`은 MIME `image/*`만 확인하고 새 Image를 만든다. A/B 교체·지우기 뒤 늦게 도착한 A.onload를 차단하지 않아 이전 이미지가 돌아올 수 있다. 실패한 새 이미지 안내가 없고 decoded 픽셀·입력 파일 크기 제한도 없다. 이 부분은 코드 근거이며 실제 브라우저 재현 전이다.
- 출력은 긴 변8192만 제한하므로8192² 이미지는 약6711만 픽셀이다. `toBlob` 콜백에 현재 이미지/옵션/언마운트 소유권 검사가 없어 수정 전 파일이 늦게 내려갈 수 있다. 실패0/진행 안내0, canvas 메모리 해제도 명시적이지 않다.
- `parseRatio('9'.repeat(400)+':1')`가 Infinity를 반환하고 `reduceRatio(Infinity,1080)`는 재귀 RangeError가 난다. [읽기 재현](check-aspect-existing-boundaries.mjs)을 실제 기존 모듈로 실행해 확인했다. UI 일반 입력/공유 hydration을 브라우저에서 확인한 결과와 구분한다.
- 복사는 Clipboard 예외와 legacy false도 성공 표시한다. 이전 Promise/성공 타이머와 현재 입력 간 보호가 없다.

## 최소 구현 제안

1. crop 모드에 가로·세로 위치0~100%를 추가한다. 기본50/50은 현재 중앙과 동일하다. 먼저9위치 버튼+두 슬라이더로 키보드/터치 조작을 보장하며, 드래그는 필수 범위에 넣지 않는다. 원본에서 실제 잘리는 여유 범위에 위치 비율을 곱해 source rect를 얻는다. 해당 축에 여유가 없으면 조작 비활성/설명. pad는 기존 가운데 정렬을 유지한다. 이미지 파일은 URL/저장소/서버에 넣지 않는다.
2. preview와 export가 같은 geometry 함수를 사용하고, 위치는 이미지 교체 시 중앙으로 초기화한다. 동일 이미지의 비율 변경은 선택 비율을 보존한다. 안전 영역 오버레이는 기존 참고 표시만 유지하며 이미지 파일에 그리지 않는다. 플랫폼별 최신 규격이나 안전 영역 수치를 이번 작업에서 새로 주장하지 않는다.
3. 공용 QR header 검사와 `imageCompress.decodeImage`를 재사용할 수 있는지 먼저 확인한다. 제안 입력 PNG/JPEG/WebP/GIF 정지 프레임·8MiB·16MP, 교체 파일 실패 시 마지막 정상 이미지는 남긴다. SVG/HEIC 등 미지원은 실행 가능한 형식 안내와 기존 이미지 보존으로 처리한다. 지원 목록 변경은 화면/번역에 명확히 표시한다. EXIF 실제 orientation·decode 실패·닫기 자원 소유권을 검증한다.
4. 출력은 최대 긴 변8192 및1600만 픽셀 두 제한을 모두 지킨다. 실제 출력 크기를 다운로드 버튼 근처에 보여 주고 자동 축소를 숨기지 않는다. 반올림 뒤 픽셀 수·0변 검증을 다시 수행한다. 계산용 치수/커스텀 비율은 유한한 양수·안전 정수/명시 범위를 정해 비정상 입력을 결과로 내지 않는다. 정확한 숫자 상한은 구현 설계에서 기존 유효 프리셋/잠금/URL과 함께 확정한다.
5. 읽기/디코드/내보내기는 세대와 실제 finally가 소유한다. 취소 후 늦은 decode/toBlob은 현재 미리보기·다운로드·오류를 바꾸지 않고 자신이 만든 Bitmap/URL/canvas만 정리한다. 연속 다운로드 중복을 막고 실패하면 현재 이미지로 명시 재시도한다. PNG 원본은 PNG, 기타 지원 래스터는 기존 JPEG 선택을 유지한다.
6. 치수·비율·CSS 복사는 현재 결과를 대상으로 실패/수동 선택/재시도를 제공한다. native 성공 또는 legacy true만 성공, 현재 입력/언어/언마운트에서 늦은 안내를 무효화한다. 별도 장기 저장은 만들지 않는다.
7. 기존 w/h/lock/zone 공유를 정적 본문과 일치하게 최초 hydration 후 복원한다. 명시 위치 공유를 추가한다면 숫자 위치만 제한하고 파일명/파일 원문은 넣지 않는다. 16px 입력·44px 조작·320px KO/EN과 현재 결과 바로가기를 유지한다.

## 완료 조건

독립 geometry oracle로 가로/세로/동일 비율과9위치·임의 슬라이더를 비교한다. 합성 색 구역 사진의 실제 PNG/JPEG 픽셀·치수·안전 영역 미포함, EXIF orientation, 원본보다 작은/큰 목표, 출력 픽셀 한도, A/B 교체 및 지우기/실패/언마운트/늦은 toBlob을 검증한다. 숫자 Infinity/NaN/아주 긴 비율·0·음수·범위 밖, 기존 계산 회귀, 공유 재방문/정적 hydration, 복사 실패·언어·모바일도 포함한다. 브라우저와 전체 타입은 기존 단일 소유권을 따른다. 빌드·배포·커밋은 실행하지 않는다.

현재는 위 결함 재현과 계획만 있으며 제품 구현·실제 파일·브라우저 검증 완료가 아니다.
