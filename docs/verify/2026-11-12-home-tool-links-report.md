# 홈 추천과 관련 링크 운영 검증 결과

2026년 11월 12일 14시 52분(KST), `toolhub.ai.kr`에서 [검증 시나리오](2026-11-12-home-tool-links-scenarios.md) 5건을 모두 통과했다.

| 위치 | 운영에서 확인한 결과 |
|---|---|
| 홈 추천 | 초기 HTML의 추천 섹션에 택배비 계산기, 음력 양력 변환기, 평수 계산기 링크가 이 순서로 있었다. 모바일 화면에서 각 링크를 눌러 해당 도구 제목을 확인했다. 홈에 돌아온 뒤에도 세 링크가 같은 순서로 보였다. |
| 마진 계산기 | 본문의 ‘택배사별 배송비 비교’를 누르면 `/shipping-calculator/`가 열렸다. |
| 나이 계산기 | 본문의 ‘음력 생일을 양력 날짜로 변환’을 누르면 `/lunar-converter/`가 열렸다. |
| 중개수수료 계산기 | 본문의 ‘전용면적 ㎡를 평으로 환산’을 누르면 `/pyeong-calculator/`가 열렸다. |
| 사이트맵 | 공개 `/sitemap.xml`에서 `<loc>https://toolhub.ai.kr/</loc>` 항목의 `lastmod`는 `2026-11-12`였다. |

14시 47분에는 운영 사이트맵에 이전 홈 날짜인 `2026-09-16`이 있었다. 14시 52분 25초에 쿼리 없는 홈·출발 페이지 3개·사이트맵이 모두 HTTP 200으로 새 내용을 반환했다. 14시 52분 50초에는 새 Chromium 세션(390 × 844 CSS 픽셀)에서 링크 6개의 이동과 사이트맵 확인을 마쳤다.
