## 확인한 코드 경로

`src/app/order-picker/OrderPickerClient.tsx`는 `DecisionTools initialTab="order" single`을 사용한다. `DecisionTools.startOrder`는400ms 뒤 기존 `shuffle(orderItems)`로 순서를 한 번 만들고,500ms마다 공개 수를 늘리는 await 루프를 실행한다. `revealAll`/`resetOrder`는 state만 바꾸고 이전 루프를 취소하지 않는다. 따라서 전부 공개/초기화 뒤 늦은 루프가 공개 수·결과 상태를 다시 변경할 수 있다. 이는 소스에서 확인한 경합이며 아직 사용자 브라우저 재현 결과라고 보고하지 않는다.

추첨 중에도 명단 추가/삭제가 가능하고 완료 뒤 명단 변경이 기존 결과를 지우지 않는다. 결과가 현재 참가자 목록의 것인지 불분명해질 수 있다.

같은 파일의 룰렛·순서 복사는 native 실패 뒤 `execCommand('copy')`의 반환값을 확인하지 않고 성공 표시한다. 새 결과/재추첨/초기화 이후 늦게 끝난 복사와 성공 타이머도 이전 결과를 현재 상태처럼 표시할 수 있다. 메뉴 계획의 복사(`MealPlanPanel`)는 별도 구현이며 이번 후보에서 이미 확인된 반환값 검사를 제거하거나 통째로 바꾸지 않는다.

## 제안 경험과 최소 범위

- 순서 공개는 기존 자동 공개를 기본으로 유지하고 ‘한 명씩 공개’를 선택할 수 있게 한다. 새 추첨 시 단 한 번 만든 순열을 방문 메모리에 보관한다. 수동 모드에서 ‘다음 한 명’은 다음 카드만 열고 다시 추첨하지 않는다. ‘모두 공개’는 현재 결과를 끝까지 공개한다.
- 작은 순수 상태·세대 컨트롤러가 `idle/shuffling/revealing/complete`와 snapshot/공개 수를 소유한다. 자동 루프에는 취소/세대를 두고 전체 공개·초기화·새 추첨·명단 변경·탭 전환·언마운트 뒤 이전 callback을 거부한다. 공개 수는 같은 추첨에서 감소하지 않는다.
- 자동→수동 전환은 현재 순서/공개 수를 보존하고 예약만 취소한다. 수동→자동은 다음 카드부터 이어 간다. 이미 끝난 결과에서 모드를 바꿔도 순서를 다시 뽑거나 숨기지 않는다.
- 추첨/공개 도중 명단 편집을 잠근다. 완료 뒤 명단을 바꾸면 이전 결과·복사 안내를 무효화한다. 동일한 이름을 다른 사람으로 쓸 수 있는 기존 동작은 유지하고 순열의 중복 항목 개수도 보존한다. 기존 암호학적 난수 Fisher–Yates `shuffle`은 바꾸지 않는다.
- 공개 진행은 버튼 초점을 유지하고 간결한 live 안내를 제공한다. `prefers-reduced-motion`에서는 장식 전환을 줄이되 순서·공개 정책은 같다. 모바일16px 입력·44px 조작·이름 줄바꿈과 내부 카드 폭을 적용한다. 손가락 스와이프나 드래그를 필수로 만들지 않는다.
- 룰렛/순서 결과 복사는 요청 당시 문자열 snapshot을 사용하고 native 또는 legacy true만 성공으로 표시한다. 실패하면 원문 선택/재시도, 취소·닫기·현재 결과 변경·언마운트 경합을 처리한다. 성공 알림 타이머도 현재 요청 세대만 수정한다.
- 완전히 공개된 순서는 UTF-8 TXT 다운로드를 제공한다. 숨긴 순서를 복사/TXT로 먼저 노출하는 동작은 기본 제공하지 않는다. 파일명에는 참가자 이름을 넣지 않는다. 룰렛 이미지 저장·식사 기록/최근 제외·주간 계획·현재 공유 URL 형식은 유지한다.
- 참가자 이름/추첨 결과의 새로운 장기 저장·서버 전송·URL 추가는 하지 않는다. 기존 명시 공유 동작은 보존한다. 새 경로나 패키지는 필요하지 않다.

## 검증

순수 모델과 실제 부모 이벤트로 shuffle 호출1회/중복 포함 순열 보존, 자동·수동·전부 공개·초기화·모드 전환·늦은 callback·언마운트를 확인한다. RNG를 고정한 합성 명단으로 재현하고 실제 사용자 명단은 쓰지 않는다.

브라우저에서는 자동 공개 중 모두 공개/초기화 뒤 충분히 기다려 되돌아가지 않는지, 수동 공개·키보드·44px·320px KO/EN을 검사한다. 결과 TXT의 전체 순서와 native clipboard를 비교하고 거부/legacy false/manual retry·새 룰렛 결과/목록 변경 후 지연 복사도 확인한다. 메뉴 모드의 기록/주간 계획 저장 bytes·제외 후보와 기존 이미지 다운로드는 영향 회귀만 실행한다.

제품 담당 한 명이 공용 DecisionTools와 ko/en 조각을 함께 소유한다. 독립 검토·단일 Chrome·공용 번역/메타·전체 타입 체크포인트 뒤 완료로 기록한다. 빌드·배포·커밋은 실행하지 않는다.
