# 27차 독립 브라우저 계획

26차 14/14 기능 검증과 타입 체크포인트 종료 뒤 준비한다. **현재 부모 final ready 대기이며 Chrome을 열지 않는다.** 준비 코드/문서만 작성하고 제품 TS·서버·패키지·빌드·전체 타입 검사는 변경하지 않는다. 부모 최종 변경과 공용 번역 준비를 확인한 뒤 root에 Chrome 시작을 알린다. 기존 localhost:3039, 한 Chrome, 순차 격리 컨텍스트, 서비스워커/외부 요청 차단, 합성 데이터만 사용한다.

## 세계시계 7흐름

1. **초 단위 URL·도시 순서·입력 우선순위** — 서울/뉴욕/UTC의 고정 epoch 초를 URL로 방문한다. 선택 결과·복사 링크·새 방문·ICS가 같은 순간이며, 분/초가 표 슬롯으로 반올림되지 않아야 한다. 도시 위/아래 이동·locale 변경은 epoch를 유지하고 기준 도시의 날짜만 달라진다. 유효 URL 도시가 저장 도시보다 우선한다. `at=0`·음수·잘못된 epoch/도시 ID는 대표 경계로 확인하고 렌더 예외가 없어야 한다.
2. **DST 두 번의 01:30:45와 실제 날짜 길이** — 뉴욕 2026-11-01T05:30:45Z/06:30:45Z를 각각 표시하고 UTC-04/UTC-05 구분 및 epoch 유지. 같은 날짜25슬롯과 봄2026-03-08의23슬롯을 검사한다. 명시 표 클릭만 해당 슬롯 시작으로 이동하며 날짜 변경의 기본 선택/URL이 일치한다.
3. **반시간 날짜·45분 업무 교집합·자정 경계** — Lord Howe의 23.5/24.5시간 날짜는 마지막 부분 슬롯을 포함한 실제 길이로 검증한다. 서울/카트만두의 월요일09~18시 교집합은 UTC03:15~09:00(5시간45분)이고 칸 시작 개수로 반올림하지 않는다. UTC 날짜 경계 및 끝 포함/제외를 대표 확인한다. 모든 역사적 시간대 전체를 검증했다고 주장하지 않는다.
4. **실제 ICS 바이트와 한글 제목** — 30/60/90/120분 중 대표 길이·초 포함 DTSTART/DTEND·자정 넘김을 실제 다운로드로 읽는다. 독립 unfolding/property parser와 Node SHA-256으로 UID identity, CRLF/noBOM, UTF-8 75octet folding, TEXT escape, 한 VEVENT 및 불필요한 alarm/attendee 없음 확인. 제목은 URL/기기 저장/외부 요청에 남지 않아야 한다. 재반출/locale/도시 순서에서도 같은 일정 UID 유지.
5. **느린 SHA·실패·현재 선택 보호** — native digest의 완료만 제어해 제목/길이/순간/도시/locale 변경·이탈 뒤 이전 파일/성공 안내0을 검사한다. 실패 시 입력 유지 및 명시 재시도 성공. 연도 끝에서 종료 시각 범위 초과는 다운로드 없이 오류로 처리한다.
6. **실제 복사·수동 복구·경합** — native Clipboard의 텍스트/링크를 현재 epoch와 대조. API 거부/legacy false→읽기 전용 전체 선택→재시도, 결과 pending 뒤 링크 복사 등 새 요청이 이전 fallback/안내에 덮이지 않는지 확인한다.
7. **320px KO/EN·기존 화면** — 결과·표·도시 선택/순서·길이/제목·수동 복구를 320px 다크에서 확인한다. 수정 입력16px·주요 버튼44px·가로 overflow·원시 키·JS/hydration을 수집하고 현재 시각/기존 시계 표시가 미팅 선택을 임의로 변경하지 않는지 확인한다.

## 백색소음 7흐름

8. **native 무음 오디오와 기한** — mount/저장 목록 읽기 AudioContext0, 명시 재생만 생성. native source/gain/stop은 사용하되 gain의 destination 연결을 별도0 gain sink로 보내고 Chrome mute도 켜서 물리 출력은 차단한다. 지연 wall/monotonic 관찰·동일 타이머·종류/음량 변경의 기한 유지, 다른 타이머의 지금부터 재설정, 무기한과 음량0을 구분한다.
9. **mute-before-resume·만료·옛 완료** — 실제 context를 suspend한 뒤 resume Promise의 전달만 지연한다. 기존 gain0 설정이 native resume 호출보다 앞서고 preparing 중 statechange/음량/fade는0을 풀지 않아야 한다. 완료 후 최신 gain만 복원, 기다리다 기한이 지났거나 stop/새 attempt/이탈이면 기존 source를 정리하고 늦은 resolve/reject/ended는 현재 상태를 바꾸지 않는다. 시작 거부/준비 timeout도 명시 실패로 확인한다.
10. **OfflineAudioContext 실제 파형** — 제품 audio adapter와 plan 유틸을 test-only transpile해 브라우저에서 실행한다. 합성 상수 버퍼에 실제 AudioParam 선형 예약을 적용하여 마지막30초 시작/중간/끝 gain과 scheduled stop 뒤0을 수치로 확인한다. 기본 fade-off, volume0, 무기한 예약도 대표 검사한다. 이는 실제 디코더/예약 엔진 검증이며 사용자 스피커 청취/OS 절전 검증이 아니다.
11. **설정 저장·재방문·불러오기·이름/삭제** — 6종 중 대표 설정·volume/timer/fade만 schema에 저장하고 실행 기한/남은 시간/버퍼가 없어야 한다. 재방문 자동 적용/재생0. 진행 중 명시 불러오기는 stop 후 설정만 적용. 이름40자/6개·중복 이름 대표 경계, rename/delete는 현재 설정을 바꾸지 않는다.
12. **손상/미래버전/차단/쿼터/readback** — 기존 raw 보호, 이름·설정 보존, 실제 결과가 미확정인 쓰기는 ‘실패로 롤백’하지 않고 재조회 안내. 차단 해제 후 명시 재조회/재시도만으로 회복하며 기존 목록은 유지한다.
13. **두 탭 CAS·실제 Web Lock 지연** — 같은 컨텍스트 두 탭에서 최신 목록 보호. lock을 실제로 점유한 상태의 load/save 대기 중 설정 편집·선택 변경·취소·storage event·이탈은 이전 작업을 무효화한다. 이후 새 명시 요청은 정상 동작하며 audio 중지는 성공한 load에만 일어난다.
14. **320px KO/EN·정리** — 다크320px·16/44·설정/음량/타이머/상태/프로필 오류 문구, locale 변경 상태 보존. 명시 중지/이탈 후 source/gain/context/listener 정리와 JS/hydration/원시 키를 수집한다.

Chrome 종료 뒤 통합 담당에게 전체 타입 검사 가능 신호를 보낸다. 제품 오류는 해당 작성자에게 재현과 함께 전달하고 변경 영향 사례만 다시 실행한다. 날짜/시간대 데이터는 실행 환경 Intl에 의존하며, native Clipboard 권한은 테스트 컨텍스트에서 허용했다는 점을 보고한다.
