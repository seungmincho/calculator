## A. 세계 시계의 정확한 공유 순간·ICS

`/world-clock/`의 선택값을 UTC epoch 순간으로 보존한다. 시간 변환기에서 넘어온 분·초와 DST 중복 시간을 `hour` 인덱스로 다시 만들지 않는다. 현재 시각/기존 표 클릭/공유 URL/도시 순서 변경이 실제 순간을 어떻게 선택하는지 명시적으로 분리한다. 도시 순서만 바꾸면 선택 순간은 유지하고 새 기준 도시의 날짜를 표시한다. 사용자가 날짜를 바꾸는 동작은 해당 날짜의 기본 선택으로 이동해도 되며 안내와 URL이 일치해야 한다.

- URL `at`는 유한한 안전 epoch 초와 표시 가능한 연도 범위를 확인하고, 도시 ID 중복/비정상 값과 과도한 목록을 정리하되 유효한 입력의 순서를 유지한다. 잘못된 URL이 Intl/Date 렌더 예외를 만들지 않게 한다. 기존 URL>저장 도시>기본 순서를 보존한다.
- 표는 기준 도시의 실제 날짜 구간을 대상으로 만들고 DST 23/25시간, 반시간 전환/30·45분 UTC 오프셋을 확인한다. 가능한 모든 날이24개 같은 칸이라고 가정하지 않는다. 선택 순간과 가까운 표 칸 표시는 선택 순간 자체를 반올림하지 않는다. 끝 경계/부분 구간을 설명하고 기존 업무 겹침 요약이 실제 구간과 일치하게 한다. 시장 개장 계산은 범위 밖이다.
- 선택 결과에 제목(1~100자), 길이30/60/90/120분, 시작/끝 도시별 표시와 ‘캘린더 파일 저장’을 추가한다. 기본60분. 제목은 메모리만 사용하고 URL/저장소에 넣지 않는다. 파일은 UTC DTSTART/DTEND 단일 VEVENT, 안정 UID·DTSTAMP·CRLF·UTF-8 75octet folding·TEXT escape를 지킨다. 기존 검증된 ICS TEXT/folding 유틸을 재사용할 수 있으나 다른 도구의 저장 schema와 결합하지 않는다.
- 반출 클릭의 순간·길이·제목을 고정한다. 비동기 UID 처리 중 입력/도시/언마운트가 바뀌면 이전 자동 다운로드를 만들지 않는다. 오류/재시도는 현재 선택을 보존한다. 반복/알림/참석자/계정 연동은 추가하지 않는다.
- 기존 텍스트/링크 복사는 실제 성공만 표시하고 실패 시 수동 선택·재시도, 늦은 복사 결과 보호를 제공한다. 표시 언어에 맞는 도시명·요일은 이 화면 범위에서 정리한다. 공유 카드·URL·복사·ICS가 같은 선택 순간을 사용한다. 수정 입력16px·버튼44px·320px을 확인한다.

검증: 기존 시간 유틸 회귀, 서울 분·초 공유/뉴욕 봄·가을 DST/반시간 전환/카트만두·UTC/자정 넘김/도시 순서, URL 재방문 실제 화면과 동일 epoch, ICS 독립 파서 시작·끝·한글 escape/fold·길이, 느린 생성 무효화/복사 실패, KO/EN·320px. 표의 기존 오류를 수정한 범위와 전체 시간대 데이터 정확성을 구분한다.

## B. 백색소음 종료 기준·설정6개

`/white-noise/`는 기존6종 합성 소리와 음량/타이머 선택을 유지한다. 실제 종료 기준을 세우고 남은 시간을 계산해 interval 지연이 시간을 늘리지 않게 한다. 타이머를 재생 중 바꾸면 ‘지금부터 N분’으로 재설정하고, 소리 종류/음량만 바꾸면 종료 기준은 유지한다. 타이머 없음은 명시 무기한이다.

- 선택적인 마지막30초 페이드를 제공하며 기본은 끈다. 음량은0~100, 타이머는 기존0/5/10/15/30/60분만 허용한다. AudioParam 예약/소스 종료를 적용하고, 화면 복귀 시 실제 기한이 지났으면 소리를 재개하지 않는다. OS의 앱 정지/기기 절전 중 정확한 백그라운드 실행을 보장하지 않는다. 시작 실패·resume 거부는 재생 성공으로 표시하지 않는다.
- 재생 시도마다 context/source/gain/timer/listener를 소유한다. 준비/빠른 연속 클릭/종류 교체/중지/언마운트 뒤 늦은 resume·ended가 새 시도를 바꾸지 않게 한다. 현재 상태와 음소거를 구분하고 자원을 정리한다. 사용자의 재생 클릭 전에는 AudioContext를 만들거나 소리를 시작하지 않는다.
- 이미 시작된 source를 suspended 상태에서 재개할 때는 native resume 호출 전에 gain을0으로 두고 준비 중 statechange/음량/페이드 변경도 다시 소리를 켜지 않게 한다. resume Promise 뒤 현재 소유권·기한·running 상태가 유효할 때만 최신 gain 예약을 복구한다. 26차 중 root 읽기 검토에서 이 경계가 미연결 준비 코드에 빠져 있음을 담당자가 확인했으며,26차 TS 고정 해제 후27차 부모 연결 전에 최소 수정과 호출 순서/지연 만료 검사를 수행한다.
- 설정 최대6개는 별도v1키에 이름40자·종류·음량·타이머·페이드만 저장한다. 재생 상태·남은 시간·오디오 버퍼는 저장하지 않는다. 저장/불러오기/이름 변경/개별 삭제를 명시 버튼으로 제공하고, 불러오기는 진행 중 소리를 정지한 뒤 설정만 적용한다. 자동 재생·다음 방문 자동 덮어쓰기는 없다.
- 기존 저장 패턴처럼 엄격 파싱/버전·한도/읽기차단·쓰기실패·readback/두 탭 충돌과 stale lock 대기를 처리한다. 손상/미지원 기록을 조용히 초기화하지 않는다. 현재 설정 편집 중 늦은 불러오기가 덮지 않게 한다. KO/EN·44px 버튼·16px 입력·디자인 토큰으로 수정 구역을 정리한다.

검증: fake wall/monotonic/audio clock으로 지연tick·기한·타이머 변경·소리 전환, native OfflineAudioContext의 페이드/종료 파형과 리소스 정리, context resume 실패/late권한/중지 후 callback, 저장 경계/두탭/손상/쿼터, 실제 부모·모바일 KO/EN. 브라우저는 무음 출력/OfflineAudioContext로 검증해 사용자 스피커에서 소리를 임의 재생하지 않는다. 실제 휴대폰 절전 상태와 수면 효과는 검증 주장 밖이다.
