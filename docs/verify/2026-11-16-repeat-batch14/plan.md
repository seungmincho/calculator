# 14차 실행 계약 — 글꼴 스타일 조합 저장

2026-11-16. 사용자가 기존 `/font-preview/`의 글꼴 스타일 조합 저장을 멀티 에이전트로 구현하고 검증하도록 승인했다. 13차 두 복구 기능은 완료한 별도 작업이다.

## 사용자 동작과 보존 기준

- 기존 제목·본문 조합 패널 안에서 이름 40자, 최대 6개 조합을 명시적으로 저장·불러오기·삭제한다. 이름 중복은 조용한 덮어쓰기 없이 설명한다.
- 저장 값은 카탈로그 글꼴 ID·크기·요청 굵기와 이름/식별 메타데이터뿐이다. 원고 문구나 로컬 폰트 파일을 저장하지 않는다. 불러오기는 현재 제목·본문 문구를 보존한다.
- 공유 URL은 기존 규칙으로 초기 복원한다. 저장된 조합을 자동 적용하지 않으며 불러오기 버튼을 누른 때만 현재 스타일을 바꾼다. 접기·재열기의 메모리 초안, 기존 CSS/링크 복사·교환·폰트 로드 검증을 유지한다.
- 버전·ID·필드·숫자 범위와 목록 개수를 검증한다. 손상·미래 버전·저장소 차단·용량 초과·감지된 다른 탭 변경은 기존 데이터를 덮거나 성공으로 표시하지 않는다. 새로 읽기 등 명시적 복구 경로를 제공한다. localStorage의 원자적 다중 탭 트랜잭션을 보장한다고 주장하지 않는다.
- 디자인 토큰·모바일 320px·16px 입력·44px 버튼·ko/en 키를 확인한다. 새 서버·패키지·경로·자동 저장 본문을 추가하지 않는다.

## 분업

- taxi_repeat: 제품 컴포넌트·저장 유틸·도메인 검사·ko/en 번역 조각.
- writing_versions: 독립 코드/도메인 검사와 결함 재현·수정 확인.
- batch5_verify: 단일 Chrome의 실제 저장/재방문/불러오기/삭제·실패 주입·회귀·모바일 검증.
- batch5_integrate: 공용 번역·메타데이터·생성물·전체 타입 검사·최종 보고/인계.
- root: 범위 결정·사용량 확인·검토·수용 판단.

제품 및 검증 담당은 공용 메시지/메타데이터를 직접 바꾸지 않는다. 브라우저를 종료한 뒤 전체 타입 검사를 2GB heap으로 한 번 수행한다. 새 실패나 변경이 없는 검사는 반복하지 않는다. 빌드·배포·커밋·푸시는 실행하지 않는다.

## 사용량

시작 조회는 계정 전체 사용 95%·잔여 5%·무료 초기화 쿠폰 3개였다. 사용자는 한도 소진 시 무료 쿠폰 사용을 승인했다. 현재 노출된 계정 도구는 읽기 전용 조회뿐이며 쿠폰 실행 기능은 없다. 실행 가능한 공식 도구가 제공되면 승인 범위 안에서 사용하고, 실제 잔여 개수·한도 복원 결과를 확인한다. 실행하지 않은 초기화를 완료했다고 기록하거나 유료 구매로 대체하지 않는다.

공식 웹 화면 접근도 Windows computer-use로 시도했다. Chrome 화면 읽기는 가능했으나 입력 실행은 `GetCursorPos failed: 액세스가 거부되었습니다. (0x80070005)`로 실패했다. 초기화 확인/사용을 실행한 적은 없다. 이 실패를 사용자 승인 거부나 한도 소진으로 해석하지 않는다. 현재 개발 작업은 계속 가능하다.
