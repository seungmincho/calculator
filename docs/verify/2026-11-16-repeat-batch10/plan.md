# 10차 실행 계약 — 작성한 내용을 다음 작업으로

2026-11-16. 연속 개선 큐07~09. 기존 도구만 개선한다. 8/9차 검증 결함은 우선 처리하며 다음 항목 구현은 소유 파일이 겹치지 않을 때 진행한다.

| ID | 범위 | 완료·보존 조건 |
|---|---|---|
| 07 메모장 → 읽어주기 | 현재 메모 전체 또는 선택 영역을 사용자 버튼으로 새 읽어주기 탭에 전달 | 본문은 URL에 넣지 않음. 30,000자·10분 만료·출처 확인, 새 탭에 일회성 sessionStorage 전달 후 소비. 원본 메모/선택/자동저장 및 기존 읽어주기 탭 보존. 자동 재생하지 않고 기기 음성 우선. 팝업/저장소 차단 오류 안내. 기존 OCR 전달 회귀 |
| 08 JSONPath 저장 | JSON 정렬기의 검색 패널에서 이름 붙인 검색식 최대12개 저장/불러오기·이름 수정·삭제 | 이름40자·검색식1,000자. JSON 원문/검색 결과는 저장하지 않음. 불러오기는 검색식만 채우며 실행은 명시적 버튼. 잘못된 검색식도 기존 실행 오류로 설명. 손상·미지원 버전·동시 수정·quota 실패를 숨기지 않음 |
| 09 URL 줄별 변환 | 기존 단일 인코딩/디코딩과 별도의 일괄 패널. 최대100줄·전체30,000자, 행마다 한 번만 encodeURIComponent/decodeURIComponent | 원문/결과/행번호/오류를 유지. 내부 빈 줄도 순서 보존하며 마지막 줄바꿈 한 개는 입력 종료 표시로 취급. 오류 행을 건너뛰거나 성공으로 표시하지 않음. 결과 복사/TXT는 오류 행에 원문을 보존한다는 설명, TSV는 상태와 원문을 함께 내보냄. 잘못된 %·UTF8·한글·이모지·중복 인코딩·CRLF 검증 |

현재 URL 도구는 encodeURIComponent/decodeURIComponent와 URL 정규화 버튼을 제공한다. URI/컴포넌트 선택 모드를 새로 만들거나 있다고 가정하지 않는다. 기존 단일 변환과 URL 분석/정규화 동작을 보존한다. 일괄 결과는 입력/모드를 바꿀 때 구식 결과로 내보내지 않게 비운다. 복사 실패를 성공으로 표시하지 않는다. 텍스트/검색식은 HTML로 삽입하지 않는다.

메모장 연결은 기존 textHandoff의 OCR 호환성을 보존하며 source `notepad`를 추가한다. 새 탭은 사용자 클릭 안에서 동기적으로 열고 대상 탭 저장소에 전달·읽기 확인 후 내부 경로로 이동한다. 팝업 실패 시 기존 탭 이동으로 원본을 잃게 하지 않는다. 전달 객체를 새로 저장하는 곳은 신뢰할 수 있는 출처 enum과 데이터 검증을 거친다.

담당자는 컴포넌트·순수 유틸·의미 있는 도메인 검사·ko/en 번역 조각을 함께 작성한다. 공용 원본 메시지/페이지/메뉴/생성물은 통합 담당만 수정한다. 브라우저는 검증 담당 단독 순차 실행. 새 의존성/빌드/배포/커밋/푸시는 실행하지 않는다. 모바일320px·16px 입력·44px 터치·토큰을 지키고, 제품 핵심 입력은 접지 않는다.
