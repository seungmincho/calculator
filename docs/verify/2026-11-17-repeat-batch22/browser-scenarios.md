# 22차 독립 브라우저 계획

기존 localhost:3039, 한 Chrome·순차 격리 컨텍스트. 서비스워커·외부 요청 차단. 제품 파일 수정 없이 실제 UI와 내려받은 산출물을 검사한다. 제품 준비/번역 생성 뒤 도구별 착수하며 최종 종료 뒤 통합 담당의 전체 타입 검사로 넘긴다.

1. 직접 등급: 빈 시작·부분 입력·정확한 합 경계·상위 탐구 한 영역·동일 과목 같은/다른 등급. 원점수 폼/12개 기록 원본 bytes/URL 보존.
2. 목표 추가·수정·삭제 및 실제 다른 탭 변경/재조회 동안 직접 등급 보존. 별도 목표 저장소나 자동 원점수 반영이 없는지 확인.
3. 원점수 빈 값/0/무효 및 누락·구형 URL 복원: 행·hero·컷 강조 일치, 원문 query 유지. 무효 number 입력의 DOM 표시와 원문 상태를 구분.
4. 실제 ShareResult PNG 1080×1350, Canvas 텍스트 및 공유 텍스트에서 미입력/0/무효 구분·학년도 근거·직접 등급 미포함 확인. 네이티브 공유창 전달은 제어하며 PNG는 실제 생성한다.
5. 완전 입력 평균 유지, 한국사 빈 값과 영어 빈 값 차이, 같은 탐구의 동일/상충 원점수 처리.
6. 320px 다크/EN: 상단 직접등급 진입·16px 입력·44px 버튼·접기/언어 변경 후 입력 보존·원시 키/JS/hydration.
7. 실제 PNG를 품질/목표 용량·축소 포맷으로 압축하고 MIME·픽셀 크기·내용을 독립 확인.
8. 네이티브 이미지 처리 콜백 전달을 지연해 pause/resume·설정 연속 변경 중 최대 활성 작업 1, paused 중 추가/설정 변경이 자동 재개하지 않는지 검사.
9. 제어한 인코더 실패 후 실패만 재시도·현재 설정 성공 재사용, 삭제/전체 삭제/이탈 뒤 늦은 결과 무효화와 자원 정리.
10. 실제 ZIP을 독립 파싱해 모든 출력 bytes·고유 파일명을 확인. Blob 읽기 지연 중 설정 변경/삭제에도 클릭 당시 고정 결과를 내보내는지 확인.
11. ZIP 실패 안내 및 새 요청/이탈 뒤 늦은 다운로드 차단. 오류 주입은 실제 압축·ZIP 성공 증거와 구분한다.
12. 공유 uniqueNames 호출부: ImageConverter 실제 충돌 이름 ZIP, ImageResizer 출력과 PdfTools 파일명 회귀. 기존 알고리즘 검사를 불필요하게 전수 반복하지 않는다.
13. 이미지 큐 320px 다크/EN 조작·상태·16px/44px·원시 키/JS/hydration.
14. 독립 리뷰 취소 보완 영향: 실제 HTML 이미지/Canvas 대체 경로의 정상 JPEG 출력, bitmap 실패 대기 중 취소 뒤 `img.decode` 추가0, Offscreen 인코딩 실패 대기 중 취소 뒤 HTML `toBlob` 추가0, 명시 재개 후 정상 대체 출력.

실제 네이티브 브라우저 API를 강제 즉시 취소했다고 주장하지 않는다. 비동기 완료 전달을 제어한 경계 검사와 실제 픽셀 압축/다운로드를 각각 기록한다.
