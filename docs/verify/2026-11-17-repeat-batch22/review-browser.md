# 22차 독립 브라우저 검증

최종 **14/14 PASS**. 수능6개·이미지 기본7개 및 독립 리뷰 취소 보완 영향1개다. 모든 사례의 JS page error·hydration 오류·처리되지 않은 Promise 거부0. Chrome을 닫고 통합 담당에게 전체 타입 검사 가능 신호를 보냈다. 전체 기본 검사를 반복하지 않고 변경된 취소 경계1개만 추가했다.

검증은 기존 `http://127.0.0.1:3039`와 단일 Chrome을 사용했다. 컨텍스트별 저장소 격리, 서비스워커 차단, 외부 요청 차단을 적용했다. 제품 파일·패키지·서버·빌드·전체 타입 검사는 변경하거나 실행하지 않았다. [실행 스크립트](../../../scripts/check-repeat-batch22-browser.mjs)와 [원본 결과](browser/final-results.json)에 사례별 증거가 있다.

검증 방식의 한계: PNG·JPEG·ZIP·PDF·원본 픽셀·클립보드/공유 URL은 로컬 검증 데이터를 사용했다. `navigator.share`는 전달 내용을 받는 제어 함수이며 OS 공유창이나 외부 전송을 수행하지 않았다. 비동기 콜백·인코더/ZIP 읽기 실패는 주입한 상태 경계다. 네이티브 작업의 즉시 강제 종료를 검증했다고 주장하지 않는다. 외부 글꼴·광고·통계 요청 차단으로 발생한 네트워크 로그는 별도 기록했다.

초기 테스트 실패는 검증 코드의 about:blank 초기화 가드, 표시 접미사·요약 위치·동일 입력 라벨 선택, 90점에 잘못 일치한0점 정규식, 원문은무효이나DOM이이미빈 number input의 이벤트 조건이었다. 이를 수정한 해당 사례만 재실행했으며 제품 변경으로 집계하지 않았다.

독립 리뷰에서 발견한 제품 경계는 취소된 native decode/encode의 늦은 실패 뒤 새 HTML fallback을 시작하던 동작이었다. 담당자가 선택적 AbortSignal을 decode/encode까지 전달하고 fallback 직전에 확인하도록 최소 수정했다. 위 마지막 사례는 그 변경에 대한 실제 브라우저 영향 확인이다. 정상 압축·ZIP의 기존 통과 증거는 보존했다.

`*-failure.png/txt`는 초기 테스트 코드 진단 자료로 남아 있으며 최종 판정은 각 `*-evidence.json`과 `final-results.json`의 PASS다. OS 공유창·실제 휴대전화·외부 폰트 시각 품질·배포 빌드 검증으로 확대 해석하지 않는다. 전체 타입 검사는 이 독립 브라우저 검증과 별도로 통합 담당이 수행한다.
