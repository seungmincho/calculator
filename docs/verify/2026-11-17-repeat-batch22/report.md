- 이미지 압축: 단일 실행기, 일시정지/계속/실패만 재시도, 설정별 완료 재사용과 오래된 결과 제외, 클릭 시점의 완료 목록 ZIP과 늦은 다운로드 보호를 연결한다. 공유 uniqueNames의 생성 파일명 충돌을 보완하고 기존 이미지/PDF 소비자 회귀를 확인한다.
- csat-grade 설명은 기존 전년도 원점수 추정·공식 표 전체 미검증·올해 확정 등급 아님을 유지한다. image-compressor의 고정 절감률 보장처럼 읽히는 문구는 원본/설정별 결과와 작업 제어 중심으로 정리했다. 두 page description/OG/Twitter/JSON-LD는 같은 상수를 사용한다.

## 실제 브라우저와 수정 경계

[브라우저 보고서](review-browser.md)와 [원본 결과](browser/final-results.json): 수능 6개·이미지 기본 7개·취소 수정 영향 1개, 합계 14개 PASS. 최종 `checkedAt=2026-11-16T17:38:13.455Z`. 전체 기본 검사는 반복하지 않고 변경 경계만 추가했다.

- 직접 등급의 빈칸/부분 입력/탐구 중복·상충과 목표 CRUD, 원점수 폼·URL·기록 문자열 보존을 확인했다. 원점수 빈칸/0/무효는 실제 1080×1350 PNG 3개와 Canvas 문구에서 구분됐고 직접 입력 등급은 공유 카드에 섞이지 않았다.
- 1,051,563byte PNG의 품질 JPEG는 34,801byte/320×240, 목표 20KiB JPEG는 19,367byte/257×193이었다. 내려받은 결과를 다시 디코딩해 픽셀을 확인했다. 특정 입력의 측정값이며 모든 이미지의 크기·품질 보장은 아니다.
- ZIP 클릭 당시 완료 Blob의 SHA-256과 개별 다운로드가 일치했다. Converter의 `a.jpg`, `a (3).jpg`, `a (2).jpg`, `A (4).jpg` 네 색을 보존했고 Resizer 2개 및 PDF 분할 p1/p1(2)/p2도 독립 파싱했다.
- 독립 검토에서 취소된 bitmap/Offscreen API의 늦은 실패 뒤 새 HTML fallback이 시작되는 경계를 발견했다. 선택적 AbortSignal을 내부 decode/encode로 전달하고 새 API 진입 전 확인하도록 수정했다. 독립 영향 2그룹과 브라우저 추가 1개에서 HTML decode/toBlob 추가 호출 0, 정상 HTML fallback·명시 resume의 실제 JPEG 생성을 확인했다. 이미 실행 중인 네이티브 작업을 즉시 강제 종료하는 보장은 아니다.
- 두 도구 320px 다크·실제 EN, 16px 입력·44px 주요 버튼·가로 넘침 없음과 수능 상단 바로가기/접기/언어 전환 뒤 초안 유지도 확인했다. 초기 선택자·정규식·이벤트 준비 오류는 검사 코드 문제로 구분했다.

## 범위와 다음 단계

사용자 직접 등급은 공식 성적 인증이나 대학별 합격 판정이 아니다. 기존 전년도 추정컷 표 전체의 원자료 정확성을 새로 인증하지 않았다. OS 공유창은 제어 함수로 전달 내용만 확인했고 실제 휴대전화·외부 폰트 품질·운영 정적 export는 검사하지 않았다. 범위 lint 통과를 저장소 전체 lint 통과로 표현하지 않는다.

공용 메타·showcase·menu updatedDate(2026-11-17)와 생성물을 반영했다. 범위 diff와 완료 인계는 [통합 검사 기록](integration-checks.json)에 남긴다. 빌드·배포·커밋·푸시는 실행하지 않았다. 다음은 [23차 내 글 타자·재녹화](../2026-11-17-repeat-batch23/plan.md)이며 24·25차는 별도 후속 계약이다. 현재 검증을 새 부모 연결의 완료 증거로 재사용하지 않는다.
