# 22차 계약 — 직접 등급 비교·이미지 압축 작업 제어

2026-11-17 KST. 기존 도구 개선이며 새 경로를 만들지 않는다. [수능 후보 조사](../../handoff/2026-11-17-csat-direct-grade-candidate.md)와 [이미지 압축 조사](../../handoff/2026-11-17-image-compress-queue-candidate.md)에 근거한다. 20·21차 체크포인트가 우선이고 아직 제품 구현에 착수하지 않았다.

## A. 사용자가 입력한 등급으로 저장 목표 비교

추천안인 `CsatGoalConditions` 내부 독립 패널을 채택한다. 기존 목표 6개와 읽기 차단 상태를 prop으로 전달하며 별도 목표 저장소를 만들지 않는다. 국어·수학·영어·탐구 1/2의 직접 등급과 탐구 과목은 방문 중 메모리에만 둔다. 원점수 추정값을 자동으로 옮기지 않으며 미입력에서 시작한다. 패널을 여는 명시적 버튼과 입력 필요 상태를 보여 준다.

- 등급은 빈 값 또는 1~9 정수만 허용한다. 탐구 과목 allowlist, 한 과목 안내, 같은 과목의 같은 등급/상충 등급, 상위 한 과목을 한 영역으로 세는 규칙은 기존 단순 목표 계약에 맞춘다. 사용한 영역을 명시하고 부족한 입력에서 충족 여부를 만들지 않는다.
- 같은 저장 목표의 추가·수정·삭제와 충돌/재조회 상태를 반영한다. 접기·재열기·언어 전환·목표 재조회는 직접 입력을 지우지 않는다.
- 직접 입력은 사용자 입력일 뿐 공식 확인이나 올해 확정 성적을 보증하지 않는다. 표준점수/백분위/평균/가짜 원점수 역산은 없다. 기존 원점수 URL·12개 기록·공유 카드에 직접 등급을 섞지 않는다고 패널에 알린다. 대학별 조건·합격 판단도 추가하지 않는다.

동시에 발견한 **원점수 결측 요약 불일치**를 별도 보완으로 포함한다. 빈 원점수를 0점/9등급으로 표시하지 않고 행·hero·공유·표 강조에서 같은 유효성 결과를 사용한다. 실제 `0`은 유효한 0점이다. 무효값은 입력 확인으로 표시한다.

- 평균 산식은 그대로다. 전체 평균은 국어·수학·영어·탐구 두 입력이 유효할 때, 영어 제외 평균은 국어·수학·탐구 두 입력이 유효할 때만 계산한다. 한국사 빈칸은 두 평균을 막지 않는다. 분모를 줄인 부분 평균을 만들지 않는다.
- 서로 다른 점수를 넣은 같은 탐구 과목은 기존 목표 평가의 충돌과 일치하게 평균 계산도 보류한다. 같은 과목/같은 점수는 기존 숫자 결과를 유지하되 중복 입력 안내를 숨기지 않는다.
- 기존 컷·보간·완전 입력의 숫자·저장 schema와 `?kor=`/파라미터 누락/실제0/구형 링크를 보존한다. 직접 패널과 결측 보완의 증거는 분리해서 기록한다.

검증: 직접 등급 경계·탐구·부분 입력·raw/direct 목표 대조, 목표 CRUD/충돌/복구 중 입력 보존, 기존 원점수·기록 bytes·URL 불변, 빈/0/무효 행과 공유 이미지·텍스트, 한국사/영어 결측의 평균 구분, 완전 입력 회귀, KO/EN·320px.

## B. 이미지 압축 일시정지·계속·실패만 재시도

기존 자동 처리·프리셋·품질/목표 용량·크기/포맷·전후 비교·개별/ZIP 다운로드를 유지한다. 단일 실행기로 작업 중첩을 막고 일시정지·계속 처리·실패 항목 재시도를 추가한다. 성공한 현재 설정 결과는 재사용한다. 일시정지 중 파일 추가/설정 변경으로 자동 재개하지 않는다.

- 선택적 취소 신호로 디코딩/인코딩 단계 사이와 목표 용량 반복을 중단한다. 이미 시작한 브라우저 API를 즉시 종료한다고 설명하지 않는다. 취소는 실패와 구분하며 늦은 결과·삭제·언마운트의 자원을 정리한다.
- 설정이 달라진 이전 결과를 현재 결과로 다운로드하지 않는다. 현재 작업이 끝나기 전에 새 작업을 중첩 실행하지 않는다. 개별 삭제/전체 삭제와 늦은 완료가 항목을 복구하지 못하게 한다.
- ZIP은 클릭 당시 완료 목록/설정의 고정 결과로 만든다. 이 정책을 표시하고 도중 편집과 구분한다. 실패를 안내하며 새 ZIP 요청/언마운트 뒤 오래된 다운로드를 실행하지 않는다.
- `uniqueNames`의 실제 재현된 생성 이름 충돌을 수정한다. 원래 `a (2).jpg` 같은 이름과 생성된 이름, 대소문자 차이를 함께 검사한다. 이 공유 함수가 쓰이는 ImageResizer·ImageConverter·PdfTools의 파일명 회귀를 확인한다.
- 기본 `compressFile`/`fitToSize` 호출 호환성과 알고리즘을 보존한다. 원본 자동 저장·서버 전송·새 패키지는 추가하지 않는다.

검증: 실제 픽셀 압축과 기존 알고리즘 회귀, 중첩 최대1, 중간 정지/재개/설정 변경/실패만 재시도/삭제/언마운트, 완료 재사용, 실제 ZIP 파일별 내용과 고유 이름, ZIP 실패·입력 변경·늦은 다운로드, KO/EN·320px.

## 통합 순서

제품별 담당이 UI와 ko/en 조각을 함께 작성한다. 공용 messages·메타·생성물은 통합 담당만 변경한다. 준비 유틸과 자식을 완성한 뒤 부모를 연결한다. 도메인/독립/단일 Chrome 검사 완료 뒤 TS 작성 정지·Chrome 종료·메모리 확인 후 전체 타입 검사를 수행한다. 빌드·배포·커밋·푸시는 실행하지 않는다.
