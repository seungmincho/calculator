# 29차 후보 — 팀 편성 다시 실행·결과 반출 복구

2026-11-17 KST. 기존 `/team-divider/` 개선이며 27차 체크포인트 완료 뒤 구현·검증을 완료했다. 브라우저7/7·독립14그룹·05:26 KST 공통 전체 타입과 범위 검사를 통과했으며 결과는 [보고서](report.md)에 있다. CSV 성능 후속과 파일 소유권을 분리해 병렬 구현하고 각 기능의 검증 근거와 공통 전체 타입 체크포인트를 기록한다. 28차 워터마크와 30차 포모도로는 미연결 준비만 진행한다. 최초 사용자 요청의 자주 쓰는 팀 편성 흐름을 보완한다.

변경 전 `TeamDivider.tsx`는20개 snapshot으로 이동/교환/고정/재편성을 되돌릴 수 있지만 다시 실행은 없다. `copyResult`는 native 거부 뒤 legacy `execCommand`의 false를 무시하고 copied를 표시한다. 새 편성·명단 변경 뒤 옛 복사 응답/타이머가 새 상태를 덮을 수도 있다.

- 기존20개 이력을 past/present/future로 정리해 ‘다시 실행’을 제공한다. 팀별 명단 순서·고정된 사람·결과 방식·직전 동료 비교 snapshot을 함께 보존하고 새 배열로 분리한다. undo+redo 총20전이, no-op 이력 없음, undo 뒤 실제 새 편집이면 redo 폐기다. 난수 생성/균형 알고리즘/겹침 줄이기 자체는 바꾸지 않는다.
- 명단/참석/팀 수/저장본 복원과 주장 선택 새 시작은 기존처럼 편성 이력을 초기화한다. 카드 공개 중·주장 선택 진행 중에는 undo/redo를 실행하지 않는다. 복원은 이미 확정된 편성을 즉시 표시하며 재추첨이나 공개 애니메이션을 다시 실행하지 않는다. 상태가 바뀐 뒤 옛 공개 타이머가 결과를 덮지 않게 한다.
- 기존 undo와 새 redo 뒤 선택된 사람/초점은 현재 유효한 항목이나 사용 가능한 이력 버튼에 둔다. 첫 범위는44px 이력 버튼과Tab/Enter/Space로 모든 동작을 제공하며 Ctrl/Command+Z·Shift+Z 추가는 보류한다. 이름/메모 입력·IME의 native undo를 가로채지 않는다.
- 현재 실력값과 다음 편성 방식은 기존 undo 범위 밖에 두고 보드 이력을 유지한다. 실제 편성 snapshot을 변경한 새 작업만 redo를 폐기한다. 다만 실력값이나 언어 변경으로 반출 텍스트가 바뀌면 진행 중 복사 요청은 무효화한다. 현재 결과의 방식과 다음 편성 방식은 분리한다.
- 팀 결과 텍스트 복사는 실제 성공만 표시한다. 실패 시 현재 편성의 읽기 전용 텍스트·전체 선택·재시도를 제공하고, 개별/전체 편성 변경·undo/redo·명단 변경·언마운트 뒤 stale 응답과 타이머를 무효화한다. 이미 OS에 제출한 복사 취소를 보장하지 않는다.
- 같은 텍스트를 UTF-8 TXT로 명시 다운로드할 수 있게 한다. 사용자 이름을 파일명/추가 URL/로그/새 저장소에 넣지 않는다. 기존 명시 공유 링크에 편성 이름이 포함된다는 안내와 공유 형식은 유지한다. 저장 명단/백업 schema는 변경하지 않는다.

검증은 기존팀 분배/고정/회전/출석 회귀를 유지하고, 이동·교환·고정·새편성20이력/noop/redo폐기·캡틴/참석/공유복원 경계, 독립 텍스트/실제TXT·복사false/stale/수동선택, KO/EN·320px·키보드·초점을 확인한다. 제품+ko/en은 같은 담당, 공용 파일은 통합 담당, 단일Chrome과 TS고정 뒤 전체타입 검사를 적용한다. 빌드·배포·커밋·푸시는 실행하지 않는다.
