# 기존 도구 재방문 개선 5차 — 병렬 작업 계약

2026-11-16. 사용자가 기존 도구의 개선 후보 선정부터 우선순위에 따른 구현·검증까지 승인했다. 새 도구·새 경로는 만들지 않는다. 이전 작업 중 변경을 보존하고 빌드·배포·커밋은 이번 범위에 포함하지 않는다.

## 우선순위

| 순위 | 기존 도구 | 확인한 빈틈과 구현 | 재방문 이유 |
|---|---|---|---|
| 1 | 택시 요금 계산기 | 조건을 URL로 공유할 수 있지만 자주 쓰는 조건을 이름으로 보관할 수 없음. 최대 10개 이동 조건 저장·수동 불러오기·관리 | 출퇴근·귀가 때 같은 조건을 다시 입력하지 않고 계산 |
| 2 | 학점 계산기 | 현재 성적 자동저장은 있으나 여러 예상 성적을 이름으로 보관·비교할 수 없음. 최대 8개 시나리오 저장·비교·복원 | 학기말 예상 성적과 실제 성적, 재수강 계획 비교 |
| 3 | 글자 수 세기 | 5문항 자동저장과 한 단계 되돌리기는 있으나 여러 수정본 보관은 없음. 최대 20개 수정본 저장·본문/분량 비교·현재 탭 복원 | 자기소개서·지원서·원고를 고치면서 이전 문장을 되찾기 |

우선순위는 첨부된 작은 시점별 이용 현황(택시·학점 이용)과 코드에서 확인한 반복 입력 비용에 따른 제품 가설이다. 최신 분석 자료나 전환율 검증으로 확정한 순위는 아니다. 이미 개선한 팀 나누기·메뉴 룰렛·음성 메모·말하기·회의록·칸반과 겹치는 기능은 이번 묶음에서 제외했다.

UI 담당자가 자기 기능의 ko/en 번역까지 작성한다. 공용 messages 원본은 root 한 명만 병합한다. 전체 타입 검사와 브라우저 검사는 동시에 실행하지 않는다. 기존 개발 서버 3039를 재사용한다.

## 공통 완료 기준

- 현재 계산식·요율·통계 기준은 유지한다. 보관한 결과 수치로 현재 계산을 대체하지 않는다.
- 저장은 명시적인 사용자 동작이며, URL로 열린 값·기존 입력을 임의로 덮지 않는다.
- 손상·미지원 버전은 덮어쓰지 않고, 저장 실패나 다른 탭의 변경을 알린다. 성공 후에만 성공 상태를 표시한다.
- 성적·긴 원고를 교체하는 불러오기와 저장 항목 삭제는 확인을 거친다. 택시 조건 프리셋은 목록의 조건 요약과 명시적인 불러오기 동작으로 선택을 확인한다. 기기 저장이며 사이트 데이터 삭제 시 사라짐을 안내한다.
- 모바일 320px, 44px 조작 영역, 16px 입력, 명확한 라벨·상태 안내, 라이트/다크와 한국어/영어를 확인한다.
- 새 저장 로직의 경계 검사 + 기존 계산 회귀 + 실제 브라우저 저장/불러오기/비교/실패 검증 + 전체 타입/변경 범위 lint/번역 검사.

## 사용량

작업 시작 시 제공된 읽기 전용 사용량 도구에서 주간 사용 53%, 초기화권 3개를 확인했다. 계정 전체 수치이며 이 작업만의 토큰 사용량은 아니다. 초기화권 실행 도구는 현재 발견되지 않았다. 초기화·크레딧 구매는 하지 않았다. 유효한 구현과 검증을 진행하며 소모만을 위한 반복 실행은 하지 않는다.
