# 재방문 기능 5차 — 택시·학점·글자 수

2026-11-16, KST. 기존 도구 세 개에 이름을 붙여 저장하고 다음 방문에 다시 쓰는 흐름을 추가했다. UI·도메인 담당 3명, 독립 브라우저 검증 담당, 공용 통합 담당이 파일을 나누어 작업했다. root는 우선순위 선정과 다음 작업 조율을 맡았다.

로컬 개발 서버 3039에서 브라우저 검증을 완료했고, 이어지는 6차·7차까지 통합한 전체 타입 검사도 통과했다. 새 도구·경로·의존성은 추가하지 않았으며 빌드·배포·커밋·푸시는 실행하지 않았다.

## 추가한 사용 흐름

| 도구 | 저장하고 다시 사용하는 내용 | 한도와 보호 |
| --- | --- | --- |
| 택시 요금 계산기 | 지역·차종·거리·시간·시간 자동 여부·교통 상황·탑승 시각·시외 여부·인원을 이름으로 저장. 불러올 때 현재 계산 로직으로 요금을 다시 계산하며 이름 변경·삭제 지원 | 최대 10개, 이름 40자. 같은 이름 방지. 저장 목록이 현재 입력이나 공유 URL을 자동으로 덮지 않음 |
| 학점 계산기 | 학기·과목·학점·성적·전공·재수강·만점 기준·목표 평점·남은 학점을 시나리오로 저장. 현재 성적과 누적/전공 평점·이수 학점 비교 후 확인하여 복원 | 최대 8개, 이름 40자. 만점 기준이 다르면 평점 차이를 단순 비교하지 않음. 기존 자동저장·공유 링크 우선순위 유지 |
| 글자 수 세기 | 현재 문항의 글·제목·목표·계산 기준을 수정본으로 저장. 저장본과 현재 글의 본문·분량을 비교하고 확인 후 현재 문항에 복원. 기존 되돌리기로 복원 직전 상태 회복 | 최대 20개, 수정본 하나 50,000자, 합계 300,000자, 이름 40자. 다른 문항을 건드리지 않음 |

성적과 긴 원고를 교체할 때는 확인을 거친다. 택시는 입력 프리셋이므로 저장 조건 요약을 보고 사용자가 누르는 명시적 불러오기 동작으로 선택을 확인한다. 저장 항목 삭제는 확인 후 수행한다.

저장 데이터는 해당 브라우저에만 존재하며 다른 기기와 동기화되지 않는다. 브라우저 데이터를 지우면 사라진다. 새 이름·목록은 공유 링크에 포함하지 않는다. 기존 요금·GPA·글자 수 계산 기준은 유지했다.

## 저장 실패와 충돌 처리

- 손상되거나 지원하지 않는 저장 형식은 조용히 초기화하지 않고 원본을 보존한다.
- 할당량·접근 실패 시 성공 안내를 표시하지 않으며 입력 중인 내용과 기존 목록을 보존한다.
- 현재 탭이 읽은 원본과 저장 직전 원본을 비교하고, 지원되는 브라우저에서는 Web Locks로 쓰기를 직렬화한다. 다른 탭의 변경을 발견하면 목록을 다시 읽도록 안내한다.
- 글자 수 기존 자동저장도 성공 여부·손상 데이터·동시 쓰기 처리를 보완했다. 수정본 저장과 현재 글 자동저장은 서로 다른 저장 키를 사용한다.
- GPA는 최대 32학기, 학기당 100과목, 전체 1,000과목의 구조를 검증한다. 입력 전체가 유효하지 않으면 일부 과목만 잘라 복원하지 않는다.

## 한계와 증거

실제 휴대폰·Safari/Firefox·프로덕션 정적 export는 이번 범위 밖이다. 세 도구 모두 Web Locks 지원 환경에서는 쓰기를 직렬화한다. 미지원 환경에서도 기존 저장 동작을 유지하며 원본 비교·쓰기 후 읽기 확인으로 오래된 쓰기를 감지하지만, 완전히 동시인 쓰기의 원자성은 보장하지 않는다.
