# 에버랜드 검증 기록

## 범위

구현과 로컬 테스트. 원격 계정·DB·배포·푸시 없음. 사주 저장소 변경 없음.

## 통과한 검증

- TypeScript 전체 프로젝트 및 별도 Pages Function/Worker 타입 검사.
- 새 파일 대상 ESLint 오류 없음.
- messages generate/check, namespace audit unresolved 0. 기존 동적 네임스페이스 주의사항 56건은 별도 기존 코드.
- Cloudflare Pages Functions 로컬 번들 컴파일 성공.
- 실제 API `/children`, `/live` 응답 확인: 2026-11-04 10:55:49 KST 수집본. 메타데이터와 라이브 데이터를 합쳐 57개, 대기시간 숫자 22개, 범위 내 좌표 57개. API 원본은 저장소에 포함하지 않음.
- 정상·누락·0·음수·문자열·NaN·새 상태·비운영 상태, KST 자정 경계, 20분 지연, 누락된 기구 상태 검증.
- 메모리 SQLite에서 migration, 원자적 쓰기, 10분 중복 제거, 7일 보관, 429 이후 마지막 정상 시각 유지 검증.
- HTML 응답·출처·HTML 이스케이프·타 사이트 iframe 차단 헤더·설정 누락 503·Worker의 공개 HTTP 404 검증.
- Chromium 합성 데이터 테스트: 모바일 390px/데스크톱, 검색·검색 결과 없음·상태 필터·정렬·위치 선택·추이 표·영문, 페이지 오류 0·가로 넘침 없음.
- Next 개발 서버 실제 페이지에서 수집본을 현황판 응답으로 연결한 통합 테스트: 제목/iframe/실제 관측 화면, 모바일 가로 넘침 없음, 페이지 오류 0. 원격 D1 대신 로컬 응답 대체를 사용했으므로 실제 Cloudflare 배포 테스트는 아님.

## 발견하고 수정한 문제

- RSS/redirect 생성기의 Windows 고정 경로를 스크립트 상대 경로로 변경해 Linux에서 생성 가능하게 함.
- iframe이 React hydration보다 먼저 로드되면 높이가 전달되지 않는 문제: 부모 측 load/ResizeObserver로 측정 보완.
- 기존 npm 설치 플랫폼·lockfile 불일치는 의존성 파일 변경 없이 로컬 설치 방식으로 검증. 상세는 `docs/everland.md`.

## 남은 확인

- 공식 내부 안내도 이미지의 사용 허락 및 이미지상 기구 좌표 검수. 현재 좌표 도식은 대체 구현임.
- 사용자가 D1과 바인딩을 만든 뒤 실제 preview에서 Cron→D1→Pages 전체 흐름 확인.
- 전체 production build 및 static export 검사는 후속 요청으로 완료(아래 참조).
- 장기간 API 누락률·정확도 관측. 미래 예측·날짜별 SEO·라이브 데이터 검색 색인은 이번 범위에 포함하지 않음.

증빙 이미지와 JSON: `/tmp/everland-evidence/`. `*-fixture.png`는 합성 데이터, `toolhub-*.png`는 위 시각 API 수집본을 연결한 개발 화면이다.

## 후속 production 검증

명시적 요청을 받아 별도 `npx tsc --noEmit` 성공 후 `SKIP_BUILD_TYPECHECK=1 npm run build` 실행, 종료 코드 0. 772/772 페이지 생성. 외부 배포·푸시 없음.

에버랜드 정적 HTML의 h1, 가이드, 출처, canonical, 현황판 iframe, WebApplication 스키마, 지도 한계 설명, sitemap 및 OG 파일 모두 확인. production 정적 파일을 로컬 제공한 뒤 모바일/데스크톱 재검증하여 페이지 오류 0, 가로 넘침 없음, iframe의 검색 전후 높이 변경 확인.

전체 HTML 검사는 기존 noindex 팁 페이지 400개의 h1 없음만 검출했으며, 모두 noindex인 것을 직접 확인. 에버랜드 관련 실패 없음. build 경고는 기존 baseline-browser-mapping 데이터 갱신 안내 10회.

빈 D1 테이블은 HTTP 200 + 기록 준비 안내 + 가짜 시설 카드 없음, 첫 성공 1개 기록은 추이 부족 안내라는 자동 테스트를 추가해 확인. DB 미연결 503, 지도의 공식 안내도 미포함·미검증 좌표 설명도 유지.

실제 D1 생성·SQL 적용·바인딩·수집 Worker 배포·Cron 활성화는 아직 수행하지 않았으므로 **자동 수집은 시작되지 않았다**.

## D1 바인딩 준비 및 원격 전송 사전 확인

- 사용자 제공 DB ID를 Pages 기본·production·preview와 수집 Worker `EVERLAND_DB`에 연결하는 로컬 구성을 준비했다. DB 이름은 미확인으로 생략했으며 설치된 Wrangler 3.114.17은 ID만으로 dry-run 성공했다. 최신 Wrangler로 전환 전에는 실제 DB 이름 확인 필요.
- 수집기 `wrangler deploy --dry-run --config workers/everland/wrangler.toml` 성공. 이 명령은 실제 업로드·배포하지 않는다.
- 기존 루트 `wrangler.toml`은 이미 Git 추적 중이다. 해당 파일의 민감한 기존 설정을 새 변경본으로 게시하지 않기 위해 이번 기능 커밋에서 제외하고, 비밀값 없는 `workers/everland/pages-bindings.toml` 추가 블록으로 전달한다.
- Git push dry-run은 성공했으나 실제 push는 별도이다. GitHub Actions workflow 0개, 현재 main commit 상태 검사 0개. 과거 Vercel bot의 Production 배포 이력 확인. GitHub webhooks 조회는 integration 권한 부족 HTTP 403으로 실패했으며 재시도하지 않았다. Cloudflare/Vercel의 현재 브랜치별 자동 배포 설정은 미확인이다.
