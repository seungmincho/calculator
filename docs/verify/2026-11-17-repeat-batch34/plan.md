# 34차 계약 — 숫자 한글 변환의 중간 편집·복사 복구

> 완료(2026-11-17 KST): 자체40·독립8·실제 Chrome7/7·06:44:29 KST 공통 전체 타입 첫 실행을 통과했다. [완료 보고서](report.md). 아래는 실행 당시 계약이다.

2026-11-17 KST. 기존 `/number-to-korean/` 개선 계약이다. 28·30차 체크포인트 뒤 승인된 신규 입력/복사 유틸·복구 자식·검사·KO/EN 조각을 미연결 상태로 준비했다. 기존 부모 연결은 31·32·38차 체크포인트 뒤 별도 신호까지 보류하며, 준비 결과는 `preparation.md`에 기록한다.

## 확인한 불편

- `NumberToKorean.tsx`는 매 `onChange`에 `formatInput`으로 쉼표를 다시 삽입하며 composition 처리가 없다. 코드에도 중간 편집 시 커서가 끝으로 이동한다는 주석이 있다. 입력은 자동 focus라 모바일 진입 시 키보드가 결과를 가릴 수 있다. 실제 기기 재현은 아직 하지 않았다.
- 단일 결과 복사는 native 실패 안내만 있고 수동 선택·재시도가 없다. 입력/접두사/띄어쓰기 변경과 이전 Promise 또는2초 성공 타이머를 연결하는 세대 보호가 없어 과거 결과의 성공 안내가 현재 결과에 표시될 수 있다.
- `NumberToKoreanBatch.tsx`도 입력·옵션·locale 변경 중 오래된 복사 완료가 현재 안내를 덮을 수 있다. 기존100행/30,000자/행300자 한도와 TSV/CSV의 스프레드시트 수식 보호는 이미 구현되어 있으므로 유지한다.

## 제안 범위

1. 입력은 편집 중 사용자의 원문과 selection을 보존한다. 우선 단순한 정책으로 편집 중에는 강제 쉼표 삽입을 하지 않고 blur 또는 명시 정리 동작에서만 유효한 숫자 입력을 정리한다. 한글 역변환 원문은 그대로 두고 IME 조합 중에는 정리·URL 적용·빠른 금액 입력으로 조합 내용을 덮지 않는다. hydration URL 복원은 최초1회·편집 전 적용을 유지한다. 숫자20자리 문자열 정확성·분수·음수·큰 단위 변환 계산은 이 작업에서 바꾸지 않는다.
2. 자동 focus를 제거하고 첫 진입 키보드는 사용자 탭으로 연다. 기본 예시와 명시 비우기를 검토하되 공유 입력이 예시로 덮이지 않게 하고 예시인지 안내한다. 기존 빠른 금액 버튼의 음수 처리 의미는 별도 결정 없이 바꾸지 않는다.
3. 단일/일괄 복사는 클릭 순간의 현재 text·row identity·입력/옵션/locale 세대를 고정한다. native 성공 또는 legacy true만 성공이고, 실패하면 읽기 전용 전체 원문 선택·현재 결과 재시도·닫기를 제공한다. 늦은 실패가 fallback을 실행하거나 과거 문구를 다시 나타내지 않게 한다. 타이머는 요청 소유자만 자신의 안내를 지울 수 있다.
4. 기존 CSV 전체 반출/행 오류/원문/포맷 옵션/URL 의미를 유지한다. 새 장기 저장·계정·서버 전송·사용자 라벨 URL 저장은 추가하지 않는다. 수정 입력16px/조작44px/KO·EN/320px와 키보드 focus를 확인한다.

## 구현 전 확인·검증

- 실제 입력에서 가운데 숫자 삽입/삭제/범위 치환·선두 음수·소수점·쉼표 붙여넣기·한글 composition을 확인하고, 결과가 맞아도 caret가 이동하면 실패로 본다. blur 정책은 안내와 DOM이 일치해야 한다.
- 정확한20자리·현재 parser 회귀를 유지한다. 기존 안전 정수 밖 한글 역변환 제한은 기능 확장으로 오해하지 않게 남긴다.
- 단일/일괄 native 거부/부재·legacy false/throw·선택 실패·현재 재시도·입력/접두사/띄어쓰기/언어/언마운트 중 늦은 완료를 실제 부모 이벤트로 검증한다.
- 일괄 TSV/CSV는 독립 reader로100행 전체·빈행·음수·따옴표/개행·수식 보호를 확인한다. 이전 PASS를 새 구현의 실제 브라우저 검증으로 대신하지 않는다.

순수 입력 정책·action guard를 준비한 뒤 부모를 연결한다. 컴포넌트와 자기 KO/EN 조각은 같은 담당, 공용 생성물은 통합 담당, Chrome과 전체 타입 검사는 단일 소유권으로 진행한다. 신규 경로·빌드·배포·커밋·푸시는 이 후보에 포함하지 않는다.
