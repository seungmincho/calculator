# 기존 도구 개선 6차 — 일괄 변환과 글꼴 조합

2026-11-16. 사용자는 root가 계속 작업을 위임하고 다음 개선을 선정하도록 요청했다. 5차의 저장·비교 기능과 독립적인 기존 도구 2개를 다음 순서로 진행한다. 새 경로·새 의존성·AI 모델은 추가하지 않는다.

## 선택 이유와 범위

1. **숫자 → 한글 변환: 여러 금액 한 번에 처리.** 현재 한 개의 금액에 대한 다양한 표기와 복사 기능만 있다. 한 줄에 한 금액 또는 스프레드시트에서 복사한 `항목명<TAB>금액`을 최대 100줄까지 입력해 변환하고, 오류 행을 남겨 고칠 수 있게 한다. 숫자는 문자열 기반 기존 함수를 재사용해 큰 정수의 정밀도를 유지한다. 결과 표 복사·CSV 다운로드, 행별 원본 줄 번호와 오류 표시를 포함한다. 0·음수·소수는 읽기 표기는 가능하지만 계약서용 금액 표기는 기존 규칙에 따라 적용하지 않는다. 일부 행만 성공해도 전체 성공처럼 표시하지 않는다. 입력을 서버나 URL에 넣지 않는다.
2. **폰트 미리보기: 제목·본문 글꼴 조합.** 현재 최대 여러 글꼴로 같은 문장을 비교하고 CSS를 복사한다. 제목과 본문 각각 글꼴·크기·굵기를 선택해 한 문서 카드에서 조합을 살펴보고, 서로 바꾸기·CSS 복사·명시적 링크 공유를 지원한다. 기존 카탈로그와 로딩 함수를 재사용하고, 로컬 업로드 폰트를 원격으로 보내거나 공유에 포함하지 않는다. 기존 폰트 목록·즐겨찾기·고정 비교 기능은 보존한다.

첨부 이용 현황의 숫자 변환·폰트 도구 방문 사례와 현재 코드의 기능 공백에 따른 우선순위다. 새 트래픽 통계를 수집한 결과는 아니다. D-day는 이미 저장·고정, 단위 변환기는 최근 기록, 포모도로는 할 일·주간 통계가 있어 유사한 저장 기능 추가를 뒤로 미뤘다.

## 분업과 완료 기준

- 5차 구현 담당이 자기 기능의 최초 검증까지 마치면 재배정한다. 5차에서 발견되는 결함 수정은 우선 처리한다.
- 각 UI 담당은 자기 번역 ko/en 조각을 작성하며 공용 원본 병합은 통합 담당만 수행한다.
- 숫자: 20자리 정수, 빈줄·잘못된 행·100줄 한도, 계약서용 비지원 값, TSV/CSV 인젝션 방지·줄 정렬을 단위 검사한다.
- 글꼴: 허용된 글꼴 ID만 사용, 크기·굵기 범위·지원 굵기 보정, URL 왕복과 잘못된 값 기본값 복구, CSS 출력과 실제 선택값 일치를 검사한다.
- 두 화면의 실제 입력·버튼·복사·다운로드 또는 공유 복원, 320px 모바일/다크, 기존 단일 변환·글꼴 고정 비교 회귀를 검증한다.
- 기존 공용 번역 런타임은 한국어 전용이다. 새 ko/en 키는 모두 작성·정적 대조하되 영어 화면 전환이 지원된다고 주장하지 않는다.
- 무거운 브라우저·전체 타입 검사는 순차 실행한다. 빌드·배포는 하지 않는다.
