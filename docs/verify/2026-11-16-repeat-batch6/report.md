# 기존 도구 개선 6차 — 금액 일괄 변환·글꼴 조합

2026-11-16, KST. 기존 숫자 한글 변환기와 글꼴 미리보기를 확장하고 구현·브라우저·전체 타입 검사를 완료했다. 새 경로·의존성·AI 모델을 추가하지 않았으며, 빌드·배포·커밋·푸시는 실행하지 않았다.

## 사용 흐름

### 금액 여러 줄 변환

`/number-to-korean/`에서 한 줄에 금액 하나 또는 스프레드시트에서 복사한 `항목명<TAB>금액`을 넣는다. 결과는 원본 줄 번호·항목명·정규화된 숫자·읽는 표기·계약서용 표기·오류 상태를 함께 보여 준다. 기존 단일 변환과 접두어·띄어쓰기 설정을 그대로 사용한다.

- 최대 100줄, 전체 30,000자, 한 줄 300자. 전체 한도를 넘으면 앞부분만 변환한 것을 전체 결과처럼 표시하지 않는다. 끝의 한 줄바꿈은 행 종료로 처리한다.
- 빈줄은 건너뛰되 원래 줄 번호를 유지한다. 오류 행은 결과에서 지우지 않아 사용자가 원문을 찾아 고칠 수 있다.
- 숫자 정밀도는 기존 문자열 기반 변환 함수를 사용해 유지한다. 0·음수·소수는 읽는 표기를 제공하며 계약서용 표기가 지원되지 않음을 따로 표시한다.
- 결과 표를 TSV로 복사하거나 UTF-8 CSV로 다운로드한다. 오류 행도 원래 순서대로 남는다. 긴 숫자·사용자 텍스트는 텍스트 셀로 보호하고 수식 시작 문자를 방어한다. 스프레드시트 앱의 가져오기 방식에 따라 보호용 앞따옴표가 보일 수 있다.
- 일괄 입력은 자동저장하거나 URL에 넣지 않는다. 복사에 실패하면 성공 메시지를 표시하지 않는다.

### 제목·본문 글꼴 조합

`/font-preview/`의 조합 열기 버튼을 누르면 제목과 본문 각각 글꼴·크기·굵기·문구를 정하고 하나의 문서 카드에서 미리본다. 기본 화면에서는 패널을 접어 기존 글꼴 탐색을 먼저 사용할 수 있고, `pair=1` 공유 링크는 패널을 자동으로 연다. 맞바꾸기는 글꼴과 요청 굵기만 바꾸며 제목/본문 문구와 크기는 각 역할에 남긴다.

- 기존 카탈로그의 글꼴 ID만 허용한다. 지원하지 않는 굵기는 가까운 지원 굵기를 적용하고 요청값과 실제값을 안내한다.
- 제목 16~96px·120자, 본문 12~40px·2,000자. 잘못된 URL의 값은 범위 안으로 보정하거나 기본값으로 복구한다.
- CSS는 실제 적용 글꼴·크기·굵기와 일치하며 전체 글꼴 CSS URL을 포함한다. 제목·본문에서 같은 패밀리를 쓰거나 기존 목록에서 같은 글꼴을 불러도 서로 필요한 CSS를 제거하지 않도록 소유권을 분리했다.
- CSS 응답 뒤 실제 선택 글꼴의 로드까지 확인한다. 글꼴 파일 실패·15초 시간 초과·확인 API 미지원 상태를 구분해 안내하고, 이미 바뀐 이전 선택의 완료 이벤트는 무시한다.
- 링크 공유는 사용자가 누를 때만 생성한다. 링크에는 제목·본문의 문구와 설정이 포함된다. 12,000자를 넘는 링크는 실패 안내를 표시한다. 업로드한 로컬 폰트는 조합 카탈로그나 공유에 포함하지 않는다.
- 웹폰트는 외부 제공처에서 불러오며 일부 Google Fonts 미리보기 요청에는 문자 서브셋을 만들기 위한 문구가 포함될 수 있음을 화면에 안내한다. 기존 글꼴 목록·즐겨찾기·최대 4개 고정 비교를 유지한다.

## 검토와 한계

독립 코드 리뷰에서 글꼴을 사용하는 영역끼리 CSS를 지울 수 있는 기존 구조와 CSV 숫자의 자동 변환 위험을 미리 점검했다. 숫자 담당은 100행 뒤 붙는 마지막 줄바꿈 경계도 리뷰에 따라 보완했다. 자세한 결과는 [코드 리뷰](review-code.md), [브라우저 검증](review-browser.md)에 기록한다.

공통 번역기는 기존에 한국어만 로드한다. 새 ko/en 키와 실제 사용 키를 대조했으며 영어 UI 전환을 검증한 것으로 기록하지 않는다. 실제 휴대폰·Safari/Firefox·운영 정적 export는 검증하지 않았다.
