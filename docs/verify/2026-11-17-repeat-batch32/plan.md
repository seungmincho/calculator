# 32차 후보 — JSON 트리에서 정확한 경로·선택 값 가져오기

> 실행 완료(2026-11-17): 실제 Chrome6/6·독립12그룹·06:24:34 KST 공통 전체 타입 재검사 PASS. 최종 [보고서](report.md)와 [통합 기록](integration-checks.json)을 따른다. 아래 최초 후보/계약 문장은 이력으로 보존한다.

2026-11-17 KST. 기존 `/json-formatter/`의 후속 후보이며 제품 구현·브라우저 재현은 미착수다. 현재 CSV 성능 후속·29차 연결과28·30차 미연결 준비가 우선이다. [설치 JSONPath 엔진의14키 읽기·실행 조사](jsonpath-engine-reading.md)는 표현식 생성 가정을 점검한 근거이며 제품 완료 결과와 구분한다.

`JsonFormatter.tsx`의 트리는 내부 경로를 점으로 이어 붙이고 다시 점으로 나눠 JSONPath를 만든다. `{"a.b":1,"a":{"b":2}}`, 빈 키, 따옴표/역슬래시 키를 구분하지 못하며 숫자 모양 객체 키도 배열 인덱스처럼 표시한다. 펼침 상태의 Set에도 같은 문자열을 쓰므로 서로 다른 노드가 같은 상태를 공유할 수 있다. 경로 복사 버튼은 hover 때만 보이고 native 복사 실패를 무시하면서 성공 상태를 설정한다.

정렬 formatter는 일반 `{}`에 `sorted[k]=value`를 쓰고, 통계 역시 일반 객체에서 키 빈도를 누적한다. `__proto__`·`constructor` 같은 유효한 데이터 키는 일반 키와 같게 다뤄야 한다. 이 후보에서는 출력/통계용 사전의 키 처리만 함께 보완한다.

## 범위

- 내부 경로는 객체 key와 배열 index를 구분한 segment 배열로 전달한다. 펼침/선택 identity는 충돌 없는 직렬화를 사용한다. 빈 키와 root도 별개 노드이며 정렬 여부만 바뀌어도 같은 노드를 가리킨다.
- 선택한 노드의 전체 값을 작은 결과 영역에서 확인하고 ‘값 JSON 복사’, ‘JSONPath 복사’, ‘JSON Pointer 복사’를 제공한다. 긴 문자열을100자로 줄인 트리 표시와 실제 복사값을 분리하고 원문 전체를 복사한다. null/false/0/빈 문자열/빈 객체/배열/루트도 유효하다.
- JSON Pointer는 [RFC 6901](https://datatracker.ietf.org/doc/html/rfc6901)의 토큰 escape와 루트/빈 키 구분을 따른다. 원문을 URL fragment에 넣거나 새 공유 형식을 만들지 않는다.
- JSONPath는 segment로부터 escape하고 기존 설치된 jsonpath-plus가 실제로 선택한 값과 일치하는지 독립 fixture로 확인한다. 지원되지 않는 특수 키를 잘못된 경로로 성공 표시하지 않는다. 기존 저장한 JSONPath12개 형식/잠금/실행 흐름은 유지하며 자동으로 저장하지 않는다.
- 복사는 native 또는 legacy true만 성공으로 처리하고 실패 시 수동 선택/재시도를 제공한다. 입력/선택/모드/요청/언마운트 세대로 이전 복사·성공 타이머를 무효화한다. 원문·선택값·새 경로의 장기 저장/전송은 추가하지 않는다.
- 정렬 formatter와 키 통계는 own data key만 안전하게 다루고 `__proto__`를 포함해 키를 누락시키지 않는다. 일반 문자열·배열 순서·기존 들여쓰기/정렬 기능을 유지한다. 별도 임의 정밀도 JSON 파서나 트리 가상화 엔진은 첫 범위에 넣지 않는다.
- 모바일에서도 선택/복사 조작을 숨기지 않는다. 접근 가능한 이름·44px 조작·키보드 초점·320px 가로 폭을 확인하고 수정 영역은 디자인 토큰을 사용한다. 파일 읽기/기존JSONPath예제/저장본을 임의 변경하지 않는다.

검증은 dotted/nested·빈 키·숫자 객체키/배열·따옴표/역슬래시/슬래시/틸드/한글/제어문자 fixtures의 경로 왕복, 독립 own-property resolver·jsonpath-plus 결과 대조, 특수 키 정렬 후 JSON.parse 구조 일치·정확 키 빈도, 실제 부모 선택/펼침/정렬/입력 변경·복사 경합과 모바일로 구성한다. 기존 저장 JSONPath와 formatter 회귀·공용 번역/메타·전체 타입 검사 뒤 완료한다. 새 경로·패키지·빌드·배포·커밋은 없다.
