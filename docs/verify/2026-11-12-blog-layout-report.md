# AI 노트와 검색창 표시 검증 결과

2026년 11월 12일, 공개 사이트와 로컬 Next.js 개발 서버에서 Chrome으로 점검했다.

| 확인한 항목 | 운영에서 관찰한 상태 | 로컬 수정본에서 확인한 결과 |
| --- | --- | --- |
| 운영 배포 | AI 노트와 평수 가이드가 HTTP 200으로 열렸다. 사이트맵에서 두 URL, RSS에서 평수 가이드 항목을 확인했다. | 등록된 AI 노트는 0편이다. |
| 평수 계산기 | 글의 버튼을 누르면 공급 112㎡를 지정한 주소가 전용 84㎡로 바뀌어 25.41평이 표시됐다. 주소로 직접 접속하면 33.88평이 표시됐다. | 모바일에서 가이드 버튼을 누르면 공급 112㎡가 유지되며 33.88평이 표시되고, 제목 링크로 글에 돌아왔다. 기존 공유 링크에서 단위·전용률·가격·기타공용·서비스면적도 복원됐다. |
| 헤더 | 폭 1280px에서 7개 메뉴 이름의 실제 텍스트 너비가 표시 너비를 초과했다. | 한국어·영어 각각 1024, 1087, 1280, 1867px에서 모든 데스크톱 메뉴가 온전히 표시됐다. 검색 버튼과 겹침이 없었고 390px에서 모바일 메뉴로 AI 노트에 들어갔다. |
| 블로그 | 첫 글이 없는 상태와 공통 도구 목록 버튼이 보였다. | 실제 AI 관련 가이드 두 편이 목록에 나타났고 첫 링크가 해당 가이드로 열렸다. 공통 도구 목록 버튼은 보이지 않았다. |
| 검색창 | 가이드 페이지에서 검색을 열었을 때 배경의 위쪽 좌표가 64px였다. | 페이지 맨 위, 420px 스크롤한 데스크톱, 350px 스크롤한 모바일에서 배경이 화면 상단부터 하단까지 닿았다. 검색 결과가 표시됐고 Esc 및 바깥 클릭 후 기존 스크롤 위치가 복원됐다. |

수정본 브라우저 검증 중 페이지 오류는 없었다. 이 점검에서는 운영에 다시 배포하지 않았다.

## 재배포 후 운영 확인

2026년 11월 12일, Chrome으로 toolhub.ai.kr의 공개 화면을 다시 열었다.

| 항목 | 운영 결과 |
| --- | --- |
| 검색창 | 1867px 화면 맨 위, 1280px에서 420px 스크롤, 390px에서 350px 스크롤한 상태 모두 배경의 위쪽 좌표가 0px였다. 스크린샷 상단 모서리 픽셀이 흰색에서 회색(#7f7f7f)으로 바뀌었다. 검색 결과가 보였고 Esc 또는 바깥 클릭 후 원래 스크롤 위치로 돌아왔다. |
| 상단 메뉴 | 1024·1087·1280·1867px에서 한국어와 영어 메뉴 8개의 글자가 전부 표시됐으며 검색 버튼과 겹치지 않았다. 카테고리 드롭다운과 390px 모바일 메뉴에서 AI 노트로 이동하는 동작도 확인했다. |
| 평수 예시 | 390px와 1280px 모두 글의 버튼을 누르면 공급면적 112㎡와 33.88평이 표시됐다. 주소 자동 갱신 후에도 값이 유지됐고, 계산기 제목 아래 글 링크로 원래 가이드가 열렸다. |
