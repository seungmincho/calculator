# 홈 추천과 관련 링크 운영 검증

대상은 `https://toolhub.ai.kr`의 일반 공개 주소다. 사용자가 진행 중인 배포가 반영된 뒤 새 브라우저 세션에서 확인한다.

| 위치 | 확인 방법 | 기대 결과 |
|---|---|---|
| 홈 추천 | 초기 HTML에서 추천 섹션의 링크를 읽고 모바일 화면에서 차례로 누른다. 도구를 방문한 뒤 홈으로 돌아온다. | 택배비 계산기, 음력 양력 변환기, 평수 계산기가 이 순서로 표시되고 각각의 도구가 열린다. 재방문 후에도 세 링크가 보인다. |
| 마진 계산기 | 배송비 입력 옆의 ‘택배사별 배송비 비교’를 누른다. | `/shipping-calculator/`가 열린다. |
| 나이 계산기 | 생년월일 입력 옆의 ‘음력 생일을 양력 날짜로 변환’을 누른다. | `/lunar-converter/`가 열린다. |
| 중개수수료 계산기 | 부동산 종류 선택 옆의 ‘전용면적 ㎡를 평으로 환산’을 누른다. | `/pyeong-calculator/`가 열린다. |
| 사이트맵 | 공개 `/sitemap.xml` 응답에서 홈 주소와 일치하는 항목을 읽는다. | 홈의 `lastmod`가 `2026-11-12`다. |
