# 택배비 가이드 배포 전 개선 계획

11월 12일에 아래 1~4번을 구현하고 로컬 배포본으로 검증했다. 새 가이드 6편과 기존 글 7편의 사례 보강도 포함했다. [배포 전 검증 결과](../verify/2026-11-12-guide-release-report.md)

## 출발점

- 11월 12일 Search Console 내보내기에서 ‘발견됨 - 현재 색인이 생성되지 않음’은 툴허브 본체 380개, 별도 서브도메인 52개다. 본체 목록에는 홈 추천인 택배비·음력·평수 계산기가 모두 있다. 이번 배포의 기준 URL은 이 세 계산기와 각각의 상세 가이드로 정한다.
- 리디렉션 오류로 기록된 여섯 경로는 `/keyboard-converter`, `/text-to-speech`, `/menu-roulette`, `/color-blind-test`, `/lunar-converter`, `/shipping-calculator`다. 11월 12일 운영 HTTP HEAD 검사에서는 여섯 건 모두 끝에 슬래시가 있는 주소로 한 번 이동해 200을 반환했다. 배포 후에도 같은 결과인지 확인한다.
- 지난 로컬 확인에서 택배비 가이드의 예시 3개와 계산기에서 돌아오는 링크는 모바일·데스크톱 모두 동작했다. 남은 문제는 예시를 누른 독자가 전체 택배사 최저가부터 보게 된다는 점이다. 글에서 비교한 두 요금은 결과 목록 아래에 있다.

## 실행 순서와 완료 기준

1. **가이드에서 선택한 GS25 비교 결과를 먼저 보여준다.** 예시 링크의 도착 위치에 점포 수령액, 집 배송액, 차액을 함께 표시한다. 일반 방문자는 기존 계산기 흐름을 그대로 이용한다. 예시에서 무게를 고치면 두 요금과 차액이 함께 바뀌고, 반값택배 한도를 넘기면 해당 서비스의 접수 불가 사유를 표시한다. 가격은 계산기의 운임 함수로 구한다.
2. **방문자가 글의 무게와 구간을 재현할 수 있게 한다.** 현재 무게 입력 간격은 0.1kg이다. 500g과 501g을 각각 입력할 수 있게 바꾸고, 글의 1.08kg 예시도 확인한다. 비교 화면에 점포 간 내륙 운임과 주소 배송 타권 운임이라는 전제를 표시한다. 검색 설명과 FAQ에서도 어떤 서비스의 시작 요금인지 드러내고, 글의 물품가액·선불 조건은 표 가까이에 둔다.
3. **가이드 목록에서 세 상세 글을 쉽게 찾게 한다.** 현재 대표 글은 윤달 생일 한 건으로 고정돼 있다. 해당 자리에 택배비·음력·평수 상세 글로 가는 링크를 함께 제공한다. 글 제목과 주소는 기존 카탈로그에서 읽는다. 홈 추천 세 도구 → 각 계산기 → 대응 가이드 → 계산기 예시까지 모바일에서도 이동할 수 있으면 완료다.
4. **배포할 내용과 링크를 검증한다.** 500g·1kg·2kg에서 반값택배와 일반택배의 차액은 각각 2,500원·2,700원·2,900원이어야 한다. 501g과 5kg 초과, 세 변 합 80cm 초과도 확인한다. 타입·운임·가이드 검사를 실행하고, 사용자 배포 과정에서 생성된 정적 HTML에 제목·본문·일반 링크가 보이는지 확인한다. 사이트맵과 RSS는 각 가이드의 기본 주소를 가리키고, 예시 쿼리가 붙은 계산기의 canonical은 기본 계산기 주소여야 한다.

## 배포 뒤

- 운영에서 새 가이드 → 500g 예시 → 가이드로 직접 왕복한다. 위 여섯 경로의 리디렉션과 사이트맵에 실린 세 가이드의 응답도 재확인한다.
- Search Console URL 검사로 세 가이드와 세 계산기의 마지막 크롤링, Google이 선택한 표준 URL, 색인 상태를 기록한다. 새 택배 글과 실질적으로 바뀐 계산기부터 색인 생성을 요청한다. 1주·2주 뒤 같은 URL의 색인 여부, 검색 노출과 클릭을 비교해 다음에 보강할 글을 고른다. [Google 재크롤링 안내](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl?hl=ko)
