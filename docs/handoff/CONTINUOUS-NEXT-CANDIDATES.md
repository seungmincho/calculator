## 1. 읽어주기: 실패한 문장에서 명시적으로 다시 읽기

- **사용자 문제:** 긴 글을 듣다가 음성 오류가 나면, 모바일에서 읽던 문장을 다시 찾아야 한다. 기본 재생 버튼은 처음부터 시작하므로 이미 들은 구간을 반복할 수 있다.
- **현재 코드 근거:** `src/components/TextToSpeech.tsx:192`의 `u.onerror`는 현재 `idx`/`cur`를 남긴 채 상태를 `stopped`로 바꾸고 오류 문구만 표시한다. `:225`의 `toggle`은 stopped이면 `speakFrom(0)`을 호출한다. `:450`의 오류 영역에는 복구 버튼이 없다. 문장별 재생·일시정지/재개·반복 구간·OCR/메모 전달은 이미 있으므로 새로 만들 대상이 아니다.
- **최소 구현 범위:** 오류 영역에 실패한 문장 번호/짧은 미리보기와 `이 문장부터 다시 읽기`를 제공하고 기존 `speakFrom`을 재사용한다. 본문 수정·새 전달·정지 후에는 이전 오류 위치를 무효화한다. 기기 음성만 사용하기 설정을 유지하며 재시도는 사용자 클릭으로만 시작한다. 44px 버튼을 오류 안내 가까이에 둔다.
- **검증 기준:** 중간 문장 오류 후 첫 문장으로 돌아가지 않고 해당 문장에서 재시도; 본문 변경 후 오래된 위치 사용 금지; 반복 구간·횟수 및 일시정지 회귀; 자동 재생 없음; 기기 음성 없음/네트워크 음성 실패 구분; 320px에서 오류와 복구 버튼을 읽고 누를 수 있음.
- **우선순위 가설:** **P1.** 기존 재생 엔진을 이용해 실패 뒤 재탐색 비용을 줄이는 작은 범위다. 실제 기기별 오류 재현은 착수 시 확인한다.

## 2. 학점 변환기: 실패를 성공으로 표시하지 않는 복사와 수동 복사 대안

- **사용자 문제:** 지원서 등에 환산 결과를 옮기는 중 브라우저가 복사를 막으면, 복사됐다는 안내만 믿고 다시 붙여넣거나 입력할 수 있다. 모바일에서도 결과 문구를 직접 선택할 수 있는 대안이 필요하다.
- **현재 코드 근거:** `src/components/GpaConverter.tsx:140`의 `copyToClipboard`는 Clipboard API 예외를 무시하고 `execCommand('copy')`의 반환값도 확인하지 않은 채 `setCopiedId`를 호출한다. `:283`의 공유 링크와 `:306`의 결과 복사가 이 경로를 쓴다. `:159` 이후 `resultText`는 이미 입력 만점·비례 환산·등급 참고 결과를 구분해 만든다. 이 조사에서는 브라우저 차단을 실제로 주입하지 않았으며 코드 경로만 확인했다.
- **최소 구현 범위:** 성공/실패 상태를 구분하고 실패 시 기존 `resultText` 또는 공유 URL을 읽기 전용 선택 가능한 필드로 보여준다. 재시도와 수동 복사를 제공하고, 입력 변경 시 오래된 성공 안내/대체 텍스트를 갱신한다. 16px 필드·44px 버튼을 적용한다. 계산식과 참고 등급표는 변경하지 않는다.
- **검증 기준:** Clipboard 거부·API 없음·execCommand false에서 성공 표시 금지; 현재 결과/현재 URL만 수동 복사 필드에 표시; 줄바꿈/한국어·비례/참고 구분 유지; 모바일 키보드 선택·가로 넘침 확인; 기존 4.5/4.3/4.0/100 변환 회귀.
- **우선순위 가설:** **P1.** 자주 쓰는 결과 반출 단계의 혼란을 작은 변경으로 줄일 수 있다. 학교별 공식 환산 기능과 무관하다.

## 3. 글꼴 미리보기: 제목·본문 스타일 조합을 이름으로 재사용

- **사용자 문제:** 같은 문서용 제목/본문 글꼴과 크기·굵기를 다음 방문마다 다시 고른다. 공유 링크를 따로 보관해야 재사용할 수 있고, 모바일에서는 두 역할의 설정을 여러 번 조작한다.
- **현재 코드 근거:** `src/components/FontPreview.tsx:141`의 `pairDraft`는 부모 메모리 상태여서 접기/재열기는 보존하지만 방문을 다시 시작하면 기본값이다. `:174`의 localStorage는 단일 글꼴 즐겨찾기 `fontPreview.favs`만 복원한다. `src/components/FontPairPreview.tsx:33`은 메모리/초기 URL에서 조합을 만들며 `:125`부터 CSS/공유 링크 복사를 제공한다. 제목·본문 조합 미리보기 자체, 실제 폰트 로드 확인, 공유, CSS 복사, 단일 글꼴 즐겨찾기는 이미 구현됐다.
- **최소 구현 범위:** 기존 조합 패널에 이름 40자·최대 6개 정도의 명시적 스타일 저장/불러오기/삭제를 추가한다. 제목·본문의 카탈로그 글꼴 ID, 크기, 굵기만 저장하고 원고 본문·로컬 폰트 파일은 저장하지 않는다. 불러와도 현재 제목/본문 문구를 유지한다. 별도 카드·경로 없이 패널 내 선택 UI로 재사용하고 손상/동시 수정/저장 실패를 설명한다.
- **검증 기준:** 새 방문 후 두 역할의 스타일 복원; 현재 원고 유지; 공유 URL 초기 복원과 저장 조합 불러오기 우선순위 명확; 미지원 ID/범위/미래 버전 전체 거부; quota/다중 탭 실패 시 원본 목록 보존; 폰트 재선택 중 로드 결과의 세대 충돌 없음; 320px·44px·16px 확인.
- **우선순위 가설:** **P2.** 반복 입력 절감 효과는 있으나 기존 공유 링크만으로 충분한 사용자도 있어, 앞선 두 오류 복구 후보 이후 수요를 확인한다. 6개 제한은 확정 요구사항이 아닌 최소안이다.

## 이번 후보에서 제외

학교·기업별 GPA 환산표, 성적증명서 공식 백분위 추정, 새로운 등급 규칙은 넣지 않았다. 검증할 공식 출처와 적용 범위가 필요한 별도 조사 대상으로 두며 이 후보 목록의 구현 근거로 삼지 않는다. 세 후보 모두 기존 경로·클라이언트 기능 안에서 검토 가능하며 서버·계정·유료 API 추가를 전제하지 않는다.
