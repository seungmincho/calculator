# 후속 후보 — 이름으로 다시 찾는 개인 기록

2026-11-17 KST. root의 읽기 전용 코드 조사이며 아직 구현하지 않았다. 18차 공용 번역과 19차 문서 도구 개선 뒤 별도 실행 계약을 정할 후보이다. 방문 통계 순위로 검증된 선택이 아니라 현재 빠진 재사용 흐름에 근거한다.

## 음력 기념일 저장

`LunarConverter.tsx`에는 단일 날짜 변환·11개년 날짜표·다음 기념일 D-day가 있고 17차에서 연도 선택 ICS를 추가했다. 여러 가족 기념일을 이름으로 저장/선택하는 목록은 없다.

최소안은 최대 12개·이름 40자로 **실제로 유효한 원 음력 연도/월/일/윤달**을 명시 저장하고 불러오기/삭제하는 것이다. 다음 날짜는 현재 날짜와 기존 `nextLunarAnniversary`로 새로 계산한다. 생년/음력 기준을 임의로 올해로 바꾸면 윤달이 사라지는 문제가 있으므로 원 날짜를 보존해야 한다. 실제 나이나 제사 방식은 추정하지 않는다.

불러오기는 현재 변환 입력을 교체한다는 확인 뒤 진행하며, 공유 링크 초기값보다 저장본을 먼저 자동 적용하지 않는다. 명시적으로 기념일을 불러온 경우 17차 달력 제목에 이름을 전달할 수 있지만 기존 연도 선택은 새 기념일에 맞춰 다시 고르게 한다. 반출할 연도를 자동 선택하거나 여러 사람을 한 파일에 조용히 합치지 않는다. 기존 변환·윤달 대체 규칙·원본 기념일의 연도와 올해 발생 날짜를 구분한다.

손상/미지원 저장소·quota·동시 변경을 보존하고 조회로 복구한다. 17차에서 남긴 복사 실패 거짓 성공도 같은 도구의 최소 관련 복구 작업으로 묶을 수 있다. 구체 연결 API와 저장 계약은 착수 전에 정한다.

## 말하기 연습 기록 이름과 검색

`SpeakingSession`은 현재 mode/시각/takes만 저장하고 `SpeakingPractice` 목록은 모드·녹음 수·시각만 보여 준다. 최대 20개 기록 중 ‘면접 첫 자기소개’, ‘이번 주 업무 보고’를 이름이나 원고로 찾는 기능은 없다. Whisper tiny·기본 점검·선택형 생성 코칭·첫 녹음 비교·텍스트/오디오 반출은 이미 있으므로 다시 구현하지 않는다.

최소안은 선택적 40자 기록 이름과 목록의 이름/전사문 검색·모드 필터다. 이름 없는 기존 v1 기록은 그대로 읽고 사용자가 저장하기 전 자동 마이그레이션/이름 만들기를 하지 않는다. 중복 이름은 허용하고 식별은 기존 id로 한다. 이름은 본문 텍스트 반출에는 포함할 수 있으나 기존 요약 공유 URL에는 새로 넣지 않는다.

저장 구현 검토가 선행되어야 한다. 현재 `saveSpeakingSession`은 readwrite 트랜잭션에서 개수만 확인하고 전체 session을 put하므로 다른 탭의 최신 수정과 경쟁할 수 있다. 이름을 바꾸다가 원 음성/전사문을 오래된 복사본으로 덮지 않도록 선택적 revision의 호환 경계를 설계하고, 같은 트랜잭션 안에서 읽기·비교·쓰기해야 한다. 기존 음성 Blob과 모든 take/feedback을 보존하며 별도의 신규 모델·계정·서버를 추가하지 않는다.

검증은 실제 IndexedDB의 이전 기록·이름 수정·검색·새 방문·빈 검색/검색 결과 없음·동시 수정·quota/트랜잭션 abort, 녹음 비교와 수동 텍스트 입력 회귀로 한다. 모델 코드를 바꾸지 않으면 대용량 모델을 다시 내려받는 검증을 필수로 만들지 않는다. 저장 한도와 기록 데이터의 안정성을 우선한다.
