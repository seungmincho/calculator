# 지뢰찾기 같은 판 연습 후보

2026-11-17 KST. 읽기 전용 코드 조사이며 미착수다. 사용자가 처음 제공한 방문 화면에 있던 기존 `/minesweeper/`의 반복 사용 개선 후보다. 그 작은 화면만으로 현재 실제 방문 순위를 단정하지 않는다.

현재 클래식은 첫 칸을 열 때 `generate/generateNoGuess`로 배치를 만들고, `newGame`은 항상 배치가 없는 새 판으로 초기화한다. 종료 후 같은 배치의 같은 출발점에서 다시 풀 수 없다. 일일 도전은 이미 고정 배치와 결과 보관을 갖고 있으며 종료한 날의 판을 공개한다. 동일 일일 기능을 새로 만들 대상은 아니다.

최소안은 **종료한 클래식 판만 ‘같은 판 연습’으로 다시 풀기**다. 해당 방문의 메모리에 원 배치·난도/크기·처음 연 칸을 보관한다. 새 난수나 현재 난도 설정으로 다시 생성하지 않으며, 원래 안전한 시작 칸을 연 상태에서 새 연습을 시작한다. 깃발/물음표/열린 칸/실패 위치/시간/클릭 수는 새 상태로 만든다. 시작 칸을 자동으로 열었다는 점과 첫 사용자 조작부터 시간을 잰다는 정책을 표시한다.

연습판은 표시가 분명해야 하고 개인 최고 기록·업적·공개 리더보드에 반영하지 않는다. 이미 본 판을 일반 기록으로 등록하지 않도록 finish/이름 입력 모달/기존 점수 제출 경로를 함께 확인한다. 새 판을 누르거나 난도/모드를 명시적으로 바꾸면 일반 흐름으로 돌아간다. 기존 일일 판/기록·공유는 이 첫 범위에서 변경하지 않는다. 배치 URL 공유/장기 저장/풀이 힌트/자동 풀이 엔진은 추가하지 않는다.

기존 `Game`에는 첫 클릭 위치가 없으므로 처음 배치를 만들 때만 명시적으로 캡처해야 한다. 배치 배열을 입력/깃발 상태와 섞어 변이하지 않으며 재연습 중 다시 실패해도 같은 원본을 유지한다. `noGuessFailed` 같은 생성 결과 표시는 원래 판의 값을 보존하고 새로 무추측 검증을 했다고 주장하지 않는다. 완료 후 남은 길게 누르기 타이머와 지연 포인터 동작이 재시작 판을 조작하지 않도록 입력 세대를 확인한다.

검증은 원본/재연습 mine·adjacent 배열 동일성, 원래 첫 칸/초기열림·새 깃발/타이머, 연습 반복, 새 난도/일일 이동, 일반 승리 기록 회귀와 연습 기록 비반영, 키보드/터치·320px·KO/EN이다. 공개 리더보드 전송은 mock으로 차단하고 실서비스에 테스트 점수를 올리지 않는다. 실제 무추측 판 생성 규칙이나 난수 품질을 이 후보에서 변경하지 않는다.
