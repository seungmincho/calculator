## 분업 규칙

- **root:** 후보 확인·범위 결정·다음 작업 배정·독립 리뷰의 제품 판단. 완료된 담당은 다음 항목으로 재배정하되 기존 결함 수정이 먼저다.
- **제품 담당 4명:** 도구별 컴포넌트·순수 로직·단위 검사·해당 ko/en 번역 조각을 함께 작성한다. 현재 팀은 root+제품 4+독립검증 1+공용통합 1이다.
- **독립 검증 담당:** 제품 파일을 고치지 않고 실제 브라우저·오류 주입·모바일·회귀를 검사하고 재현 조건을 구현 담당에게 전달한다.
- **공용 통합 담당:** messages 원본은 한 명만 병합. 메뉴·페이지 설명·생성물·최종 타입 검사·보고서·인계 담당.
- 전체 타입 검사와 브라우저는 순차 실행한다. 기존 개발 서버 3039를 재사용하고 메모리 상태를 확인한다. 타입 검사는 우선 2GB heap 한도로 실행한다.
- 새 유틸·자식 컴포넌트 파일을 먼저 완성하고 범위 lint를 확인한 뒤 부모 import를 마지막에 연결한다. 없는 파일을 먼저 import하면 Next 개발 서버의 전역 오류 화면이 다른 도구 검증도 막는다. 중간 편집 환경 실패와 제품 결함을 구분하고 영향받은 사례만 재실행한다.
- 사용량을 소모하기 위한 반복 검사·중복 구현은 하지 않는다. 실제 개선과 검증에 작업을 쓴다. 사용량 초기화는 사용자의 허용 의사를 기록하되 실제 실행 기능과 필요성을 확인해야 하며, 실행하지 않은 초기화를 완료했다고 기록하지 않는다.

## 묶음별 완료 기준

1. 기존 기능 보존, 모바일 320px/터치 44px/입력 16px, 디자인 토큰, 명확한 저장/복사 실패 안내.

3. ko/en 번역 원본과 사용 키 일치. 현재 공용 번역 런타임의 한국어 전용 제약을 영어 화면 전환 완료로 과장하지 않는다.

5. 보고서와 실제 결과 파일 링크가 있어야 `검증 완료`로 바꾼다. 에이전트의 구현 완료 보고만으로 완료 표시하지 않는다.

## 최종 체크포인트와 재개

8~12차 01~15의 필수 작업과 검증은 완료했다. 마지막 전체 타입 검사 시각은 2026-11-16 23:34 KST이며 2GB heap·직전 여유 5.54GiB·Chrome 종료 상태에서 exit0을 확인했다. 번역 생성/검사 796개 일치, namespace 미해결 0개(기존 동적 안내 60개), 공용 범위 lint·RSS/redirect/llms·diff 검사도 통과했다. 제품 담당 4명은 완료 후 서로 다른 제품의 독립 검토로 재배정됐고, root·독립 브라우저·공용 통합까지 총 7명이 역할을 나눴다.

기존 Notepad Date.now purity 오류 1개는 HEAD와 현재가 동일함을 `batch10/notepad-implementation.md`에 기록했다. TimerStopwatch의 기존 exhaustive-deps 경고 1개도 남아 있다. 따라서 전체 저장소 lint가 0이라는 주장은 하지 않는다. 한국어 전용 공용 번역기, Web Locks 없는 환경의 완전 동시 쓰기 원자성, 실제 모바일 기기·OS 음성·실사용자 마이크·ASR 품질·운영 정적 export는 별도 한계다. 빌드·배포·커밋·푸시는 실행하지 않았다.

다음 세션은 [후속 후보](CONTINUOUS-NEXT-CANDIDATES.md)와 NEXT-SESSION 상단부터 읽는다. 이 큐를 다시 구현하거나 변경 없이 전체 검사를 반복하지 않는다. 후속에서 실제로 수정한 범위에 맞는 검증을 수행하고, 배포 등 별도 요청이 생기면 그 시점의 권한과 저장소 상태를 확인한다.
