# 22차 후보 — 확인한 수능 등급으로 저장 목표 비교

2026-11-17 KST. **읽기 전용 후보 조사이며 구현 미착수**다. 19차 전체 타입 검사와 20·21차 체크포인트를 우선한다. TS·제품·번역을 수정하지 않았고 브라우저/전체 타입 검사를 실행하지 않았다. 아래 합산 규칙은 현재 도구의 단순 비교 계약이며 새 입시 제도 사실이나 대학별 인정 기준을 추가하지 않는다.

## 문제와 현재 기능

성적표 등에서 이미 등급을 알고 있는 사용자가 현재 도구의 이름 붙인 목표 조건을 다시 확인하려면 원점수를 입력해 이전 학년도 참고 컷으로 등급을 추정해야 한다. 확인한 등급을 추정 등급으로 대체할 필요가 없는 사용자 흐름이다.

- `CsatGrade.tsx:106`의 원점수→등급/표준점수·백분위 추정, `:176`의 결과 공유, `:260`의 원점수 12개 기록, `:306`의 목표 6개 조건이 이미 있다. 새 기록 저장이나 새 목표 목록을 만들 필요는 없다.
- `csatScoreRecords.ts:8`의 v1 snapshot은 원점수 문자열 6개·선택과목·시험/참고학년도다. 등급 숫자를 이 필드에 넣으면 원점수 1~9점으로 다시 해석되므로 직접 등급을 저장할 수 있는 스키마가 아니다.
- `csatGoals.ts:7`의 조건은 이름·영역 수 2/3/4·합 상한뿐이며 원점수/성적을 저장하지 않는다. 같은 조건을 직접 등급에도 사용할 수 있다.
- 현재 목표 평가는 국어·수학·영어·탐구 상위 1과목 중 낮은 등급 수치의 2/3/4영역을 합산한다. 유효 영역이 부족하면 `needsInput`, 충분하면 `within/over`다. 탐구 두 슬롯은 한 영역이고 중복 과목의 상충 입력을 제외한다(`csatGoals.ts:42`).

## 대안 비교와 추천

| 대안 | 장점 | 변경/혼동 위험 |
|---|---|---|
| 화면 전체를 원점수/직접등급 모드로 전환 | 입력·결과 위치를 공유할 수 있음 | hero·과목 행·평균·추정 표·기존 ShareResult·공유 query·12개 기록 모두 모드 출처를 구분해야 함. v1 기록으로 직접 등급을 저장하면 의미가 손상됨. 현재 목표 이외의 결과까지 범위가 커짐 |
| **저장 목표 영역 안에 독립 직접등급 패널** | 원점수/공유/기록 상태를 유지하며 같은 6조건만 재평가. 별도 저장소/목표 중복 없음 | 결과 출처를 명확히 표기하고 직접 입력이 공유/저장되지 않는 범위를 알려야 함 |

**두 번째를 추천한다.** `CsatGoalConditions`가 보유한 `goals`와 읽기 가능 상태를 새 자식 `CsatDirectGradePanel`에 전달한다. 기존 raw `current`나 점수 setter를 자식에 전달하지 않는다. 저장/수정/삭제 후 `setView`로 바뀐 실제 목록이 바로 전달되므로 같은 탭의 최신 목표를 비교한다. 다른 탭 충돌·읽기 차단 시에는 기존 `blocked` 상태를 전달해 비교 결과를 최신 목록인 것처럼 유지하지 않고 재조회를 안내한다. 자식에서 같은 storage를 따로 읽거나 같은 조건을 복사해 저장하지 않는다.

## 추천 최소 계약

1. ‘확인한 등급 직접 입력’ 패널을 명시적으로 연다. 국어·수학·영어·탐구 1/2의 입력은 `미입력`과 `1~9` 선택지로 시작하고, 원점수 추정값을 자동으로 채우지 않는다. 데이터 검증은 빈 문자열 또는 한 자리 `[1-9]`만 허용한다. 0·10·소수·지수·NaN을 등급으로 보정하지 않는다.
2. 탐구 두 슬롯은 이 패널만의 과목 선택을 갖는다. 등급을 넣었지만 과목을 선택하지 않으면 안내하고 제외한다. 한 유효 과목이면 그 과목만 사용했다고 밝힌다. 같은 과목/같은 등급은 한 영역, 같은 과목/다른 등급은 탐구 제외+수정 안내로 처리한다. 서로 다른 두 과목도 상위 한 과목만 한 영역으로 센다. 동률에는 안정된 슬롯 순서로 실제 사용 과목을 표시한다.
3. 기존 저장 목표의 이름·2/3/4영역·합 상한을 읽기 전용으로 나열해 비교한다. 필요한 유효 영역이 부족하면 합/충족 여부를 만들지 않는다. 일부 입력으로 충분할 때도 ‘현재 입력한 유효 영역 기준’과 사용 과목/등급을 표시한다. 목표가 없으면 기존 목표 저장 영역으로 안내한다. 별도 CRUD나 일회성 조건 편집기를 중복 추가하지 않는다.
4. 등급→가짜 원점수 역산 후 `evaluateCsatGoal`에 넣지 않는다. 직접 등급 검증/탐구 선택과 raw `gradeOf` 변환은 별도로 두고, 이미 숫자 등급이 준비된 뒤의 합산·ready/status 부분만 작은 공통 helper로 재사용할 수 있다. 기존 `bestSum` 및 완전 입력의 결과를 회귀로 대조한다. 원점수 컷·보간·평균 함수를 새 직접 입력에 적용하지 않는다.
5. 상단과 각 결과에 ‘사용자가 직접 입력한 등급 기준 · 참고 원점수 컷으로 추정하지 않음’을 표시한다. ‘공식 확인된 등급’, ‘2027 확정 성적’처럼 입력의 진위/학년도를 자동 보증하지 않는다. 직접 패널에는 평균/표준점수/백분위/다음 등급까지 원점수를 표시하지 않는다.
6. 직접 입력은 해당 방문의 메모리에만 둔다. 패널 접기/언어 전환/목표 목록 갱신은 입력을 지우지 않는다. 명시 초기화와 페이지 이탈 때만 사라진다. 원점수 입력·12개 저장본·기존 공유 URL/해시·최초 URL 복원 우선순위를 변경하지 않는다. 직접 입력을 기존 공유 카드나 기록에 자동 포함하지 않는다고 패널에서 알린다. 모드 query나 새 저장 스키마는 이 최소안에 없다.

## 발견한 기존 결측 요약 불일치 — 직접 패널과 별도 범위

`CsatGrade.tsx:108`은 `Number(scores[id] || 0)`으로 빈칸을 0점으로 바꾼다. `:113`~`:114`가 이 등급으로 평균을 만들고, hero/각 과목 행/공유 카드(`:162`, `:170`, `:180`~`:187`, `:238`)에도 9등급과 0점이 나타날 수 있다. 반면 목표 평가(`csatGoals.ts:46`)는 빈칸을 제외한다. 이 경로는 코드상 확인했으며 이번 조사에서 브라우저로 새로 재현하지 않았다.

**수정 필요성을 별도 보완 범위로 권고한다.** 직접 등급 후보를 실행할 때 이 불일치를 새 모드에 복제하면 안 된다. 직접 패널은 처음부터 미입력을 유효 등급으로 세지 않는다. 원점수 요약도 별도 계약으로 다음과 같이 보완하는 것이 작다.

- 빈/무효 원점수 행의 grade·추정치·다음 컷 안내는 미입력/입력 확인으로 표시한다. 실제 문자열 `0`은 계속 유효한 0점과 기존 등급이다.
- 평균에 필요한 영역이 모두 유효할 때만 기존 `gradeAverages` 식을 사용한다. 미입력 영역에 9를 넣거나 임의의 분모로 부분 평균을 만들지 않는다. 원래 평균에서 제외하는 한국사 빈칸 때문에 평균 전체를 막지 않는다. 두 탐구 중 하나의 결측과 중복 과목 처리는 이 보완 계약에서 분명히 정한다.
- hero·공유 이미지/텍스트·과목 표·모바일 요약이 같은 결측 상태를 사용하게 한다. 완전한 기존 입력의 숫자 결과, 원점수 기록 schema, `?kor=`/없는 파라미터/실제0 구분, 구형 링크와 기타 query/hash는 유지한다.

이 보완은 직접 입력을 원점수 모드로 합치는 이유가 아니며, 등급컷 갱신·학교별 예측·평균 산식 변경으로 확대하지 않는다.

## 소유 파일·검증·미지원 범위

- **제품 소유안:** 새 `src/components/CsatDirectGradePanel.tsx`, 새 `src/utils/csatDirectGrades.ts`, 관련 순수/컴포넌트 검사와 ko/en 조각. 기존 `CsatGoalConditions.tsx`는 읽기 전용 목록/상태를 자식에 전달하는 최소 연결. 공통 합산을 추출한다면 `csatGoals.ts` 관련 부분만 회귀 검사 후 변경. `csatScoreRecords.ts`/기존 record schema는 변경하지 않는다. 위 결측 요약 보완을 따로 실행할 때만 `CsatGrade.tsx`를 별도 소유 범위로 포함한다. 원본 messages·메타는 통합 담당 소유다.
- **검증:** 빈 입력/1/9/잘못된 값, 2/3/4영역 미달과 부분 충족, 탐구 한 개/중복 같음·상충·서로 다름·동률, 실제 사용 영역과 합, 같은 등급을 넣었을 때 raw/direct의 목표 결과 일치. 목표 CRUD/다른 탭 충돌/손상 재조회 동안 직접 입력 보존. 직접 패널 사용 전후 원점수·12개 저장 raw bytes·URL·ShareResult 불변. 패널 접기/재열기·ko/en·320px·16px 선택/44px 제어·키보드·JS/hydration 검사. 별도 결측 보완은 `''`/`0`/누락 URL, 완전 입력 수치 회귀와 실제 공유 이미지까지 검증한다.
- **미지원:** 대학별 필수영역·탐구 평균/가중치·한국사 별도 조건·지원 가능/합격 판정, 성적표 OCR/진위 확인, 표준점수/백분위 환산, 직접 등급 저장/백업/공유, 원점수 추정 결과와 직접 입력의 자동 합성. 필요한 경우 후속의 별도 기준과 스키마 계약으로 다룬다.

새 입시 제도 사실을 제안에 넣지 않아 이번 조사에서 공식 제도 자료를 추가 인용하지 않았다. 기존 컷의 정확성을 직접 등급 패널의 근거로 사용하지 않는다.
