# 수능 시즌 개선 후보 — 제안 단계

2026-11-17 사용자 질문: 수능 관련 콘텐츠를 집중 업데이트하고 SEO에 대응하기에 늦었는지 검토. **제품 구현은 미착수이며, 아래 후보는 승인된 실행 계획이 아니다.** 이번 조사는 코드·콘텐츠·기존 정적 HTML을 읽는 데 한정했다. 제품·메타데이터·공용 핸드오프는 수정하지 않았다.

## 일정과 검색 기대치

- 2027학년도 수능 시험일은 **2026-11-19**, 성적 통지일은 **2026-12-11**이다. [교육부 공식 발표](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=100526&lev=0&m=020402) — root가 확인한 출처.
- Google 재수집은 며칠에서 몇 주가 걸릴 수 있고, 요청해도 검색 결과 포함을 보장하지 않는다. 따라서 시험 전 신규 검색 유입을 보장하는 계획으로 잡지 않는다. 기존 방문자의 정확한 정보 확인과 시험 후 가채점·성적 발표까지 이어지는 개선을 우선 검토한다. [Google 재수집 안내](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl) — root가 확인한 출처.

## 우선 후보 3개

1. **등급 기준과 추정 여부를 먼저 명확히 한다.** `src/utils/csatGrade.ts:11`은 올해 `CSAT_YEAR=2027`과 전년도 `CUT_YEAR=2026`을 구분한다. 그러나 `src/app/csat-grade/page.tsx:16`의 메타 설명·OG·JSON-LD는 2026학년도와 원점수 즉시 등급 확인을 강조하고, `src/components/CsatGrade.tsx:139`의 올해 D-day 아래 결과·공유물에는 기준 연도/추정 표시가 없다. 상단·공유물·검색 설명의 표현을 맞추고 올해 컷 미공개 상태를 알리는 후보다. 숫자를 올해 확정 컷으로 임의 변경하지 않는다. `messages/ko.json`의 `csatGrade.u.inputNote`·`disclaimer`의 “확정”과 `u.tableRel`의 “원점수 추정”을 정리하고, 실제 과목별 CUTS와 맞지 않는 `guide.tips`의 “사탐·과탐 평균 수준만 제공” 문구도 대조한다.

2. **올해 공식 수험생 유의사항과 안내를 대조한다.** `src/utils/csatDday.ts:40`의 4교시 세부 시간과 가채점 문항 수는 예년 기준이며, `csatDday.guide.sources.note`에는 “공고 후 다시 확인”이 남아 있다. 출처는 기관 홈페이지 중심이다. 올해 공고 직접 링크와 확인일을 붙이고 준비물·반입금지·4교시·가채점 안내를 대조하는 후보다. 특히 `csatDday.sheet.warn`의 “2027 수능은 가채점표 작성이 가능…수험표 뒷면”은 이번 코드 조사에서 공식 규칙을 검증한 문장이 아니므로 공식 유의사항 확인이 우선이다.

3. **기존 타이머에 과목별 연습 진입을 연결한다.** `src/components/CsatDday.tsx:180`의 연습은 1교시부터 시작하고, `src/components/TimerStopwatch.tsx:14`의 빠른 설정은 1·3·5·10·15·30분이다. `src/utils/timer.ts:94`는 이미 `?m=`을 지원한다. 공식 시험 시간과 대조한 국어 80분·수학 100분 등의 목적별 링크와 짧은 연습 안내만으로 반복 설정을 줄일 수 있다. 일반 관련 도구 링크는 `src/config/relatedTools.ts`에 이미 있으므로, 새 경로·타이머 엔진보다 시간이 채워진 진입이 최소 범위다.

## SSR 확인 범위와 한계

현재 네 페이지 코드에는 페이지 전체 Suspense 또는 `ssr:false`가 없고 `I18nWrapper.tsx`는 단순 통과 컴포넌트다. 기존 `out/`의 네 HTML(2026-11-16 18:28~18:29 생성)을 읽어 모두 `<h1>`이 `</main>` 앞에 있고 `hidden id="S:0"` 경계가 없음을 확인했다. D-day의 실시간 숫자는 초기 “계산 중” 상태지만 시험일·시간표·체크리스트·일정·FAQ는 본문 렌더 구조다.

이는 **기존 산출물 확인이며 최신 소스의 빌드·배포·실제 Google 색인 검증이 아니다.** 브라우저·전체 타입 검사·빌드는 실행하지 않았다. 내신 번역에 남은 오래된 `guide.tips` 문구는 현재 컴포넌트가 출력하지 않으므로 공개 화면 오류로 단정하지 않는다.
