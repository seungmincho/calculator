## PDF 페이지 정리의 단계별 되돌리기

`PdfTools.tsx`에는 병합·분할·이미지 변환, 페이지 회전/삭제/순서 이동, 키보드 위아래 이동과 전체 원상복원이 이미 있다. 빠진 것은 중간 삭제나 회전 한 번만 취소하는 흐름이다. `removeCard`는 즉시 배열에서 제거하고 reset은 전체 `orgInit`으로 되돌려 다른 편집까지 없앤다.

최소안은 페이지 정리 탭의 이동·개별/전체 회전·삭제·전체 원상복원을 최대30개 메모리 이력으로 undo/redo하는 것이다. 카드의 원본 페이지 번호/회전값/크기/안정 key를 보존한다. 원본 File/실제 PDF 바이트를 이력마다 복제하지 않는다. no-op은 이력을 만들지 않고 새 문서는 이력을 분리한다. undo 뒤 새 편집은 redo를 비운다.

실제 PDF 반출은 클릭 당시 카드 목록을 고정해 순서와 원래 PDF 회전+추가 회전이 맞는지 확인한다. 반출 뒤 편집하면 이전 파일임을 구분하거나 결과를 무효화해 현재 상태의 파일로 오인하지 않게 한다. 병합·분할·이미지 PDF의 기존 동작과 URL 탭은 유지한다. 새 썸네일 엔진/페이지 복제/파일 자동 저장은 추가하지 않는다.

검증은 카드 이력·삭제 후 복원 초점·맨위/아래 경계·전부 삭제→undo·전체 회전/원상복원·30회 한도·다른 문서, 그리고 실제 다중 페이지 PDF를 만들어 출력 순서/회전/내용을 pdf-lib로 다시 읽는 방식이다. 기존 키보드/모바일 정리 UI를 유지한다. 현재 읽기/작업 세대 guard를 착수 전에 대조하고 늦은 파일/반출로 새 이력을 덮는 경계가 있다면 최소 보완 계약에 포함한다.

추가 코드 확인: `selectTab`은 즉시 busy 상태/결과를 초기화하지만 실행 중 작업을 무효화하지 않는다. 공통 `finish`는 전달된 결과로 다운로드를 즉시 시작하며 현재 작업 확인이 없다. `readPdfs`도 await 후 status를 무조건 바꾼다. 따라서 새 이력 연결 시 ‘다른 탭/새 파일/새 편집/언마운트 뒤 늦은 완료가 상태·다운로드를 만들지 않음’이라는 공통 작업 세대 계약을 먼저 확정해야 한다. pdf-lib의 이미 실행 중인 연산을 실제 중지한다고 설명하지 않는다. 이 조사에서는 코드 경로만 확인했다.

## 비밀번호 생성 결과 한 개 다시 만들기·복사 실패 복구

현재 `PasswordGenerator.tsx`에는 무작위 비밀번호·PIN·단어 조합·강도 확인, 여러 개 생성, 개별/전체 복사가 있다. 생성 함수는 매번 전체 `results`를 바꾸므로 목록 중 한 개만 다시 만들 수 없다. copy는 execCommand 반환값을 확인하지 않고, catch 뒤에도 copied를 설정해 체크 아이콘이 생긴다.

최소안은 생성 결과 행마다 ‘이 항목 다시 만들기’를 제공해 현재 설정으로 해당 위치 하나만 갱신하고 나머지 값을 보존하는 것이다. 설정 변경과 전체 다시 만들기의 기존 전체 갱신은 유지한다. 기존 암호학적 난수/단어 목록/옵션 검증/엔트로피 계산을 바꾸지 않는다. 난수가 우연히 같은 값을 낼 수 있으므로 ‘이전과 반드시 다른 값’이나 중복 방지를 보장하지 않는다.

복사는 실제 성공만 체크 표시하며 실패하면 사용자가 선택해 복사할 수 있게 한다. 개별/전체 복사의 대상 snapshot을 구분하고 재생성/설정 변경/탭 이동/언마운트 뒤 늦은 완료가 다른 결과에 성공 안내를 붙이지 않게 한다. 생성 결과나 강도 확인 입력을 저장소/URL/로그/외부 요청에 추가하지 않는다. 마스킹 상태의 확인 입력을 복구 UI로 새로 노출하는 변경은 하지 않는다.

검증은 난수 포트를 제어한 한 위치 교체·다른 값 보존·PIN/단어/일반 옵션, 실제 생성기 범위 회귀, 복사 권한 거부/legacy false/재생성과 경합, 원문 비저장·설정 URL 유지·KO/EN·320px이다. 실사용 비밀번호를 테스트 데이터로 사용하지 않는다. 실제 보안 개선/강도 향상을 주장하는 후보가 아니라 생성·복사 사용성 개선이다.

두 후보는 아직 코드 경로만 조사한 상태다. 확정 시 부모/유틸 소유권과 실제 검증을 지정하며 같은 실패를 고쳤다는 완료 주장으로 미리 사용하지 않는다.
