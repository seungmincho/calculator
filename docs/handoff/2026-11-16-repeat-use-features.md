# 재방문 기능 후보와 첫 묶음 — 2026-11-16

사용자 요청: 사람들이 자주 쓸 만한 기능을 골라 순서대로 추가한다. 첫 묶음은 기존 도구 3개를 확장했다. 새 경로·가입·서버 저장·기본 대용량 모델 다운로드는 추가하지 않았다.

## 선정 기준

- 기존 도구에서 매번 다시 입력하거나, 페이지를 닫으면 잃는 작업을 줄인다.
- 휴대폰에서도 짧은 입력으로 결과를 얻고, 다음 방문 때 이어 쓸 수 있게 한다.
- 모델은 필요한 작업에서만 받는다. 단순 반복·저장은 모델 없이 처리한다.
- 첨부된 이용 화면은 팀 나누기와 TTS의 이용 사례를 보여 주지만 작은 시점별 수치다. 아래 우선순위는 수요가 검증된 순위가 아니라 기존 코드의 빈틈과 재사용 비용에 따른 제품 가설이다.
