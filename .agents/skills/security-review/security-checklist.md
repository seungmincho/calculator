# 보안 리뷰 체크리스트

## 언제 참고하나?

- 보안 리뷰를 수행할 때
- PR 머지 전 보안 항목을 점검할 때
- 프로덕션 배포 전 최종 확인 시

## 종합 체크리스트

### 민감 정보 관리

- [ ] 모든 비밀번호, API 키, 토큰이 환경 변수(`.env`)로 관리되는가
- [ ] 소스 코드에 하드코딩된 비밀 정보가 없는가
- [ ] `.env` 파일이 `.gitignore`에 포함되어 있는가
- [ ] 로그에 비밀번호, 토큰이 포함되지 않는가

### 입력 검증

- [ ] 모든 외부 입력에 Pydantic 모델 검증이 적용되어 있는가
- [ ] `Field()`로 값 범위와 길이 제한이 설정되어 있는가

### 위험 패턴 방지

- [ ] `pickle.loads()`, `eval()`, `exec()` 사용이 없는가
- [ ] `subprocess` 호출 시 `shell=True`를 사용하지 않는가

### API 보안

- [ ] CORS가 프로덕션에서 허용 도메인으로 제한되어 있는가
- [ ] 에러 응답에 스택 트레이스가 노출되지 않는가
- [ ] 프로덕션에서 Swagger UI(`/docs`)가 비활성화되어 있는가
- [ ] Rate Limiting이 적용되어 있는가

### 인프라 보안

- [ ] Redis 비밀번호(`requirepass`) 설정 완료
- [ ] Redis 외부 네트워크 미노출 (`bind 127.0.0.1`)
- [ ] MQTT 인증(`allow_anonymous false`) 설정 완료
- [ ] MQTT 토픽 ACL 설정 완료
- [ ] 프로덕션 MQTT TLS 적용 완료

### Docker / 의존성

- [ ] Docker 서비스가 격리된 내부 네트워크를 사용하는가
- [ ] Redis, MQTT 포트가 외부에 노출되지 않는가
- [ ] `uv run pip-audit`으로 취약점 스캔 완료
