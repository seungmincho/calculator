# Sprint Start Skill

세션 시작 시 컨텍스트를 빠르게 로드하고 다음 작업에 즉시 착수한다.

## Trigger Keywords

"시작하자", "이어서", "sprint", "다음 작업", "계속", "이전 작업 이어서", "로드맵 진행"

## Execution Flow

```
┌─────────────────────────────────────┐
│ 1. MEMORY.md 읽기                   │
├─────────────────────────────────────┤
│ 2. 다음 작업 식별 + 사용자에게 확인  │
├─────────────────────────────────────┤
│ 3. 즉시 구현 착수 (계획 X)           │
└─────────────────────────────────────┘
```

## Step 1: 컨텍스트 로드

다음 파일들을 읽는다 (병렬):
- `~/.Codex/projects/{project-path}/memory/MEMORY.md` — 진행 상황, 다음 작업
- `docs/composable-component-architecture.md` — 아키텍처 (MEMORY.md에서 참조 시)

**읽지 않는 것:**
- 이전 세션의 구현 상세 (이미 코드에 반영됨)
- 완료된 Phase 상세 (MEMORY.md 테이블로 충분)

## Step 2: 다음 작업 식별

MEMORY.md의 "다음 작업" 섹션에서 첫 번째 미완료 항목을 찾는다.

사용자에게 간결하게 보고한다:

```
현재 상태: [브랜치], 마지막 커밋 [해시] [메시지]
다음 작업: [작업 제목]
- [세부 항목 1]
- [세부 항목 2]

바로 시작할까요?
```

## Step 3: 즉시 착수

사용자가 확인하면 **바로 코딩을 시작**한다.

**금지:**
- TodoWrite로 계획 작성
- 옵션 탐색이나 대안 제시
- "먼저 ~를 확인하겠습니다" 류의 불필요한 사전 조사

**허용:**
- 구현에 필요한 파일 읽기 (최소한으로)
- TDD: 테스트 먼저 작성 → 구현

## Quick Reference

| 사용자 입력 | 동작 |
|-------------|------|
| "시작하자" | MEMORY.md → 다음 작업 확인 → 착수 |
| "sprint [작업명]" | 지정된 작업으로 바로 착수 |
| "/sprint" | 위와 동일 |
