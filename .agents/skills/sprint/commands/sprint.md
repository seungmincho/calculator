# Sprint Start (/sprint)

MEMORY.md를 읽고 다음 작업을 식별하여 즉시 착수한다.

## Usage

- `/sprint` — 다음 작업 확인 후 착수
- `/sprint [작업명]` — 지정 작업으로 바로 착수

## Execution

`skills/sprint/SKILL.md`의 워크플로우를 따라 실행한다.

1. MEMORY.md 읽기
2. 다음 작업 식별 + 현재 상태 간결히 보고
3. 확인 후 즉시 코딩 시작 (계획/TodoWrite 없이)
